## Selecting a token

For a CI integration, use a [workspace API token](/bitrise-platform/workspaces/workspace-api-token). It belongs to the workspace instead of to a person, so your builds keep working when someone changes roles or leaves the company.

A [Personal Access Token](/bitrise-platform/accounts/personal-access-tokens) also works, but it carries the roles of the user who created it and stops working when that user leaves the workspace.

On your own machine you need neither: the CLI signs you in through the browser and stores the credentials in the OS keychain. See [Setting up in a local dev environment](/bitrise-build-cache/getting-started-with-the-build-cache/getting-started-with-the-build-cache#setting-up-in-a-local-dev-environment) for the local guide of your build tool.
