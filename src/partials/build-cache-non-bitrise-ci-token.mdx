:::note[Which token to use]

For a CI integration, use a [Workspace API token](/bitrise-platform/workspaces/workspace-api-token). It belongs to the Workspace instead of to a person, so your builds keep working when someone changes roles or leaves the company.

A [Personal Access Token](/bitrise-platform/accounts/personal-access-tokens) also works, but it carries the roles of the user who created it and stops working when that user leaves the Workspace. Use it for per-developer setups, such as your own local builds.

:::
