1. Run the workflow. The activation step should finish successfully and log the cache endpoint it connected to.
1. Open the [Build Cache page](https://app.bitrise.io/build-cache/) of your Workspace. Your run appears in the invocation list, with the cache statistics of the build.
1. The first run reports a 0% cache hit rate: the cache is empty at that point. This is expected.
