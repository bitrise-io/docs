Make sure that the .ipa file has development, ad hoc, or enterprise distribution, and that the test device is of a supported device type, runs at least the minimum iOS version of the app, and, for development and ad hoc builds, is included in the app's provisioning profile. The public install page can't install an .ipa file with App Store distribution, and it lists the supported device types and the minimum iOS version. If the device isn't in the provisioning profile, add it in your Apple Developer account and rebuild the app. Enterprise builds don't need this.
