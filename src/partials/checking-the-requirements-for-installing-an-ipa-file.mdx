1. Make sure that:

   - The .ipa file has development, ad hoc, or enterprise distribution. The public install page can't install an .ipa file with App Store distribution.
   - The test device is of a supported device type and runs at least the minimum iOS version of the app. The install page lists both.
   - For development and ad hoc builds, the test device is included in the app's provisioning profile. If it isn't, add the device in your Apple Developer account and rebuild the app. Enterprise builds don't need this.
