1. When iOS asks whether the website can download a configuration profile, tap **Allow**.

   ![The iOS dialog asking whether app.bitrise.io can download a configuration profile, with the Ignore and Allow buttons](/img/ios-deployment/2026-11-12-allow-profile-download.png)

1. When iOS confirms that the profile is downloaded, tap **Close**.

   ![The Profile Downloaded message with the Close button](/img/ios-deployment/2026-11-12-profile-downloaded.png)

1. Open the **Settings** app and tap **Profile Downloaded**, right below your Apple Account at the top.

   ![The iOS Settings app with the Profile Downloaded item](/img/ios-deployment/2026-11-12-settings-profile-downloaded.png)

1. Check that the profile is the **Device Registration** profile from Bitrise, then tap **Install** in the top right corner. If your device has a passcode, iOS asks you to enter it.

   ![The Install Profile screen showing the Device Registration profile from Bitrise](/img/ios-deployment/2026-11-12-install-profile.png)

1. Tap **Install** in the confirmation dialog.

   ![The iOS dialog confirming that installing the profile changes settings on the device, with the Cancel and Install buttons](/img/ios-deployment/2026-11-12-confirm-install-profile.png)

1. Wait until the profile is installed. iOS takes you back to Safari automatically.
