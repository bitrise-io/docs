1. When iOS asks whether the website can download a configuration profile, tap **Allow**.

   <img src={require('@site/static/img/ios-deployment/2026-11-12-allow-profile-download.png').default} alt="The iOS dialog asking whether app.bitrise.io can download a configuration profile, with the Ignore and Allow buttons" width="260" />

1. When iOS confirms that the profile is downloaded, tap **Close**.

   <img src={require('@site/static/img/ios-deployment/2026-11-12-profile-downloaded.png').default} alt="The Profile Downloaded message with the Close button" width="260" />

1. Open the **Settings** app and tap **Profile Downloaded**, right below your Apple Account at the top.

   <img src={require('@site/static/img/ios-deployment/2026-11-12-settings-profile-downloaded.png').default} alt="The iOS Settings app with the Profile Downloaded item" width="260" />

1. Check that the profile is the **Device Registration** profile from Bitrise, then tap **Install** in the top right corner.

   If your device has a passcode, iOS asks you to enter it.

   <img src={require('@site/static/img/ios-deployment/2026-11-12-install-profile.png').default} alt="The Install Profile screen showing the Device Registration profile from Bitrise" width="260" />

1. Tap **Install** in the confirmation dialog.

   <img src={require('@site/static/img/ios-deployment/2026-11-12-confirm-install-profile.png').default} alt="The iOS dialog confirming that installing the profile changes settings on the device, with the Cancel and Install buttons" width="260" />

1. Wait until the profile is installed.

   iOS takes you back to Safari automatically.
