Many tests generate image files: screenshot tests, XCUITests, and so on. Bitrise can show these attachments under their associated test cases, so you can view them on the **Tests** tab of your build page. How to collate the test attachments with test results depends on your test tool and whether it generates an `xcresult` file.

## Collating attachments with test results

If your tests generate an `xcresult` file, Bitrise automatically collates the attachments with their test cases. This requires no further configuration.

If your tests don't generate an `xcresult` file, you have two options:

- [Name each file after its test case](#naming-attachments-after-their-test-case).
- [Reference each file in the JUnit XML](#referencing-attachments-in-the-junit-xml).

### Naming attachments after their test case

Name a screenshot, recording, or log after the test case that produced it, using the `<classname>__<name>[__run<k>]__<label>.<ext>` structure, and Bitrise shows it under that test. This requires the **Deploy to Bitrise.io** Step version 2.26.0 or newer.

For the full instructions, see:

- [Naming attachments after their test case](/bitrise-ci/testing/test-reports/test-attachments/naming-attachments-after-test-cases): the filename structure, how to export the attachments with a Bitrise Step, and how to troubleshoot missing attachments.
- [Setting up your test tool](/bitrise-ci/testing/test-reports/test-attachments/naming-attachments-after-test-cases#setting-up-your-test-tool): examples of how to make popular test tools name the attachments correctly: Espresso, Paparazzi, Roborazzi, Detox, and Playwright.

### Referencing attachments in the JUnit XML

If you can't name the files after their test cases, add a `<properties>` element to each `testcase` in your JUnit XML that lists the attachment files, then export the JUnit XML with the **Export test results to Test Reports** Step. This requires the Step version 1.1.0 or newer.

For the full instructions, see [Referencing attachments in the JUnit XML](/bitrise-ci/testing/test-reports/test-attachments/referencing-attachments-in-junit-xml).
