The Insights API gives you programmatic access to the data behind Bitrise Insights, so you can use it in your own tools, workflows, and AI agents. It's a public, read-only REST API that returns JSON.

## What it's for

Use it to bring your Insights data to where your team already works, or to build on top of it with your own automation and reporting.

## How it works

Requests are scoped to a project, and you can narrow and group the results to match how you look at your data in Insights. The [API reference](/insights-api/api-reference/bitrise-insights-api) describes the endpoints, parameters, and limits.

## Get started

You need a paid Insights plan and a Bitrise API token (a personal access token or a workspace API token), which you send in the `Authorization` header.
