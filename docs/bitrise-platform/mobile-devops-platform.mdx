Bitrise is a Mobile DevOps platform for every step of the mobile development process, from planning to monitoring. The platform equips mobile development teams with the necessary resources to build high-quality applications using their preferred tools, all while eliminating the interruptions and overhead that come with managing infrastructure and environments.

Signing up and creating a workspace provides the basis for everything Bitrise offers.

## About the platform docs

The platform documentation covers the shared structure behind the Bitrise products:

- [Accounts](/bitrise-platform/accounts/accounts-overview): How to sign up for a Bitrise account and what options you have to manage them.
- [Workspaces](/bitrise-platform/workspaces/workspaces-overview): Workspaces allow you to manage your projects and collaborate with team members. You need a workspace to run CI builds, to manage Release Management apps, or to use the other Bitrise products.
- [Projects](/bitrise-platform/projects/projects-overview): A Bitrise project can handle all stages of the Mobile DevOps process, including building, testing, and distributing mobile apps.
- [Integrations](/bitrise-platform/integrations/about-integrations): Bitrise supports a number of integrations to make sure you can use your preferred tools and environments every step of the way.

Once you have a workspace set up, explore the different Bitrise products to find the ones that fit your team.

## Explore the products

<div className="card-table">

| Product | Description |
|---|---|
| [Bitrise CI](/bitrise-ci) | Save time spent on testing, onboarding, and maintenance with automated Workflows and triggers. Bitrise CI runs your builds and tests on mobile-optimized machines, with integrations for the tools you already use. |
| [Release Management](/release-management) | Simplify distributing your iOS and Android apps to testers or directly to app stores, all from one platform and from the CI you choose. |
| [Build Cache](/bitrise-build-cache) | A fully managed remote caching solution that reduces CI build and test durations for apps built with Gradle, Bazel, or Xcode, and for React Native projects. |
| [Build Hub](/bitrise-build-hub) | Run your GitHub Actions workflows on Bitrise's mobile-optimized build machines. Build Hub brings Bitrise infrastructure and testing capabilities to your existing GitHub Actions CI/CD setup. |
| [Remote Dev Environments](/bitrise-rde) | On-demand cloud dev machines for macOS and Linux, running on the same infrastructure, stacks, and caches as Bitrise CI. Connect from your terminal, IDE, or AI agent, then archive an environment and restore it later. |
| [Insights](/insights) | Use build, test, and credit data to know what to prioritize and to optimize your CI/CD Workflows. |
