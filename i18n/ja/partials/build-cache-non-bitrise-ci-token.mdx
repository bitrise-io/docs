## トークンの選択 {#selecting-a-token}

CI の連携には、[workspace API トークン](/bitrise-platform/workspaces/workspace-api-token)を使用してください。このトークンは個人ではなくworkspaceに属するため、担当者のロールが変わったり退社したりしても、ビルドは引き続き動作します。

[Personal Access Token](/bitrise-platform/accounts/personal-access-tokens)も使用できますが、作成したユーザーのロールを引き継ぎ、そのユーザーがworkspaceを離れると動作しなくなります。

ご自身のマシンでは、どちらも必要ありません。CLIがブラウザー経由でサインインし、認証情報をOSキーチェーンに保存します。お使いのビルドツール向けのローカルガイドについては、[ローカル開発環境でのセットアップ](/bitrise-build-cache/getting-started-with-the-build-cache/getting-started-with-the-build-cache#setting-up-in-a-local-dev-environment)を参照してください。
