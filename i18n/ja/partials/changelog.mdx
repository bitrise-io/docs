## 変更履歴

### 2025年6月

<strong>変更</strong>

Linux <GlossTerm baseform="stack">スタック</GlossTerm>の更新ポリシーに関する記述を専用のページ [Linux スタック更新ポリシー](/bitrise-build-hub/infrastructure/build-stacks/linux-stack-update-policy) に移動しました。このページでは、Edge、Stable、Frozen の各スタックについて詳しく説明しています。また、Linux スタックを毎年新しくリリースするサイクルや、古い Linux スタックの非推奨化と削除についても説明しています。

スタックの以前のバージョンの使用方法をこのページから削除し、[Stack 更新ポリシー](/bitrise-build-hub/infrastructure/build-stacks/stack-update-policy) に追加しました。

### 2024年7月

<strong>削除</strong>:

依存関係マネージャーのキャッシュ更新に関する記述。Cocoapods と Homebrew は、レジストリの git リポジトリ全体をクローンする方法よりも優れた仕組みを備えるようになり、これらの新しい仕組み (Cocoapods CDN、Homebrew API) がスタックで有効になっています。スタックが更新される際、ディスク上のリポジトリは最新の状態になります。ただし、リリースする他の変更がない場合、Stable スタックは週次で厳密に更新されなくなりました。

<strong>変更</strong>:

stable macOS スタックに対する破壊的変更 (新しい Xcode のメジャーバージョンがリリースされる年に1回) は、既存の古い stable スタックには適用されなくなり、新しくリリースされた stable スタックにのみ適用されます。たとえば、Xcode 16.0 がリリースされた場合、予定されている破壊的変更は Xcode 16.0 の stable スタックにのみ適用されます。Xcode 14.x および 15.x の stable スタックには破壊的変更は適用されません。

### 2024年3月

<strong>New</strong>:

Edge スタックが、より新しい Edge スタックに置き換えられて段階的に廃止される際の動作を定義しました。

<strong>削除</strong>:

新しい Xcode Edge スタックがリリースされても、Stable スタックにツール類の変更が反映されなくなりました。

<strong>変更</strong>:

シミュレーターランタイムのポリシーを、よりシンプルなものに変更しました。インストールされる古い iOS メジャーバージョンの数は同じですが、それぞれ最新のマイナーバージョンのみがインストールされます。
