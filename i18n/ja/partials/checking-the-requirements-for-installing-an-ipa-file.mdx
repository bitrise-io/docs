1. 次の点を確認してください。

   - .ipa ファイルが開発（development）、アドホック（ad hoc）、またはエンタープライズ（enterprise）配布向けであること。公開インストールページでは、App Store 配布向けの .ipa ファイルをインストールできません。
   - テストデバイスがサポート対象のデバイスタイプであり、アプリの最小 iOS バージョン以上が動作していること。インストールページに両方が表示されます。
   - 開発およびアドホックビルドの場合、テストデバイスがアプリのプロビジョニングプロファイルに含まれていること。含まれていない場合は、 Apple Developer アカウントでデバイスを追加し、アプリを再ビルドしてください。エンタープライズビルドでは不要です。
