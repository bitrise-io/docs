## JavaScriptの依存関係のインストール {#installing-javascript-dependencies}

Bitriseの <GlossTerm baseform="project scanner">プロジェクトスキャナー</GlossTerm>がプロジェクトのスキャンに成功すると、<strong>Run npm command</strong> または <strong>Run yarn command</strong> <GlossTerm baseform="Step">Steps</GlossTerm>がデフォルトの <GlossTerm baseform="Workflow">Workflows</GlossTerm> に含まれます。これらのStepsは、アプリに不足しているJavaScriptの依存関係をインストールできます。

ネイティブのAndroidの依存関係には、<strong>Install missing Android SDK components</strong> Stepを使用できます。

ネイティブの iOS の依存関係には、<strong>Brew install</strong> Stepや <strong>Run CocoaPods install</strong> Stepなどを使用できます。

npm でJavaScriptの依存関係をインストールするには、次の手順を実行します。

:::note[npm の代わりに Yarn を使用する]

このガイドでは、JavaScriptの依存関係のインストールに npm を使用しています。ただし、<strong>Run yarn command</strong> Stepを使用することもできます。追加の設定なしで、不足している JS の依存関係をインストールできます。

:::

1. Log inでBitriseに移動し、左側で <strong>Bitrise CI</strong> を選択して、プロジェクトを選択してください。
1. メインページで <strong>Workflows</strong> ボタンをクリックしてください。
1. Workflowに <strong>Run npm command</strong> Stepが含まれていることを確認してください。
1. <strong>The 'npm' command with arguments to run</strong> 入力変数に `install` と入力してください。

   ![Getting_started_with_React_Native_apps.png](/img/_paligo/uuid-021a140f-5b4c-697c-a5ac-4b5429ce1bab.png)

   :::tip[`npm install`の代わりに`npm ci`コマンドを使用する]

   プロジェクトに最新の `package-lock.json` ファイルがある場合は、<strong>The 'npm' command with arguments to run</strong> 入力で `ci` コマンドを使用することを推奨します。`npm ci`を使用すると、`npm install`に比べてビルド時間が大幅に短縮されるだけでなく、ビルドの信頼性も向上します。

   :::
