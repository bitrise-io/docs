Bitriseでは、仕様の異なる複数のbuild machinesを提供しています。必要に応じて選択できます。

各マシンタイプでアプリのビルドに費やした時間は、Insights で確認できます：[Bitrise CI metrics](/insights/available-metrics-in-insights/bitrise-ci-metrics)。

:::tip[サブスクリプションプランごとのマシンの利用可否]

すべてのマシンがすべてのサブスクリプションプランで利用できるわけではありません。ご利用のプランで使えるマシンについては、[料金ページ](http://www.bitrise.io/pricing)をご確認ください。

:::

マシンタイプはリソースクラスに分類されます。同じリソースクラスには、おおむね同程度の性能を持つ複数のマシンタイプが含まれます。Bitriseはリソースクラスの中からマシンタイプを自動的に割り当てるため、同じ日でもビルドが異なるマシンタイプで実行される場合があります。

:::tip

マシンタイプ ID を使用して、[configuration YAML](/bitrise-ci/configure-builds/configuring-build-settings/setting-the-stack-for-your-builds#setting-the-stack-in-the-configuration-yaml)でマシンタイプを設定します。

:::
