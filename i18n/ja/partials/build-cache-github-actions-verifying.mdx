1. ワークフローを実行します。アクティベーションStepが正常に完了し、接続したキャッシュエンドポイントがログに記録されるはずです。
1. Workspaceの[Build Cacheページ](https://app.bitrise.io/build-cache/)を開きます。実行したビルドが、ビルドのキャッシュ統計とともにinvocation listに表示されます。
1. 最初の実行では、キャッシュヒット率は0%と報告されます。この時点ではキャッシュが空のためで、想定どおりの動作です。
1. キャッシュをウォームアップするため、ワークフローをさらに1～3回実行してください。ヒット率が0%を超えるはずです。
