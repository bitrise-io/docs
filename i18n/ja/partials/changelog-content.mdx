## 2026年9月 {#2026-september}

### <time dateTime="2026-09-21">2026-09-21</time> CIのドキュメントを CLI v3 の構文に更新 {#2026-09-21-update-ci-docs-with-cli-v3-syntax}

CIのドキュメントに、CLI v3 のコマンド構文が反映されました。`bitrise run` のようなコマンドは `bitrise local run` として記載されています。既存のコマンドはこれまでどおり動作します。詳しくは、[CLIを使用した初めてのローカルビルドの実行](/bitrise-ci/bitrise-cli/running-your-first-local-build-with-the-cli)をご覧ください。

### <time dateTime="2026-09-18">2026-09-18</time> Remote Dev Environmentsで仮想デバイスに対応 {#2026-09-18-remote-dev-environments-adds-virtual-devices}

Remote Dev Environmentsで、iOSシミュレーターまたは Android エミュレーターを使用できるようになりました。インタラクティブなデバイスセッション、または共有可能なデバイスプレビューリンクから利用できます。詳しくは、[仮想デバイス](/bitrise-rde/devices/virtual-devices)をご覧ください。

### <time dateTime="2026-09-18">2026-09-18</time> プルリクエストビルドの承認を切り替えられるユーザーに関する記述を修正 {#2026-09-18-fixed-who-can-toggle-pull-request-build-approval}

プルリクエストの手動承認設定のオン・オフを制御するのは、Approve build requests ではなく Edit workflows であることを、ドキュメントに正しく反映しました。Approve build requests は、この設定がオンの場合に個々のビルドを承認または却下する権限のみを対象とします。詳しくは、[プルリクエストビルドの承認](/bitrise-ci/run-and-analyze-builds/starting-builds/approving-pull-request-builds)をご覧ください。

### <time dateTime="2026-09-18">2026-09-18</time> GitHub Actionsのセットアップガイドを Build Cache 向けに追加 {#2026-09-18-github-actions-setup-guides-for-the-build-cache}

Build Cacheの各ツール（Gradle、Xcode、Bazel、React Native）に、専用の GitHub Actionsセットアップガイドが用意されました。Build Hubランナーと GitHub ホスト型ランナーの両方に対応した、実行可能なワークフローの YAML を掲載しています。詳しくは、[GitHub Actionsでの Build Cache for Gradle の設定](/bitrise-build-cache/build-cache-for-gradle/configuring-the-build-cache-for-gradle-in-github-actions)をご覧ください。

### <time dateTime="2026-08-24">2026-08-24</time> Remote Dev EnvironmentsのFAQと、修正されたセッション保持モデル {#2026-08-24-remote-dev-environments-faq-and-a-corrected-session-retention-model}

新しい[Remote Dev EnvironmentsのFAQ](/bitrise-rde/getting-started/rde-faq)では、セッション、ストレージ、接続、認証情報、AIコーディングエージェント、制限に関するよくある質問に回答しています。

セッションの保持に関するドキュメントも修正しました。終了したセッションは、一定期間が過ぎても自動的にクリーンアップされません。セッションの永続ディスクは、ユーザーが削除するまで、またはセッションの作成元のスタックが[スタックの非推奨化と削除に関するポリシー](/bitrise-build-hub/infrastructure/build-stacks/stack-deprecation-and-removal-policy)に基づいて削除されるまで保持されます。また、[主要な概念](/bitrise-rde/getting-started/key-concepts)では、セッションは作成元のスタックに恒久的に紐づけられ、別のスタックへ移動できないことも説明しています。

### <time dateTime="2026-08-14">2026-08-14</time> コラボレーションからRemote Dev Environmentsへのアクセスを管理 {#2026-08-14-manage-remote-dev-environments-access-from-collaboration}

### <time dateTime="2026-08-05">2026-08-05</time> Workflow Editor でモジュール式の YAML を編集 {#2026-08-05-edit-modular-yaml-in-the-workflow-editor}
