:::note[ビルドの保持期間は 200 日間]

アプリの <strong>Builds</strong> ページには、過去 200 日間のビルドのみが表示されます。このページで[特定のビルドを検索する](/bitrise-ci/run-and-analyze-builds/finding-a-specific-build)場合にも、同じ制限が適用されます。この制限は、ほとんどの API 呼び出しにも適用されます。`GET/apps/{app-slug}/builds` エンドポイントおよび関連するエンドポイントが返すのは、過去 200 日間のビルドのみです。

ただし、200 日より前のビルドを取得する方法が 2 つあります。

- 正確なビルド URL がわかっている場合は、そのビルドにアクセスできます。
- `GET/apps/{app-slug}/archived-builds` API エンドポイントを使用できます。[アプリのアーカイブ済みビルドを一覧表示する](/bitrise-ci/api/managing-an-app-s-builds#listing-the-archived-builds-of-an-app)。

:::
