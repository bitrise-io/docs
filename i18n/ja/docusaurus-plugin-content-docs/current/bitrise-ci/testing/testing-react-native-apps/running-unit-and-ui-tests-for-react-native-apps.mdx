Bitrise 上で、React Native アプリのあらゆる種類のテスト (ユニットテスト、統合テスト、コンポーネントテスト) を実行できます。たとえば [Jest](https://jestjs.io/) を使用してすべてのテストを記述し、ビルド中に [npm](https://www.npmjs.com/) または [Yarn](https://yarnpkg.com/) のいずれかで実行できます。

:::tip[E2E テスト]

エンドツーエンドテストには、Detox または Maestro を参照してください: [Bitrise での Detox テストの実行](/bitrise-ci/testing/testing-react-native-apps/running-detox-tests-on-bitrise)、[Bitrise での Maestro テストの実行](/bitrise-ci/testing/running-maestro-tests-on-bitrise)

:::


<Tabs>
  <TabItem value="workflow-editor" label="Workflow Editor">

  1. テストを記述し、React Native プロジェクトに追加します。
  1. Bitrise で、プロジェクトで使用しているパッケージマネージャーに応じて、[<strong>Run npm command</strong>](https://github.com/bitrise-steplib/steps-npm) または [<strong>Run yarn command</strong>](https://github.com/bitrise-community/steps-yarn) <GlossTerm baseform="Step">Step</GlossTerm> を <GlossTerm baseform="Workflow">Workflow</GlossTerm> に追加します。
  1. `test` コマンドを実行するように Step を設定します。

     - Yarn の場合は、<strong>Arguments for running yarn commands</strong> 入力を探して `test` を追加します。

     - npm の場合は、<strong>The npm command with arguments to run</strong> 入力を探して `test` を追加します。

     ![npm-test.png](/img/_paligo/uuid-195577ac-fbba-5fe4-810b-3749e614682c.png)

     どちらの場合も、Step は package の `scripts` オブジェクト内の `test` スクリプトを実行します。

  </TabItem>
  <TabItem value="yaml" label="Configuration YAML">

  1. テストを記述し、React Native プロジェクトに追加します。
  1. プロジェクトで使用しているパッケージマネージャーに応じて、`npm` または `yarn` Step を Workflow に追加します。追加先は <GlossTerm baseform="configuration yaml">Configuration YAML</GlossTerm> ファイルです。
  1. `test` コマンドを実行するように、任意の Step を設定します。どちらの Step でも、`command` 入力を `test` に設定します。

     ```yaml
     empty:
       steps:
         - git-clone: {}
         - npm:
             inputs:
             - command: test
         - yarn@0:
             inputs:
             - command: test
         - deploy-to-bitrise-io: {}
     ```

     どちらの Step も、package の `scripts` オブジェクト内の `test` スクリプトを実行します。

  </TabItem>
</Tabs>


テストを実行して結果を確認します: [テスト結果の表示](/bitrise-ci/testing/test-reports/viewing-test-results)
