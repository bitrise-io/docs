Bitrise CLI は、macOS と Linux 向けの単一のバイナリとして配布されています。curl または Homebrew でダウンロードできます。


## curl を使用した Bitrise CLI のインストール {#installing-the-bitrise-cli-with-curl}

1. bash シェルで次のコマンドを実行します。

   ```bash
   curl -fL https://github.com/bitrise-io/bitrise/releases/latest/download/bitrise-$(uname -s)-$(uname -m) > /usr/local/bin/bitrise
   ```

   Bitrise CLI の最新リリースは、[releases](https://github.com/bitrise-io/bitrise/releases) ページで確認できます。
1. ダウンロードしたバイナリを実行可能にします。

   ```bash
   chmod +x /usr/local/bin/bitrise
   ```
1. `bitrise local setup` を実行します。

   これにより、Bitrise の実行に必要なものがすべてインストールされ、利用可能であるかが確認されます。この手順を省略しても、`bitrise local run` を初めて呼び出す際に CLI がセットアップを実行します。


## Homebrew を使用した Bitrise CLI のインストール {#installing-the-bitrise-cli-with-homebrew}

Mac に Homebrew パッケージマネージャーがインストールされている場合は、それを使用して Bitrise CLI をインストールできます。

1. Mac で `Terminal` アプリを開き、次のコマンドを実行します。

   ```bash
   brew update && brew install bitrise
   ```
1. Bitrise CLI の初回セットアップを実行します。

   ```bash
   bitrise local setup
   ```

   これにより、Bitrise の実行に必要なものがすべてインストールされ、利用可能であるかが確認されます。この手順を省略しても、`bitrise local run` を初めて呼び出す際に CLI がセットアップを実行します。


## Bitrise CLI の更新 {#updating-the-bitrise-cli}

Bitrise CLI の更新は簡単です。Homebrew でインストールした場合でも、GitHub のリリースからインストールした場合でも、手順は同じです。

`bitrise update` を実行するだけです。CLI は毎日 1 回更新を確認し、新しいバージョンが公開されるとすぐに通知します。


## Bitrise CLI の設定 {#configuring-the-bitrise-cli}

CLI は設定を `~/.config/bitrise/cli/config.yml` に保存します。`~/.config` (設定している場合は `$XDG_CONFIG_HOME`) が書き込み可能であることを確認してください。書き込みできない場合、`bitrise local setup` やプラグインのコマンドが失敗することがあります。

設定ファイルや保存できる設定の詳細については、[Configuring the Bitrise CLI](/bitrise-ci/bitrise-cli/configuring-the-bitrise-cli)を参照してください。
