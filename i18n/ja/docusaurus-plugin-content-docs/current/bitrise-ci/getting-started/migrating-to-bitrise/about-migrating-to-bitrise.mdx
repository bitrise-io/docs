モバイルのCI/CDフローを高速化し、専任の人員負担を軽減するためにBitriseへの切り替えを検討している場合は、このガイドが最適です。ここでは、Bitriseの主要な機能と、Bitriseにすばやく慣れる方法を紹介します。

Jenkinsと旧Visual Studio App Center専用の移行ガイドを用意しています。

- [JenkinsからBitriseへの移行](/bitrise-ci/getting-started/migrating-to-bitrise/migrating-from-jenkins-to-bitrise)。
- [App CenterからBitriseへの移行](/bitrise-ci/getting-started/migrating-to-bitrise/migrating-from-app-center-to-bitrise)。

これらのガイドは、他のCI/CDサービスの機能をBitriseと比較することで移行プロセスをサポートし、Bitriseの仕組みに関する重要な概念を紹介することを目的としています。

他のCI/CDやDevOpsプラットフォームからBitriseに移行する場合は、まず主要な概念を理解しておくことをおすすめします。

- [Bitrise platformの主要な概念](/bitrise-platform/getting-started/key-concepts-of-the-bitrise-platform)。
- [Bitriseの主要な概念](/bitrise-ci/getting-started/key-bitrise-concepts)。
- [Release Managementの概念](/release-management/getting-started-with-release-management/release-management-concepts)。
