Bitriseにログインして最初に表示されるのがダッシュボードです。ダッシュボードでは、現在の<GlossTerm baseform="workspace">workspace</GlossTerm>全体でBitrise製品にアクセスできます。次の項目に移動できます：

- <GlossTerm baseform="Project">プロジェクト</GlossTerm>。
- workspaceのCIダッシュボードにある[CIビルド](/bitrise-ci/run-and-analyze-builds/finding-a-specific-build)。
- [Bitrise Build Cache](/bitrise-build-cache)。
- [Release Management](/release-management)。

![dashboard-overview.png](/img/_paligo/uuid-c88d4641-9945-2d84-dd14-ef30fdd68fc4.png)

workspaceの[Insights](/insights)データも確認できます。

## プロジェクトの詳細を確認する {#checking-project-details}

プロジェクトはダッシュボードの左側に表示されます。詳細なデータを確認するには、下向き矢印をクリックしてください。

詳細には、プロジェクトに関連するすべてのBitrise製品の基本情報が表示されます：

- プロジェクトのdefault branchにおける最後のBitrise CIビルドとそのステータス。ダッシュボードには他のブランチのビルド情報は表示されません。
- Build Cacheが最後に使用された日時。
- プロジェクトがRelease Managementに持つconnected appsの数。

![project-card-dashboard.png](/img/_paligo/uuid-2c2a82f9-5bea-aa62-cd49-339aa061c265.png)

これらの各製品には、プロジェクトカードの詳細セクションからアクセスできます。

## ダッシュボードから新規プロジェクトを追加する {#adding-a-new-project-from-the-dashboard}

ダッシュボードの右上には<strong>New project</strong>ボタンがあります。このボタンから、[CI設定で新規プロジェクトを追加](/bitrise-ci/getting-started/adding-a-new-project)できます。

:::note[CIなしのプロジェクト]

CI設定なしでプロジェクトを作成することもできます。Release Managementに新しいアプリを追加し、新規プロジェクトを作成するオプションを選択してください。

:::

この方法で追加したCIプロジェクトも、ダッシュボードに表示されます。また、[Release Management](/release-management)にアクセスして、アプリを追加しプロジェクトにリンクすることもできます。

## Workspaceのインサイト {#workspace-insights}

<strong>Insights for workspace</strong>セクションでは、workspaceのプロジェクトに関する基本的な集計データを確認できます：

- <strong>Successful build time</strong>：workspaceのプロジェクト全体における、成功したBitrise CIビルドの平均ビルド時間。
- <strong>Build failure rate</strong>：workspaceのプロジェクト全体における、失敗したBitrise CIビルドの割合。
- <strong>Cache hit rate (P50)</strong>：Bitrise Build Cacheによって正常に処理されたデータリクエストの割合。
- <strong>Command error rate</strong>：失敗したコマンドの割合。

![workspace-insights.png](/img/_paligo/uuid-b15d9482-748d-bb6a-1aaa-c1153ed8392b.png)

詳細なメトリクスを確認し、データに基づく可視性を得るには、[Insights](/insights)をご覧ください。
