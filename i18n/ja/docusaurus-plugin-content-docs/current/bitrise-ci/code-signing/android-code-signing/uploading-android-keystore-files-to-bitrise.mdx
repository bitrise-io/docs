Androidアプリにデジタル署名し、Google Play Storeで配布できるようにするには、[キーストアファイル](https://developer.android.com/training/articles/keystore)が必要です。キーストアファイルは任意のアクセス可能な場所に保存でき、<GlossTerm baseform="step">Steps</GlossTerm>で使用できますが、最も簡単で便利な方法は、直接Bitriseにアップロードすることです。

手順は次のとおりです。

:::note[複数のファイル]

Bitriseに複数のキーストアファイルをアップロードできます。その場合、それぞれ異なるURLを持つことになるため、Stepsが正しいものを使用していることを確認してください。

:::

1. <Partial_GettingToTheProjectSettingsPage />
1. 左側で<strong>Code signing</strong>を選択し、<strong>Android</strong>タブに移動します。
1. <strong>Add keystore file</strong>ボタンをクリックします。
1. ダイアログボックスで、キーストアファイルをフィールドにドラッグ&ドロップするか、フィールドをクリックしてファイルを参照します。

   キーストアファイルをアップロードすると、keystore URLが自動的に生成されます。Bitriseは、ファイルのダウンロードURL(有効期限付きの読み取り専用ダウンロードURL)を値として環境変数(`$BITRISEIO_ANDROID_KEYSTORE_URL`)に割り当てます。[Android Sign](https://github.com/bitrise-steplib/steps-sign-apk)Stepが自動的にダウンロードするため、手動でダウンロードする必要はありません。
1. 表示された3つの入力フィールドに、Androidのキーストア認証情報を入力します。

   - <strong>Keystore password</strong>
   - <strong>Key alias</strong>
   - <strong>Private key password</strong>

   ![Add keystore fileダイアログ](/img/code-signing/android-code-signing/2026-07-14-add-android-keystore-file.png)

   パスワードとエイリアスは、キーの作成時に設定できます: [アップロードキーとキーストアの生成](https://developer.android.com/studio/publish/app-signing#generate-key)。
1. <strong>Continue</strong>をクリックします。ファイルのアップロードが完了すると、次のページに、ビルドで使用できるようになる新しいEnvironment Variablesが表示されます。

   - `$BITRISEIO_ANDROID_KEYSTORE_ALIAS`
   - `$BITRISEIO_ANDROID_KEYSTORE_PASSWORD`
   - `$BITRISEIO_ANDROID_KEYSTORE_PRIVATE_KEY_PASSWORD`
   - `$BITRISEIO_ANDROID_KEYSTORE_URL`

   最初のファイルの後に追加のキーストアファイルをアップロードするたびに、新しいファイルに対応する環境変数のフィールド名の前に番号が挿入されます。例: `$BITRISEIO_ANDROID_KEYSTORE_1_ALIAS`、`$BITRISEIO_ANDROID_KEYSTORE_2_ALIAS`。
1. キーストアのデータを確認し、正しいファイルをアップロードしたことを確かめてください。
1. 必要に応じて、キーストアファイル用のカスタムIDを設定できます: <strong>Custom keystore ID</strong>フィールドに、キーストアファイルの識別に使用したいIDを追加します。

   このIDは、キーストア関連の環境変数の一意の部分を置き換えます。例えば、IDを`My_Best_App`に設定した場合、URLは`$BITRISEIO_ANDROID_KEYSTORE_My_Best_App_URL`になります。
1. <strong>Addキーストア</strong>をクリックします。
