プロジェクトのcode signing設定は、[Android Studio](https://developer.android.com/studio/)で指定できます。キーストアファイル、key alias、キーのパスワードが必要です。手順を開始する前に準備しておいてください。

1. Android Studioを開きます。
1. <strong>Project navigator</strong>に移動します。
1. プロジェクトを選択し、<strong>Module Settings</strong>を開きます。
1. <strong>Module</strong>からモジュールを選択します。
1. <strong>Signing</strong>タブで、署名情報を入力します。この例では、以下の値を使用しています。

   - 名前: `release`
   - Key alias: `MyAndroidKey`
   - キーのパスワード: `***`
   - ストアファイル: `/path/to/my/keystore.jks`
   - ストアのパスワード: `***`

署名情報を入力すると、モジュールの`build.gradle`ファイルに`signingConfigs`ブロックが作成されます。Bitriseでは、<strong>Android Build</strong>または<strong>Gradle Runner</strong>のStepのいずれかを使ってアプリをビルドするだけです。
