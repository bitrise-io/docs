Android code signingには、キーストアファイルが必要です。Androidアプリのキーストアファイルの保存場所は、`build.gradle`ファイルで定義できます。[GradleにおけるAndroid code signing](/bitrise-ci/code-signing/android-code-signing/android-code-signing-in-gradle)。キーストアファイルをBitriseにアップロードし、<strong>File Downloader</strong> Stepを使用してBitriseからキーストアファイルをダウンロードして、`build.gradle`ファイルで定義した場所に配置できます。

:::note[Android Sign Step]

<strong>Android Sign</strong> Stepを使用してアプリに署名する場合、キーストアファイルをダウンロードする必要はありません。Stepがファイルを検出します。[Android Sign Stepを使用したAndroid code signing](/bitrise-ci/code-signing/android-code-signing/android-code-signing-using-the-android-sign-step)。

:::

1. <strong>File Downloader</strong> StepをWorkflowに追加します。Stepは、<strong>Gradle Runner</strong>など、キーストアファイルを必要とするStepより前に追加する必要があります。
1. 次の2つの入力フィールドを入力します。

   - <strong>Download ソースURL</strong>: [Bitriseにファイルをアップロード](/bitrise-ci/code-signing/android-code-signing/uploading-android-keystore-files-to-bitrise))際に取得する、生成されたkeystore URLを設定します。
   - <strong>Download 保存先パス</strong>: キーストアファイルの場所を相対パスとして設定します。このパスは、`build.gradle`ファイルですでに定義されているキーストアパスと同じにする必要があります（例: `$HOME/keystores/project_release.keystore`）。
1. ファイルのダウンロードStepの直後に<strong>Gradle Runner</strong> Stepを追加します。

なお、`build.gradle`ファイルで指定したのと同じ場所にキーストアファイルをダウンロードするためのStepsを正しく追加できていれば、ワークフローに<strong>Android Sign</strong> Stepは必要ありません。<strong>Gradle Runner</strong> Stepがプロジェクトの署名とアセンブルを行います。
