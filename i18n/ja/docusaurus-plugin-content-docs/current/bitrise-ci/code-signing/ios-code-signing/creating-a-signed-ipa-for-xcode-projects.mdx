Bitriseを使用すると、Xcodeプロジェクト用に署名済みのIPAファイルを簡単に作成できます。

- You haveBitriseで[Apple service connection](/bitrise-platform/integrations/apple-services-connection/about-connecting-to-apple-services)を設定済み。
- [code signingファイルが正しく管理されている](/bitrise-ci/code-signing/ios-code-signing/creating-a-signed-ipa-for-xcode-projects)。
- <strong>Xcode Archive & Export for iOS</strong> Stepの関連する入力を設定済み。

<Partial_IMPORTANTUploadTheDistributionANDTheDevelopmentSigningCertificates />

準備ができたら、<GlossTerm baseform="Workflow">Workflow</GlossTerm>でIPAエクスポートの設定に進んでください。


<Tabs>
  <TabItem value="workflow-editor" label="Workflow Editor">

  1. 必要な[code signingファイルが収集およびアップロードされている](/bitrise-ci/code-signing/ios-code-signing/managing-ios-code-signing-files---automatic-provisioning#uploading-ios-code-signing-certificates-to-bitrise)。
  1. [<strong>Xcode Archive & Export for iOS</strong>](https://github.com/bitrise-steplib/steps-xcode-archive) StepがWorkflowにあることを確認してください。
  1. Stepの<strong>Distribution method</strong>入力を設定します。

     ![xcode-archive.png](/img/_paligo/uuid-fced107c-9b69-e5af-1472-4d96fbada364.png)

     オプションは次のとおりです。

     - `app-store`: アプリをApp Storeにデプロイする場合はこれを選択します。Distribution証明書とApp Store用のプロビジョニングプロファイルが必要です。
     - `ad-hoc`: アプリをアドホックテスターにデプロイする場合はこれを選択します。Distribution証明書とAd Hoc用のプロビジョニングプロファイルが必要です。
     - `enterprise`: AppleのEnterpriseアカウントを持っていて、それを使用してアプリを配布したい場合はこれを選択します。
     - `development`: 社内テスト用にはこれを選択します。Developer証明書とDevelopment用のプロビジョニングプロファイルが必要です。
  1. <strong>Automatic code signing</strong>入力に、code signingに使用するApple service connectionを設定します。使用できるオプションは次のとおりです。

     - automatic code signingを使用しない場合は`off`。
     - [if you use API key authorization](/bitrise-platform/integrations/apple-services-connection/about-connecting-to-apple-services)場合は`api-key`。
     - [if you use Apple ID authorization](/bitrise-platform/integrations/apple-services-connection/about-connecting-to-apple-services)場合は`apple-id`。
  1. Workflowを保存し、新しいビルドを開始します。

  </TabItem>
  <TabItem value="yaml" label="Configuration YAML">

  1. ビルドに必要な[code signingファイルがすべて利用可能である](/bitrise-ci/code-signing/ios-code-signing/creating-a-signed-ipa-for-xcode-projects)ことを確認してください。
  1. アプリの`bitrise.yml`ファイルを開きます。
  1. Workflowに`xcode-archive` Stepがあることを確認してください。

     ```yaml
     my-workflow:
       steps:
       - xcode-archive:
           inputs:
     ```
  1. `distribution_method`入力を正しい値に設定します。使用できるオプションは次のとおりです。

     - `app-store`: アプリをApp Storeにデプロイする場合はこれを選択します。Distribution証明書とApp Store用のプロビジョニングプロファイルが必要です。
     - `ad-hoc`: アプリをアドホックテスターにデプロイする場合はこれを選択します。Distribution証明書とAd Hoc用のプロビジョニングプロファイルが必要です。
     - `enterprise`: AppleのEnterpriseアカウントを持っていて、それを使用してアプリを配布したい場合はこれを選択します。
     - `development`: 社内テスト用にはこれを選択します。Developer証明書とDevelopment用のプロビジョニングプロファイルが必要です。

     ```yaml
     my-workflow:
       steps:
       - xcode-archive:
           inputs:
           - distribution_method: development
     ```
  1. `automatic_code_signing`入力に、code signingに使用するApple service connectionを設定します。使用できるオプションは次のとおりです。

     - automatic code signingを行わない場合は`off`。
     - [if you use API key authorization](/bitrise-platform/integrations/apple-services-connection/about-connecting-to-apple-services)場合は`api-key`。
     - [if you use Apple ID authorization](/bitrise-platform/integrations/apple-services-connection/about-connecting-to-apple-services)場合は`apple-id`。

     ```yaml
     my-workflow:
       steps:
       - xcode-archive:
           inputs:
           - automatic_code_signing: api-key
           - distribution_method: development
     ```

以上です。Xcodeは、プロジェクトのBundle IDとTeam IDの設定、および設定したエクスポート方法に基づいて、適切な署名ファイルを自動的に選択します。


## 別のチームのcode signingファイルでIPAファイルに署名する

別のチームのcode signingファイルを使用してIPAファイルに署名したい場合があります。例:

- 社内ビルドには自社のcode signingファイルを使用するが、App Store配布にはクライアントのcode signingファイルを使用する場合。
- automatic code signingにApple IDを使用していてApple IDが複数のチームに属している場合は、「The Developer Portal team to use for this export」入力を使用して、automatic code signingアセット管理に使用するチームを指定します。

その場合は、次の手順に従います。

1. 新しい開発チームの正しいcode signingファイルがBitriseにアップロードされていることを確認します。
1. <strong>Distribution method</strong>に加えて、「The Developer Portal team to use for this export」オプションも設定します。
1. <strong>Distribution method</strong>を設定します。
