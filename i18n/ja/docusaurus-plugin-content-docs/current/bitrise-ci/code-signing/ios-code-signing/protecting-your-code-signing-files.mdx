code signingファイルを<strong>Protected</strong>モードに設定できます。この設定を行うと、[bitrise.io](https://www.bitrise.io)アカウントからファイルをダウンロードできなくなります。ビルドではこれらの保護されたファイルを使用できますが、誰もその内容を表示することはできず、上書きする方法もありません。ファイルを削除して新しいファイルをアップロードすることのみ可能です。

1. <Partial_GettingToTheProjectSettingsPage />
1. 左側のメニューから<strong>Code signing</strong>を選択します。
1. make protectedしたいファイルを見つけ、右側にある省略記号ボタンをクリックしてドロップダウンメニューを開きます。
1. <strong>Make protected</strong>オプションを選択します。

   確認すると、この変更は元に戻せないことを警告するダイアログボックスが表示されます。変更を個別に保存する必要はありません。

完了すると、ファイルのドロップダウンメニューで選択できるオプションは<strong>Delete</strong>のみになります。
