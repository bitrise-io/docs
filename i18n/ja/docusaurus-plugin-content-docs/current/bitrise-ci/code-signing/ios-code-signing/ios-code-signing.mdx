新しいデバイスにiOSアプリをインストールする場合や、[App Storeでアプリを配布](/bitrise-ci/deploying/ios-deployment/deploying-an-ios-app-to-app-store-connect)する場合は、code signingファイルを準備する必要があります。iOSプロジェクトのcode signingには、次のものが必要です。

- Appleが発行したSigning certificate。
- プロジェクト(チームID、バンドルIDなど)に対応するプロビジョニングプロファイルファイル。

:::note[ビルドの失敗]

ビルドが失敗し、code signingに問題があると思われる場合は、[トラブルシューティングページ](/bitrise-ci/code-signing/ios-code-signing/troubleshooting-ios-code-signing)をご確認ください。

:::

| 方法 | 仕組み | 使用するタイミング |

| [自動管理のプロビジョニングプロファイル(推奨)](/bitrise-ci/code-signing/ios-code-signing/managing-ios-code-signing-files---automatic-provisioning) | Bitriseに対してコードsigning certificateをアップロードし、[Apple Service connection](/bitrise-platform/integrations/apple-services-connection/about-connecting-to-apple-services)を確立するだけで済みます(App Store ConnectのAPIキー、またはApple ID経由)。Bitriseがプロビジョニングプロファイルのダウンロード、作成、更新を行い、App IDとテストデバイスの登録も自動的に処理します。 | これはほとんどのアプリにおすすめのオプションです。このオプションを使用すると、プロビジョニングプロファイルの管理がシームレスになり、Workflowsの設定がずっと簡単になります。 |
| [手動管理のプロビジョニングプロファイル](/bitrise-ci/code-signing/ios-code-signing/managing-ios-code-signing-files---manual-provisioning) | コードsigning certificateとプロビジョニングプロファイルをBitriseにアップロードし、iOSプロジェクトに合わせてプロビジョニングプロファイルを最新の状態に保つ必要があります。 | 次の場合はこのオプションを選択してください:<ul><li>App Store ConnectのAPIキーまたはApple IDをBitriseに接続できない場合。</li><li>code signingファイルを独自の方法で保存または管理している場合。</li><li>複数のAppleデベロッパーアカウントのcode signingファイルを使用したい場合。</li></ul> |
