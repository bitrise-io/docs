Bitriseビルド中にリッチなHTMLコンテンツ(コードカバレッジレポートやパフォーマンスレポートなど)を生成した場合、別のツールでレポートをダウンロードして表示する必要はありません。BitriseUIで直接コンテンツを確認できます。また、すべての要素をHTMLファイルに埋め込む必要もありません。Bitriseがすべての画像、CSSファイル、Javascriptファイルを解析し、意図したとおりに全体のコンテンツを表示します。

![after.gif](/img/_paligo/uuid-ab2808a9-e648-a309-8e76-6aa126e8047c.gif)

BitriseでHTMLレポートを表示するには:

1. ビルド中にHTMLレポートを生成します。
1. BITRISE_HTML_REPORT_DIRディレクトリに、わかりやすい名前でサブフォルダーを作成します。このフォルダー名が、UI上でのレポートのタイトルになります。

   BITRISE_HTML_REPORT_DIRは、BitriseがHTML reportsを検索するディレクトリを指す環境変数です。
1. 生成したレポートがサブフォルダーにデプロイされていることを確認してください。

   :::tip[複数のレポート]

   複数のサブフォルダーに複数のレポートを生成できます。各レポートには`index.html`ファイルが必要です。

   :::
1. ビルドを実行します。
1. ビルドが完了したら、ビルドのページに移動し、<strong>Artifacts</strong>タブを選択します。<strong>HTML reports</strong>セクションにレポートが表示されます。

   :::note[7日間の制限]

   各HTMLレポートは7日間利用できます。

   :::
