AIアナライザーが、CIビルドが失敗した理由の要約を提供し、ビルドページ上でその場で修正案を提案します。

![Bitrise AI Failure details、Reason、Suggested solutionを含むパネル](/img/run-and-analyze-builds/2026-07-14-bitrise-ai-failure-details-panel.png)

この機能を有効にするには:

:::note[AIの無効化]

AI機能をまったく使用したくない場合は、<GlossTerm baseform="workspace">Workspace</GlossTerm>の設定ページにあるAI Settingsメニューからすべて無効にできます: [BitriseでのAI機能の有効化](/bitrise-platform/ai/enabling-ai-features-on-bitrise)

:::

1. <Partial_GettingToTheProjectSettingsPage />
1. 左側で<strong>Bitrise AI</strong>を選択します。
1. <strong>Summary</strong>を見つけて、オンに切り替えます。
