ビルドの<strong>Details</strong>タブにアクセスすると、特定のビルドに関する追加の詳細を確認できます。詳細には、ビルドがトリガーされた日時、開始および終了した日時、agent versionやホスト名などのインフラストラクチャの詳細、パラメータ、さらには起動に使用された正確なコマンドまでが含まれます。

詳細を確認するには:

1. <Partial_AccessingBuildsTabAndSelectingABuild />
1. <strong>Details</strong>タブを選択します。

   ![details-tab.png](/img/_paligo/uuid-6b6e5440-9a6c-5fec-0970-63b75c992d1a.png)

また、ビルドの実行時の動作について詳しい情報を得たい場合や、パフォーマンスに関連する失敗の診断に役立てたい場合は、<strong>VM monitoring</strong>タブを確認してください。

VM monitoringには、ビルドのライフタイム全体にわたるCPU、メモリ、ディスクの使用状況が表示されます。ビルドのタイムラインと時間軸が揃っているため、リソースの急増を特定のステップ、ログ、または長時間実行される操作と関連付けることができます。
