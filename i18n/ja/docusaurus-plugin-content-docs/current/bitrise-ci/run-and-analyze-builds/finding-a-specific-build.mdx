プロジェクトに[bitrise.io](https://www.bitrise.io)上で複数のビルドがある場合、さまざまなオプションを使用して特定のビルドを検索できます。方法は次のとおりです。

1. Bitriseでプロジェクトを開きます。
1. プロジェクトの<strong>Builds</strong>ページでは、ビルドの一覧の上にあるフィルターオプションと検索フィールドを確認できます。次のオプションがあります。

   - 検索フィールドにビルド番号またはコミットメッセージを入力して、ビルドを検索します。

     ![builds-search.png](/img/_paligo/uuid-5447e1bd-56ac-3503-4473-18f9784a64bf.png)
   - 日付フィルタードロップダウンメニューからフィルターを選択すると、特定の日付範囲内に実行されたビルドを検索できます。
   - ブランチフィルタードロップダウンメニューからフィルターを選択すると、特定のブランチで実行されたビルドを検索できます。
   - <GlossTerm baseform="workflow">Workflow</GlossTerm>/<GlossTerm baseform="pipeline">Pipeline</GlossTerm>フィルタードロップダウンメニューからフィルターを選択すると、特定のWorkflowまたはPipelineで実行されたビルドを検索できます。
   - ステータスフィルタードロップダウンメニューからフィルターを選択すると、特定のステータスのビルドを検索できます。
   - <GlossTerm baseform="trigger">トリガー</GlossTerm>ドロップダウンメニューからフィルターを選択すると、プッシュ、プルリクエスト、タグのいずれかのトリガーオプションによってトリガーされたビルドを検索できます。
   - アーティファクトタイプフィルタードロップダウンメニューからフィルターを選択すると、特定のタイプのアーティファクトを生成したビルドを検索できます。
