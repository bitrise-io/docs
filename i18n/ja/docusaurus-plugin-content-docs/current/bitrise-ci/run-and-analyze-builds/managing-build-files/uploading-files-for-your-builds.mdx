ビルドの実行にファイルが必要な場合は、<strong>Project settings</strong>ページのBitriseにアップロードできます。どのファイル形式にも対応しており、unique IDを指定してファイルをアップロードするだけです。

ファイルをアップロードすると、[環境変数（Env Var）](/bitrise-ci/configure-builds/environment-variables)として保存されます。このEnv Varを使用すると、ビルドでファイルにアクセスして利用できます。また、ファイルは次のことも可能です。

- Bitriseの対象アプリのチームで[管理者またはオーナーの役割](/bitrise-platform/projects/roles-and-permissions-for-bitrise-ci)を持つユーザーであれば誰でもダウンロードできます。これを防ぐには、[アップロードしたファイルの保護](#protecting-your-uploaded-files)を参照してください。
- プルリクエストのビルドに公開されます。

:::important[ファイル制限]

アップロードできるサイズとファイル数には、次のような制限があります。

- 5 MBを超えるファイルはアップロードできません。
- 同時に保存できるファイルは、合計100個までです。それ以上アップロードする場合は、ストレージ内のファイルを削除する必要があります。

:::

ファイルをアップロードするには、次の手順を実行します。

1. <Partial_GettingToTheProjectSettingsPage />
1. 左側で、<strong>Files</strong>を選択します。
1. <strong>Add file</strong>をクリックします。
1. ダイアログボックスの<strong>File Storage ID</strong>入力フィールドにunique IDを入力します。

   unique IDは、Bitriseが[環境変数](/bitrise-ci/configure-builds/environment-variables)として保存する、生成されたダウンロードURLの一部になります。

   ![Project settingsのFilesページにあるAdd fileダイアログ](/img/run-and-analyze-builds/2026-07-14-add-file-dialog.png)
1. ファイルをアップロードします。次の2つの方法があります。

   - <strong>Select a file to upload</strong>セクション内の任意の場所をクリックし、コンピューター上のファイルを選択します。
   - <strong>Select a file to upload</strong>セクションにファイルをドラッグ&ドロップします。

   ファイルサイズは5 MBを超えないようにしてください。


## アップロードしたファイルの保護

Bitriseにファイルをアップロードすると、アップロードしたファイルをProtectedモードに設定できます。これにより、アカウントからファイルをダウンロードしたり内容を確認したりすることは誰にもできなくなりますが、ビルドでは引き続き使用できます。Bitriseは、アップロードしたファイルに紐づく環境変数を[シークレット](/bitrise-ci/configure-builds/secrets)として扱います。

1. Bitriseで、<strong>Admin</strong>[プロジェクトでの役割](/bitrise-platform/projects/roles-and-permissions-for-bitrise-ci)を持つユーザーでプロジェクトを開きます。
1. プロジェクトのメインページで、<strong>Project settings</strong>ボタンをクリックします。

   ![project-settings-button.png](/img/_paligo/uuid-14defaa4-472c-2d09-84df-145dc3aef4f5.png)
1. 左側で、<strong>Files</strong>を選択します。
1. ファイル名の横にある水平三点リーダーボタンをクリックし、<strong>Make protected</strong>を選択します。
1. ダイアログボックスで<strong>Make it protected</strong>をクリックします。
