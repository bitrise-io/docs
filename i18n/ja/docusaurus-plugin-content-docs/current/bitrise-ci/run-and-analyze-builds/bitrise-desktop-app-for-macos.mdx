BitriseデスクトップアプリはネイティブのmacOSメニューバーアプリで、作業中のブランチのビルドのライブステータスを表示するため、ブラウザタブを開いてビルドステータスを確認する必要がありません。

:::note
BitriseデスクトップアプリはmacOS専用です。
:::

## アプリのインストール {#installing-the-app}

Bitriseデスクトップアプリを使用するには、macOS 14.6以降と、少なくとも1つの<GlossTerm baseform="workspace">workspace</GlossTerm>とプロジェクトにアクセスできるBitriseアカウントが必要です。ローカルフォルダを追跡する場合は、リポジトリのローカルチェックアウトも必要です。

1. [GitHubから`Bitrise.dmg`ファイル](https://github.com/bitrise-io/bitrise-desktop-app/releases/latest/download/Bitrise.dmg)をダウンロードします。
1. `.dmg`を開き、Bitriseを<strong>Applications</strong>フォルダにドラッグします。
1. <strong>Applications</strong>からBitriseを起動します。

アプリは画面上部のメニューバーにアイコンとして表示されます。初回起動時は、サインインするまで未設定の状態が表示されます。

## ログイン時に起動する {#launching-at-login}

<strong>Settings</strong>の<strong>General</strong>ペインで<strong>Launch at login</strong>をオンにすると、Macにログインするたびにアプリが自動的に起動し、アプリを手動で開かなくてもメニューバーにビルドステータスが表示されます。

## サインインする {#signing-in}

1. メニューバーのBitriseアイコンをクリックします。
1. <strong>Connect to Bitrise</strong>をクリックします。アプリがブラウザを開いてサインインします。
1. ブラウザでサインインを完了し、アプリに戻ります。

サインイン後、アプリはアクセストークンをmacOSキーチェーンに保存し、自動的に更新します。サインインしたハンドルはbuild listヘッダーと<strong>Settings</strong>に表示されます。

## workspaceを選択する {#choosing-a-workspace}

選択したworkspaceは、ビルド、フィルタ、ローカルフォルダのマッチングなど、アプリが表示するすべての範囲を決定します。

- workspaceに1つだけ所属している場合は、自動的に選択されます。
- 複数に所属している場合は、workspaceピッカーから1つを選択します。
- どれにも所属していない場合、アプリはアクセスを取得するためにBitriseのWebUIを案内します。

<strong>Account</strong>ペインの<strong>Settings</strong>から、後でworkspaceを切り替えられます。

## 監視するプロジェクトを追加する {#adding-projects-to-watch}

build listは最初は空です。Settingsの<strong>Projects</strong>ペインで1つ以上のプロジェクトをサブスクライブすることで内容を追加できます。プロジェクトを追加する方法は2つあります。

- <strong>プロジェクトに直接サブスクライブする</strong>: これはプロジェクトのヘルスウォッチです。ローカルでチェックアウトしている内容に関係なく、プロジェクトを監視するために使用します。たとえば、`main`がグリーンのままであることを確認する場合などです。
- <strong>ローカルフォルダを追跡する</strong>: アプリは、gitリモートのURLを使用して各リポジトリをそのBitriseprojectに自動的に照合するため、プロジェクトを手動で選択する必要はありません。その後、現在チェックアウトしているブランチのビルドを追跡し、ローカルでブランチを切り替えても同期を維持します。

<Tabs>
<TabItem value="subscribing-to-a-project-directly" label="Subscribing directly" default>

1. <strong>Settings</strong>を開き、<strong>Projects</strong>ペインに移動します。
1. 監視するプロジェクトをworkspaceから選択します。

</TabItem>
<TabItem value="tracking-a-local-folder" label="Tracking a local folder">

1. <strong>Projects</strong>ペインで、ローカルフォルダを追加するオプションを選択し、フォルダを参照します。
1. アプリはフォルダとそのサブフォルダをスキャンしてgitリポジトリを検出し、見つかったものを一覧表示します。
1. 追跡したいリポジトリを選択します。

</TabItem>
</Tabs>

:::note
Bitriseにビルドがないブランチでは、空のリストが表示されます。まだビルドが実行されていない新しいブランチに切り替えた場合、これは想定どおりの動作です。
:::

## フィルタと通知を設定する {#setting-filters-and-notifications}

監視している各プロジェクトには独自の設定があり、<strong>Projects</strong>ペインの詳細ビューで編集できます。

- <strong>Branches</strong>: プロジェクトが追跡するブランチを選択します。ローカルフォルダの場合、これはチェックアウトと自動的に同期されます。
- <strong>Notifications</strong>: 各プロジェクトをオフ、失敗時のみ、またはすべての完了時のいずれかに設定します。Notificationsペインのグローバルな<strong>Allow通知</strong>スイッチで、すべてのバナーのオン/オフを切り替えられます。

## build listのグループ化 {#grouping-the-build-list}

<strong>Settings</strong>の<strong>Builds</strong>ペインで、build listの整理方法を選択します。

- <strong>By project</strong>: ビルドをプロジェクトごとにグループ化し、プロジェクトごとに1つのセクションを表示します。
- <strong>By date</strong>: すべてのプロジェクトのビルドを新しい順に一覧表示し、それぞれにプロジェクト名のラベルを付けます。

プロジェクトは<strong>dual-tracked</strong>（二重追跡）になる場合があります。これは、プロジェクトに直接サブスクライブしていると同時に、同じリポジトリに一致するローカルフォルダも追跡している状態です。dual-trackedのプロジェクトについては、表示方法を選択できます。

- <strong>Separate lists per source</strong>: プロジェクトに対して2つのセクションを表示し、ソースごとに1つずつ、それぞれに出所を示すアイコンでラベルを付けます。
- <strong>Merged into one list</strong>: 両方のソースのビルドを、そのプロジェクトの単一のリストにまとめます。

## ビルドステータスを確認する {#reading-build-status}

メニューバーのアイコンは、監視しているプロジェクト全体で最後に開始されたビルドの状態を反映します。

- <strong>Passed</strong>: 最新のビルドが成功しました。
- <strong>Failed</strong>: 最新のビルドが失敗しました。
- <strong>Running</strong>: ビルドが実行中です。
- <strong>Aborted</strong>: 最新のビルドが中止されました。

アイコンをクリックするとbuild listが開きます。各ビルドはカードとして表示され、ステータスとコミットメッセージ、ブランチまたはタグ、<GlossTerm baseform="workflow">Workflow</GlossTerm>または<GlossTerm baseform="pipeline">Pipeline</GlossTerm>の名前、開始時刻、所要時間、ビルド番号が示されます。カードから、ワンクリックでビルド、プルリクエスト、またはコミットをBitrise上で開けます。

Bitriseが追跡するビルドステータスの全一覧については、[ビルドステータス](/bitrise-ci/run-and-analyze-builds/build-statuses)をご覧ください。

## アプリを最新の状態に保つ {#keeping-the-app-updated}

アプリは定期的に新しいリリースを確認するほか、<strong>About</strong>ペインの<strong>Settings</strong>から<strong>Check Now</strong>を使用してオンデマンドで確認することもできます。

更新が利用可能な場合は、新しい`.dmg`をダウンロードできます。初回インストール時と同じ方法で、アプリを<strong>Applications</strong>にドラッグしてインストールします。

## トラブルシューティング {#troubleshooting}

| 表示される内容 | 意味と対処方法 |
| --- | --- |
| ブランチのbuild listが空 | そのブランチにはBitriseにビルドがありません。ビルド履歴のあるブランチに切り替えるか、ビルドをトリガーしてください。 |
| フォルダに対応するプロジェクトが見つからない | フォルダのgitリモートが、選択したworkspace内のプロジェクトと一致しません。リモートとworkspaceを確認してください。 |
| リモートがこのworkspaceの外部にある | リポジトリが別のworkspaceに属しています。Accountペインでworkspaceを切り替えてください。 |
| Detached HEADまたはリモートなし | アプリが追跡するブランチを特定できません。upstreamリモートが設定されたブランチをチェックアウトしてください。 |
| サインインエラー | 認証に失敗したか、有効期限が切れています。メニューバーから再度サインインしてください。 |
