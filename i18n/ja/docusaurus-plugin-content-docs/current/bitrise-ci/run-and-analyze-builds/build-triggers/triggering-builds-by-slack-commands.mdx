Slackアプリで[Slash Commands](https://api.slack.com/interactivity/slash-commands)を設定することで、Slackの<GlossTerm baseform="workspace">workspace</GlossTerm>からBitriseビルドを<GlossTerm baseform="trigger">トリガー</GlossTerm>できます。Bitriseアプリごとに専用のSlash Commandが必要です。

1. SlackアプリにBitrise webhook URLを登録します。

   :::note[Slackアプリの再インストール]

   新しいSlash Commandを作成すると、Slackアプリの再インストールが必要になる場合があります。

   :::
1. 少なくとも2つの必須パラメーターである`workflow`と`branch`を追加して、コマンドを使用します。

   ```text
   /build-myapp workflow: run_tests|branch: main
   ```

   コマンド呼び出しでは、コミットハッシュや、ビルドに渡したい任意の[Environment Variables](/bitrise-ci/configure-builds/environment-variables)など、さまざまなパラメーターを設定できます。使用可能なパラメーターの詳細については、[Slackコマンドの利用可能なパラメーター](/bitrise-ci/run-and-analyze-builds/build-triggers/triggering-builds-by-slack-commands#available-parameters-for-your-slack-command)を参照してください。


## Slackコマンドの利用可能なパラメーター {#available-parameters-for-your-slack-command}

Slack経由でビルドをトリガーするには、`key:value|key:value`形式のパラメーターでSlash Commandを変更する必要があります。

少なくとも1つのパラメーターを指定する必要があります:

- `b`または`branch`。例: `branch: main`
- `w`または`workflow`。例: `workflow: run_tests`

コマンドでブランチまたは<GlossTerm baseform="workflow">Workflow</GlossTerm>のいずれも指定しない場合、コマンドは失敗します。

オプションのパラメーターを使用すると、ビルドをさらに設定できます:

- `t`または`tag`。例: `branch: main|tag: v1.0`
- `c`または`commit`。例: `workflow: run_tests|commit: eee55509f16e7715bdb43308bb55e8736da4e21e`
- `m`または`message`。例: `branch: main|message: ship it!!`

また、次の形式でenvironment variablesを送信することもでき、Workflowで使用できるようになります: `env[KEY1]:value1|ENV[KEY2]:value2`

<strong>すべてのパラメーターを含むSlackコマンド</strong>

この例には、必須およびオプションのすべてのパラメーターが含まれています。特定のコミットをビルドし、2つのEnvironment Variablesをビルドに渡します:

- 値が`iPhone 6S`の$DEVICE_NAME。
- 値が`82667b4079914d4aabed9c216620da5dedab630a`の$DEVICE_UDID

```text
/build-myapp workflow: run_tests|b: main|tag: v1.0|commit:eee55509f16e7715bdb43308bb55e8736da4e21e|m: start my build!|ENV[DEVICE_NAME]:iPhone 6S|ENV[DEVICE_UDID]:82667b4079914d4aabed9c216620da5dedab630a
```
