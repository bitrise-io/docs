以下は、Bitriseチームが管理しているオープンソースツールの一覧です。

| 名前 | 種類 | 説明 | リンク |
| --- | --- | --- | --- |
| <strong>Bitrise CLI</strong> | CLI | [bitrise.io](https://www.bitrise.io)でビルドを実行するために使用されるBitrise CLIです。ローカルでビルドを実行する際にも使用できます。 | [https://github.com/bitrise-io/bitrise](https://github.com/bitrise-io/bitrise) |
| <strong>stepman</strong> | CLIツール | Step Libraryの管理に使用されるStep Collection Managerです。 | [https://github.com/bitrise-io/stepman](https://github.com/bitrise-io/stepman) |
| <strong>envman</strong> | CLIツール | ビルド中に[Environment Variables](/bitrise-ci/configure-builds/environment-variables)を分離および管理するためにBitrise CLIが使用するEnvironment Variable Managerです。Bitrise CLIとは独立して使用することもできます。 | [https://github.com/bitrise-io/envman](https://github.com/bitrise-io/envman) |
| <strong>init</strong> | CLIコアプラグイン | このプラグインを使用すると、プロジェクトスキャナーがローカルでプロジェクトの種類を検出し、Bitriseの設定を生成できます。 | [https://github.com/bitrise-io/bitrise-plugins-init.git](https://github.com/bitrise-io/bitrise-plugins-init.git) |
| <strong>step</strong> | CLIコアプラグイン | このプラグインを使用すると、Stepの情報の一覧表示や取得、Stepsの作成を行えます。 | [https://github.com/bitrise-io/bitrise-plugins-step](https://github.com/bitrise-io/bitrise-plugins-step) |
| <strong>workflow-editor</strong> | CLIコアプラグイン | このプラグインを使用すると、オフラインのWorkflow Editorでビルドの`bitrise.yml`設定をローカルで構成できます。 | [https://github.com/bitrise-io/bitrise-workflow-editor.git](https://github.com/bitrise-io/bitrise-workflow-editor.git) |
| <strong>bitrise-plugin-io</strong> | CLIコアプラグイン | このプラグインを使用すると、ターミナル/コマンドラインから直接[bitrise.io](https://www.bitrise.io)上のアプリを管理できます。 | [https://github.com/bitrise-io/bitrise-plugins-io](https://github.com/bitrise-io/bitrise-plugins-io) |
| <strong>bitrise webhooks</strong> | Webhookプロセッサー | この[Bitrise Webhooksプロセッサー](https://github.com/bitrise-io/bitrise-webhooks)は、さまざまな受信Webhook(たとえばGitHub、Bitbucket、またはSlackからのもの)を[bitrise.io](https://www.bitrise.io)のBuild Trigger API形式に変換し、それを呼び出してビルドを開始します。 | [https://github.com/bitrise-io/bitrise-webhooks](https://github.com/bitrise-io/bitrise-webhooks) |
