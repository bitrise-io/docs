<GlossTerm baseform="step">Step</GlossTerm>は、ビルドタスクをカプセル化したものです。このタスクを実行するコード、タスクに対して定義できる入力とパラメーター、そしてタスクが生成する出力が含まれます。

たとえば、`Git Clone` Stepは、指定されたリポジトリに対して、クローンするブランチやコミットなどの指定された入力を使用して`git clone`を実行します。

技術的な観点では、Stepはセマンティックバージョニングされたリポジトリであり、StepのコードとStepのインターフェース定義が含まれています。

Stepのインターフェース定義は、すべてのStepについて<GlossTerm baseform="step.yml">`step.yml`</GlossTerm>ファイルで定義されています。これには以下が含まれます。

- Stepの依存関係。
- Stepの入力と出力。
- Stepのタイトルと説明。
- 課題管理ツールやサポートURLなどのプロパティ、および特定のフィルタープロパティ。

Stepsを<GlossTerm baseform="Workflow">Workflow</GlossTerm>に含めるには、プロジェクトの<GlossTerm baseform="configuration yaml">設定YAML</GlossTerm>ファイルでそれらを参照する必要があります。そのためには、Stepの正しい参照形式が必要です。設定ファイルでは、Stepのインターフェース定義で定義されている入力に対して、入力値を指定することもできます。
