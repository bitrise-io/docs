<GlossTerm baseform="bitrise.yml">`bitrise.yml`</GlossTerm>ファイルで指定する<GlossTerm baseform="Step">Step</GlossTerm>のデータや情報は、Stepのデフォルトの定義と比較して変更したいStepのパラメーターです。

Stepの元のインターフェース定義を確認するには、Step ライブラリでチェックできます。Stepのインターフェース定義は、StepLib の[steps ディレクトリ](https://github.com/bitrise-io/bitrise-steplib/tree/master/steps)にあります。

`bitrise.yml`の設定でStep(参照/ID)以外に入力やその他のStepプロパティを指定しない場合、StepはStepの開発者がインターフェース定義で定めたdefault valueを使用して実行されます。

単一の[<strong>Script</strong>](https://github.com/bitrise-io/steps-script)Stepを使った例を見てみましょう。これは`bitrise local run test`を実行すると実行されます。

```yaml
format_version: '26'
default_step_lib_source: https://github.com/bitrise-io/bitrise-steplib.git
    
workflows:
  test:
    steps:
    - script:
```

`inputs:`リストプロパティを使用して、Stepの入力を指定します。入力は*キー*と*値*で構成されます。

:::warning[インデント]

[YAML形式](https://github.com/yaml/yaml-spec)ではインデントが非常に重要です。半角スペース2つまたは4つでインデントする必要があり、タブでインデントすることはできません。

:::

```yaml
format_version: '26'
default_step_lib_source: https://github.com/bitrise-io/bitrise-steplib.git
    
workflows:
  test:
    steps:
    - script:
        inputs:
        - content: "echo 'Hello World!'"
```

Stepに必須の入力がない場合は、入力を指定する必要はありません。必要な数だけ入力に値を指定できます。

Stepの入力値は常に<strong>文字列</strong>/テキスト値であり、Environment VariablesとしてStepに渡されます。値は、標準のYAMLマルチライン形式を使用してマルチラインにすることもできます。

```yaml
format_version: '26'
default_step_lib_source: https://github.com/bitrise-io/bitrise-steplib.git

workflows:
  test:
    steps:
    - script@1.1.3:
        inputs:
        - content: |
            #!/bin/bash
            set -ex
            var_to_print='Hello World!'
            echo "${var_to_print}"
```

上記のようにマルチライン値を使用する場合、キーに対して半角スペース2つまたは4つで値をインデントする必要があります。

`is_always_run`プロパティを`true`に設定することで、直前のStepが失敗した場合でもStepを強制的に実行できます。

```yaml
format_version: '26'
default_step_lib_source: https://github.com/bitrise-io/bitrise-steplib.git

workflows:
  test:
    steps:
    - script@1.1.3:
        is_always_run: true
        inputs:
        - content: "puts 'Hello Ruby!'"
        - runner_bin: ruby
```

`title`プロパティを使用して、Stepにわかりやすいタイトルを追加します。

```yaml
format_version: '26'
default_step_lib_source: https://github.com/bitrise-io/bitrise-steplib.git

workflows:
  test:
    steps:
    - script@1.1.3:
        title: Print Hello Ruby
        is_always_run: true
        inputs:
        - content: "puts 'Hello Ruby!'"
        - runner_bin: ruby
```
