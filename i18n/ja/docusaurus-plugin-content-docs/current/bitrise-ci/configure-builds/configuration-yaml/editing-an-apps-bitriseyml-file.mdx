Bitriseの設定はYAMLファイルで定義されます。すべてのBitrise<GlossTerm baseform="project">プロジェクト</GlossTerm>には、ルートとなる`bitrise.yml`ファイルがあり、これは<GlossTerm baseform="pipeline">Pipelines</GlossTerm>、<GlossTerm baseform="workflow">Workflows</GlossTerm>、アプリレベルのEnvironment Variables、<GlossTerm baseform="trigger">トリガー</GlossTerm>マップ、およびプロジェクトの<GlossTerm baseform="stack">スタック</GlossTerm>タイプとマシンタイプを定義します。このファイルは、次の3つの方法で編集できます。

- <GlossTerm baseform="workflow editor">Workflow Editor</GlossTerm>のグラフィカルなUIを使用する方法。Workflow Editorで変更を行うと、`bitrise.yml`ファイルが自動的に更新されます。
- [Workflow Editorでbitrise.ymlファイルを編集する](#editing-the-bitriseyml-file-online)方法。[設定ファイルをリポジトリに保存](/bitrise-ci/configure-builds/configuration-yaml/storing-an-apps-configuration-yaml#storing-the-bitriseyml-file-in-your-repository)している場合でも、この方法を使用できます。Workflow Editorは変更を直接リポジトリにプッシュできます。
- 任意のエディタで[bitrise.ymlファイルをローカルで編集する](#editing-the-bitriseyml-file-locally)方法。内容をオンラインエディタにコピーしたり、設定ファイルをリポジトリに保存している場合はそこにプッシュしたりできます。

:::note[モジュール化された設定]

設定が`include`キーワードを使って複数のファイルに分割されている場合、Workflow Editorはすべてのモジュールを読み込み、1つずつファイルを編集できるようにします。[Workflow Editorでモジュール化された設定を編集する](/bitrise-ci/configure-builds/configuration-yaml/editing-a-modular-configuration-in-the-workflow-editor)を参照してください。

:::

## bitrise.ymlファイルをオンラインで編集する

<strong><GlossTerm baseform="bitrise.yml">bitrise.yml</GlossTerm>エディタ</strong>でビルド設定をyml形式で編集できます。そのためには、Workflow Editorを開き、上部で<strong>YAML</strong>に切り替えてください。

![Workflow Editor内のVisualとYAMLの切り替え](/img/2026-06-05-workflow-editor-visual-yaml-toggle.png)

ここでファイルを直接編集できます。Bitriseは設定を検証します。`bitrise.yml`ファイルが無効な場合、ファイルを保存できません。

現在の`bitrise.yml`ファイルをダウンロードするには、<strong>Download</strong>をクリックしてください。または、ファイルの特定のセクションを選択して、ローカルの`bitrise.yml`ファイルや別のプロジェクトの`bitrise.yml`ファイルにコピーすることもできます。


## bitrise.ymlファイルをローカルで編集する

<Partial_OfflineWorkflowEditor />

私たちのYAMLスキーマは[schemastore](https://www.schemastore.org/bitrise.json)で共有されています。これにより、次のファイルをローカルで編集する場合に、シンタックスハイライトとオートコンプリートが使用できます。

- `bitrise.yml`
- `step.yml`
- `bitrise.json`

次のエディタはオートコンプリート機能をサポートしています。

- IntelliJ IDEA
- PhpStorm
- PyCharm
- Rider
- RubyMine
- Visual Studio 2013+
- Visual Studio Code
- Visual Studio for Mac
- WebStorm
- JSONBuddy

  ![autocomplete.png](/img/_paligo/uuid-949123a0-1356-b913-0a17-cd7270ba78c3.png)

ファイルをローカルで編集した後、その内容をオンラインの`bitrise.yml`ファイルにコピーするか、[自分のリポジトリに保存](/bitrise-ci/configure-builds/configuration-yaml/storing-an-apps-configuration-yaml#storing-the-bitriseyml-file-in-your-repository)して、Workflow Editorを使用してブラウザから直接今後の変更をプッシュすることもできます。
