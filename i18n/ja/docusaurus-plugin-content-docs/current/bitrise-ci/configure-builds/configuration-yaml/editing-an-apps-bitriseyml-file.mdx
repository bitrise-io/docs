Bitriseの設定はYAMLファイルで定義します。すべてのBitrise<GlossTerm baseform="project">プロジェクト</GlossTerm>には、ルートの`bitrise.yml`ファイルがあります。このファイルでは、<GlossTerm baseform="pipeline">Pipelines</GlossTerm>、<GlossTerm baseform="workflow">Workflows</GlossTerm>、アプリレベルのEnvironment Variables、<GlossTerm baseform="trigger">トリガー</GlossTerm>マップ、プロジェクトで使用する<GlossTerm baseform="stack">スタック</GlossTerm>タイプとマシンタイプを定義します。このファイルは、次の3つの方法で編集できます。

- <GlossTerm baseform="workflow editor">Workflow Editor</GlossTerm>のグラフィカルなUIを使用します。Workflow Editorで変更を加えるたびに、`bitrise.yml`ファイルが自動的に更新されます。
- [Workflow Editorでbitrise.ymlファイルを編集します](#editing-the-bitriseyml-file-online)。[設定ファイルをリポジトリに保存している場合](/bitrise-ci/configure-builds/configuration-yaml/storing-an-apps-configuration-yaml#storing-the-bitriseyml-file-in-your-repository)でも編集できます。Workflow Editorは変更をリポジトリに直接プッシュできます。
- 任意のエディターで[bitrise.ymlファイルをローカルで編集します](#editing-the-bitriseyml-file-locally)。内容をオンラインエディターにコピーするか、設定ファイルをリポジトリに保存している場合はリポジトリにプッシュできます。

:::note[モジュール構成]

`include`キーワードで設定を複数のファイルに分割している場合、Workflow Editorはすべてのモジュールを読み込み、1ファイルずつ編集できます。[Workflow Editorでのモジュール構成の編集](/bitrise-ci/configure-builds/configuration-yaml/editing-a-modular-configuration-in-the-workflow-editor)を参照してください。

:::

## bitrise.ymlファイルのオンライン編集 {#editing-the-bitriseyml-file-online}

ビルド設定は、<strong><GlossTerm baseform="bitrise.yml">bitrise.yml</GlossTerm>エディター</strong>でyml形式のまま編集できます。Workflow Editorを開き、上部で<strong>YAML</strong>に切り替えてください。

![Workflow EditorのYAML切り替え](/img/2026-06-05-workflow-editor-visual-yaml-toggle.png)

ここでファイルを直接編集できます。Bitriseが設定を検証します。`bitrise.yml`ファイルが無効な場合は、ファイルを保存できません。

現在の`bitrise.yml`ファイルをダウンロードするには、<strong>Download</strong>をクリックします。また、ファイルの特定のセクションだけを選択して、ローカルの`bitrise.yml`ファイルや別のプロジェクトの`bitrise.yml`ファイルにコピーすることもできます。


## bitrise.ymlファイルのローカル編集 {#editing-the-bitriseyml-file-locally}

<Partial_OfflineWorkflowEditor />

Bitrise CLIを使用してファイルを編集することもできます。[`bitrise.yml`をダウンロード](/bitrise-ci/bitrise-cli/working-with-bitrise-yml-via-the-bitrise-cli#downloading-the-bitriseyml-file)し、[検証](/bitrise-ci/bitrise-cli/working-with-bitrise-yml-via-the-bitrise-cli#validating-a-bitriseyml-file)してから、[Bitriseにアップロード](/bitrise-ci/bitrise-cli/working-with-bitrise-yml-via-the-bitrise-cli#uploading-a-bitriseyml-file)します。これらのコマンドにはBitrise CLI 3.0.0以降が必要です。

YAMLスキーマは[schemastore](https://www.schemastore.org/bitrise.json)で共有されています。そのため、次のファイルをローカルで編集する場合は、シンタックスハイライトと自動補完を利用できます。

- `bitrise.yml`
- `step.yml`
- `bitrise.json`

次のエディターが自動補完機能に対応しています。

- IntelliJ IDEA
- PhpStorm
- PyCharm
- Rider
- RubyMine
- Visual Studio 2013+
- Visual Studio Code
- Visual Studio for Mac
- WebStorm
- JSONBuddy

  ![autocomplete.png](/img/_paligo/uuid-949123a0-1356-b913-0a17-cd7270ba78c3.png)

ファイルをローカルで編集した後は、内容をオンラインの`bitrise.yml`ファイルにコピーするか、[独自のリポジトリに保存](/bitrise-ci/configure-builds/configuration-yaml/storing-an-apps-configuration-yaml#storing-the-bitriseyml-file-in-your-repository)して、Workflow Editorを使用して今後の変更をブラウザーから直接プッシュできます。
