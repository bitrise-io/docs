Bitrise CIの設定はYAMLファイル内で定義および保存されます。<GlossTerm baseform="workflow editor">Workflow Editor</GlossTerm>のGUIで設定を変更すると、YAMLファイルが変更されます。これらのファイルでは、以下を定義します。

- ビルドが使用する[Bitrise CLI](/bitrise-ci/bitrise-cli/installing-and-updating-the-bitrise-cli)のフォーマットバージョン。このフォーマットバージョン番号によって、その設定を実行できるBitrise CLIのバージョンが決まります。
- プロジェクトの種類(例: AndroidやiOS)。
- デフォルトで使用される[Steps](/bitrise-ci/references/steps-reference/step-reference-id-format)のソース。
- ビルド、および特定の<GlossTerm baseform="Workflow">Workflows</GlossTerm>または<GlossTerm baseform="Pipeline">Pipelines</GlossTerm>の[stack](/bitrise-ci/configure-builds/configuring-build-settings/setting-the-stack-for-your-builds#setting-the-stack-in-the-configuration-yaml)と[machine type](/bitrise-ci/configure-builds/configuring-build-settings/setting-the-stack-for-your-builds#setting-the-stack-in-the-configuration-yaml)。
- Gitイベントに基づく[ビルドトリガー](/bitrise-ci/run-and-analyze-builds/build-triggers/about-build-triggers)。
- ビルドからアクセスできる、appおよびWorkflowレベルの[Environment Variables](/bitrise-ci/configure-builds/environment-variables#setting-env-vars-in-the-configuration-yaml)。
- ビルドで使用されるWorkflowsおよび<GlossTerm baseform="step">Steps</GlossTerm>。

デフォルトの<GlossTerm baseform="configuration yaml">設定YAML</GlossTerm>ファイルは`bitrise.yml`と呼ばれます。各Bitrise<GlossTerm baseform="project">project</GlossTerm>には`bitrise.yml`ファイルがあります。`bitrise.yml`ファイルの詳細なリファレンス情報については、[設定YAMLリファレンス](/bitrise-ci/references/configuration-yaml-reference)を参照してください。

設定YAMLファイルは、以下の場所に保存できます。

- Bitrise website。これがデフォルトの設定です。
- 独自のGitリポジトリ。

独自のGitリポジトリに設定を保存している場合、[Workflow Editorはブラウザから直接変更をプッシュできます](/bitrise-ci/configure-builds/configuration-yaml/storing-an-apps-configuration-yaml#updating-a-bitriseyml-stored-in-the-repository)。ブランチを選択して読み込み、変更を加えて、Bitriseを離れることなくコミットして戻せます。この機能はGitHubおよびGitLabでホストされているリポジトリで利用できます。Bitbucket Cloudではサポートされていません。

独自のGitリポジトリにYAML設定を保存している場合は、モジュール化されたYAML設定を使用することもできます。これは、デフォルトの`bitrise.yml`設定ファイルに加えて、追加設定を含むYAMLファイルを1つ以上使用することを意味します。これにより、大規模な設定をより小さくモジュール化されたコンポーネントに分割できるだけでなく、複数の異なるリポジトリやBitriseproject間で設定セグメントを効率的に再利用できます。詳しくは、[モジュール化されたYAML設定](/bitrise-ci/configure-builds/configuration-yaml/modular-yaml-configuration)を参照してください。

:::important[Enterpriseのみ]

モジュール化されたYAML設定は、[Enterpriseプラン](https://bitrise.io/pricing)を利用している<GlossTerm baseform="workspace">Workspaces</GlossTerm>でのみ使用できます。現時点では、YAML設定をbitrise.ioに保存している場合は利用できません。

:::
