Bitriseでビルドを実行すると、そのビルドで使用された`bitrise.yml`設定を常に確認できます。設定をダウンロードして現在の`bitrise.yml`ファイルと比較したり、現在の設定ファイルをビルドの設定ファイルに置き換えたりすることもできます。

ビルドの設定ファイルにアクセスするには:

1. Bitrise CIを開き、プロジェクトを選択してから、そのプロジェクトのビルドのいずれかを選択します。
1. 右上にある<strong><GlossTerm baseform="configuration yaml">Configuration YAML</GlossTerm></strong>を選択します。

   ![show-config-yaml.png](/img/_paligo/uuid-b4d1eb0b-3222-87c7-f672-82695ed71e87.png)
1. ドロップダウンメニューで<strong>View configuration YAML</strong>を選択します。


## 設定YAMLの変更を確認する

ビルドの<strong>Configuration YAML</strong>ページには、次の情報が表示されます。

- ビルドで使用されたYAML設定。
- ビルドが異なる設定を使用していた場合は、現在の設定YAMLも確認できます。

このページには、現在の設定とビルドで使用された設定の差分も表示されます。

- 緑は追加されたコンテンツを示します。
- 青は変更されたコンテンツを示します。
- 赤は削除されたコンテンツを示します。

![compare-config-yaml.png](/img/_paligo/uuid-e0c8a32c-f635-adb8-8380-03c13b38026d.png)


## 設定YAMLを復元する

現在の設定YAMLを、アプリの過去のビルドのいずれかの設定に変更できます。この操作を行うと、現在の設定が上書きされます。手順は次のとおりです。

1. Bitrise CIを開き、プロジェクトを選択してから、そのプロジェクトのビルドのいずれかを選択します。
1. 右上にある<strong>Configuration YAML</strong>を選択します。
1. ドロップダウンメニューで<strong>View configuration YAML</strong>を選択します。
1. ダイアログで<strong>Restore configuration YAML</strong>をクリックします。
1. 確認ダイアログで<strong>Overwrite</strong>をクリックします。


## ビルドの設定YAMLを削除する

必要であれば、ビルドの`bitrise.yml`ファイルを削除できます。ただし、この操作は元に戻せない点に注意してください。削除すると、そのビルドの`bitrise.yml`ファイルは誰も閲覧できなくなります。

1. Bitrise CIを開き、プロジェクトを選択してから、そのプロジェクトのビルドのいずれかを選択します。
1. 右上にある<strong>Configuration YAML</strong>を選択します。

   ![show-config-yaml.png](/img/_paligo/uuid-b4d1eb0b-3222-87c7-f672-82695ed71e87.png)
1. ドロップダウンメニューで<strong>Delete configuration YAML</strong>を選択します。
1. 確認ダイアログで<strong>Delete configuration YAML</strong>をクリックします。
