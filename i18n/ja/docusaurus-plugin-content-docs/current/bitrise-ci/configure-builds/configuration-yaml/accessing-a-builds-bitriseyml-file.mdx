Bitriseでビルドを実行すると、そのビルドが使用した`bitrise.yml`の設定をいつでも確認できます。ダウンロードして現在の`bitrise.yml`ファイルと比較したり、現在の設定ファイルをそのビルドの設定ファイルに置き換えたりすることもできます。

コマンドラインからダウンロードするには、[`bitrise build yml`](/bitrise-ci/bitrise-cli/managing-builds-with-the-bitrise-cli#viewing-a-build)または[`bitrise yml get --build`](/bitrise-ci/bitrise-cli/working-with-bitrise-yml-via-the-bitrise-cli#downloading-the-bitriseyml-file)を使用します。どちらのコマンドも Bitrise CLI 3.0.0 以降が必要です。

ビルドの設定ファイルにアクセスするには:

1. Bitrise CIを開き、プロジェクトを選択して、そのプロジェクトのいずれかのビルドを選択します。
1. 右上の <strong><GlossTerm baseform="configuration yaml">Configuration YAML</GlossTerm></strong> を選択します。

   ![show-config-yaml.png](/img/_paligo/uuid-b4d1eb0b-3222-87c7-f672-82695ed71e87.png)
1. ドロップダウンメニューで <strong>View configuration YAML</strong> を選択します。


## YAMLの設定の変更の確認 {#checking-changes-in-the-configuration-yaml}

ビルドの <strong>Configuration YAML</strong> ページでは、次の内容を確認できます。

- ビルドが使用したYAMLの設定。
- ビルドが異なる設定を使用していた場合は、現在の設定YAMLも確認できます。

このページには、現在の設定とビルドが使用した設定との差分も表示されます。

- 緑は追加された内容を示します。
- 青は変更された内容を示します。
- 赤は削除された内容を示します。

![compare-config-yaml.png](/img/_paligo/uuid-e0c8a32c-f635-adb8-8380-03c13b38026d.png)


## YAMLの設定の復元 {#restoring-the-configuration-yaml}

現在の設定YAMLを、アプリの過去のビルドのいずれかの設定に変更できます。これにより、現在の設定が上書きされます。手順は次のとおりです。

1. Bitrise CIを開き、プロジェクトを選択して、そのプロジェクトのいずれかのビルドを選択します。
1. 右上の <strong>Configuration YAML</strong> を選択します。
1. ドロップダウンメニューで <strong>View configuration YAML</strong> を選択します。
1. ダイアログで <strong>Restore configuration YAML</strong> をクリックします。
1. 確認ダイアログで <strong>Overwrite</strong> をクリックします。


## ビルドの設定YAMLの削除 {#deleting-a-builds-configuration-yaml}

必要に応じて、ビルドの`bitrise.yml`ファイルを削除できます。ただし、この操作は元に戻せません。削除すると、そのビルドの`bitrise.yml`ファイルは誰も表示できなくなります。

1. Bitrise CIを開き、プロジェクトを選択して、そのプロジェクトのいずれかのビルドを選択します。
1. 右上の <strong>Configuration YAML</strong> を選択します。

   ![show-config-yaml.png](/img/_paligo/uuid-b4d1eb0b-3222-87c7-f672-82695ed71e87.png)
1. ドロップダウンメニューで <strong>Delete configuration YAML</strong> を選択します。
1. 確認ダイアログで <strong>Delete configuration YAML</strong> をクリックします。
