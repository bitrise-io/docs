デフォルトのGitユーザー名とユーザーのメールアドレスは、<GlossTerm baseform="Stack">スタック</GlossTerm>では次のとおりです。

```bash
git config --global user.email "noreply@bitrise.io"
git config --global user.name "Bitrise CI"
```

ビルドの実行中にBitriseから自分自身のリポジトリにコミットをプッシュバック（`git push`）したい場合は、自分のユーザー名とメールアドレスを設定する必要があります。これを実現する方法は3つあります。

- カスタムScript <GlossTerm baseform="Step">Step</GlossTerm>を使用して、`git config`コマンドで認証情報を設定できます。
- Git認証情報を環境変数として設定できます。
- [<strong>Set Git Credentials</strong>](https://bitrise.io/integrations/steps/set-git-credentials)Stepを使用できます。

## 環境変数を使用してGit認証情報を設定する {#setting-your-git-credentials-using-env-vars}

Gitには、Bitrise 環境変数](/bitrise-ci/configure-builds/environment-variables)と似た、基本的な[環境変数](https://git-scm.com/book/en/v2/Git-Internals-Environment-Variables)がいくつかあります。<GlossTerm baseform="workflow">Workflow</GlossTerm>内のStepsの量を減らしたい場合は、特定のGit環境変数を利用してBitriseで環境変数を設定できます。

1. <GlossTerm baseform="workflow editor">Workflow Editor</GlossTerm>を開きます。
1. <strong>Env Vars</strong>タブに移動します。
1. 次の環境変数を作成します。

   - GIT_AUTHOR_NAME: 「author」の人が読める形式の名前です。
   - GIT_AUTHOR_EMAIL: 「author」のメールアドレスです。
   - GIT_COMMITTER_NAME: 「committer」の人が読める形式の名前です。
   - GIT_COMMITTER_EMAIL: 「committer」のメールアドレスです。

   ![git_credentials.png](/img/_paligo/uuid-2b06167e-f54e-eb64-2314-315d36a5d17f.png)

## [Set Git Credentials](https://bitrise.io/integrations/steps/set-git-credentials)Stepを使用してGit認証情報を設定する {#setting-your-git-credentials-using-the-set-git-credentials-step}

1. [<strong>Set Git Credentials</strong>](https://bitrise.io/integrations/steps/set-git-credentials)Stepを、Workflowの一番最初のステップとして追加します。`git commit`をする前に、まずStepを実行する必要があります。こうすることで、現在のビルドで行った変更が、必ず自分のユーザー名とメールアドレスに関連付けられたコミットに含まれるようにできます。
1. <strong>Git Username</strong>フィールドに、自分のユーザー名を値として設定します。
1. <strong>Git Email Address</strong>フィールドに、自分のメールアドレスを値として設定します。
1. [ビルドを開始します。](/bitrise-ci/run-and-analyze-builds/starting-builds/approving-pull-request-builds)

うまくいけば、Gitプロバイダー上の自分のリポジトリで変更を確認できるはずです。新しいユーザー名とメールアドレスは、以降ビルドからGitプロバイダーにプッシュするすべてのコミットで表示されるようになります。
