<strong>Rolling Builds</strong> 機能を使用すると、実行中のビルドや保留中のビルドをキャンセルできます。新しいビルドが開始されると、プロジェクトの以前のビルドは自動的に中止されます。

<strong>Rolling builds</strong> オプションを有効にして新しいビルドを開始すると、手動ビルドとスケジュールされたビルドもキャンセルされる点にご注意ください。

:::note[ビルドが中止されるタイミング]

実行中のビルドがあるブランチでビルドを<GlossTerm baseform="trigger">トリガー</GlossTerm>すると、同じ<GlossTerm baseform="Workflow">Workflow</GlossTerm>を実行している場合に限り、実行中のビルドは中止されます。

たとえば、リポジトリの <strong>main</strong> ブランチで <strong>deploy</strong> Workflowを使ってビルドをトリガーしても、<strong>primary</strong> Workflowを使って同じ <strong>main</strong> ブランチで実行中の build running on はキャンセルされません。

:::

## rolling buildsの設定 {#configuring-rolling-builds}

1. <Partial_GettingToTheProjectSettingsPage />
1. 左側で <strong>Builds</strong> を選択します。
1. <strong>Build strategy</strong> セクションを見つけます。
1. 新しいビルドが開始されたときに中止するビルドの種類を選択します。

   ![rolling-builds.png](/img/_paligo/uuid-74153d13-4c04-d223-7389-268265192245.png)

   - <strong>Abort on-hold builds triggered by pull requests</strong>: Pull Requests および関連するすべての Push に対して、まだ <strong>保留中</strong> のすべての以前のビルドを Cancel します。<strong>Running builds が中止される</strong> も有効にしない限り、<strong>Running</strong> ビルドは中止<strong>されません</strong>。
   - <strong>Abort on-hold builds triggered by pushes</strong>: 同じブランチへの Push について、まだ <strong>保留中</strong> のすべての以前のビルドを Cancel します。<strong>Running builds が中止される</strong> も有効にしない限り、<strong>Running</strong> ビルドは中止<strong>されません</strong>。Push イベントの除外は [Push イベントの除外の管理](#managing-exclusions-for-push-events) で設定できます。
   - <strong>Abort on-hold builds triggered by tags</strong>: Git タグによってトリガーされたビルドの場合、まだ <strong>保留中</strong> のすべての以前のビルドを Cancel します。
   - <strong>Abort running builds</strong>: 保留中のビルドに加えて、実行中のビルドも自動的にキャンセルします。

## Push イベントの除外の管理 {#managing-exclusions-for-push-events}

Bitrise を設定すると、特定のコード Push ビルドを中止しないようにできます。そのためには、rolling builds の設定時に除外を追加します。除外できる対象は次のとおりです。

- リポジトリのブランチ
- <GlossTerm baseform="pipeline">Pipelines</GlossTerm> および Workflows

除外されたブランチ、Pipeline、または Workflow が関係するビルドは、決して中止されません。

1. [Build strategy セクションに移動して rolling builds を設定します](#configuring-rolling-builds)。
1. <strong>Abort on-hold builds triggered by pushes</strong> を有効にします。
1. <strong>Add 除外</strong> をクリックします(既存の除外がある場合は <strong>Manage 除外</strong>)。
1. <strong>Excluded branches</strong> フィールドに excluded branches を入力し、<strong>Excluded pipelines and workflows</strong> フィールドに除外する Pipelines または Workflows を入力します。どちらのフィールドもカンマ区切りの値のリストを使用できます。

   ![add-exclusions.png](/img/_paligo/uuid-563e93b4-6feb-8322-27f7-7b86d6957992.png)
