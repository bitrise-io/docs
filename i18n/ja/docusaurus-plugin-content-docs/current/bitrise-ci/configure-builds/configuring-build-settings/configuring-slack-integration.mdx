[<strong>Send a Slack message</strong>](https://github.com/bitrise-io/steps-slack-message) <GlossTerm baseform="Step">Step</GlossTerm>を使うと、Bitriseビルド中に個々のユーザー、グループ、チャンネルにSlackメッセージを送信できます。メッセージをカスタマイズしたり、添付ファイルを含めたり、ユーザーをビルドページへ移動させるリンクボタンを追加したりできます。

Stepを使ってメッセージを送信するには:

1. [workspace Slack インテグレーション](/bitrise-platform/workspaces/workspace-slack-integration)をSet upし、[インテグレーションIDを取得](/bitrise-platform/workspaces/workspace-slack-integration)してください。

   StepにはインテグレーションIDが必要です。
1. [<strong>Send a Slack message</strong>](https://github.com/bitrise-io/steps-slack-message) Stepを<GlossTerm baseform="workflow">Workflow</GlossTerm>に追加してください。
1. 前のStepが失敗しても[常に実行されるように設定されている](/bitrise-ci/workflows-and-pipelines/steps/enabling-or-disabling-a-step-conditionally)ことを確認してください！

   これはStepのデフォルト設定です。変更すると、ビルドが失敗した場合にメッセージが送信されなくなります。
1. <strong>Workspace Slack Integration ID</strong> 入力欄を見つけて、インテグレーションIDを追加してください。
1. Stepの関連する入力欄を使ってSlackメッセージをカスタマイズしてください。

   次のようなオプションがあります(ただしこれらに限定されません):

   - 送信先のチャンネル、グループ、ユーザー名の設定: 名前またはエンコードされたIDを指定できます。
   - 送信するメッセージの本文。
   - メッセージ送信時のボットのユーザー名
   - メッセージの色
   - ファイルの添付
   - メッセージに添付するリンクボタン

   <GlossTerm baseform="workflow editor">Workflow Editor</GlossTerm>のすべての入力項目を確認して、Slackメッセージをカスタマイズする方法をすべて確認してください。
