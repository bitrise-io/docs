[bitrise.io](https://www.bitrise.io)で新しいプロジェクトを追加すると、初期の<GlossTerm baseform="Pipeline">Pipelines</GlossTerm>と<GlossTerm baseform="Workflow">Workflows</GlossTerm>が作成されます。

これらを使用して、テストを実行したり、IPAやAPKなどのインストール可能なバイナリを作成したりできます。デフォルトのPipelinesとWorkflowsは、必要に応じて自由に変更してください。

デフォルトのPipelinesは、新しいすべてのiOSおよびAndroidプロジェクトに対して作成されます。このPipelinesは、自動的に作成されたdefault Workflowsで構成されます。

| Pipeline ID | Pipelineの概要 | Pipeline内のWorkflows |
| --- | --- | --- |
| `run_tests` | iOSプロジェクトをビルドし、[2つの並列シャード](/bitrise-ci/workflows-and-pipelines/build-pipelines/configuring-a-bitrise-pipeline#running-variations-of-the-same-workflow)でXcodeのテストを実行します。シャード数は環境変数$TEST_SHARD_COUNTで指定します。 | `build_for_testing`  `test_without_building` |

| Pipeline ID | Pipelineの概要 | Pipeline内のWorkflows |
| --- | --- | --- |
| `run_tests` | [2つの並列テストシャード](/bitrise-ci/workflows-and-pipelines/build-pipelines/configuring-a-bitrise-pipeline#running-variations-of-the-same-workflow)でAndroidのインストルメンテーションテストを実行し、テストレポートを取得します。シャード数は環境変数$TEST_SHARD_COUNTで指定します。 | `run_instrumented_tests` |
