Bitrise Pipelineは、当社のCI/CD設定における最上位の階層です。Pipelinesを使用すると、CI/CDプロセス全体を整理し、複数の異なるタスクを並行または順次実行する高度な設定をセットアップできます。

Pipelineを使用すると、Workflows間の依存関係を設定できます。各Workflowは、親であるWorkflowsが完了すると実行を開始します。同じレベルにあるWorkflowsは並行して実行されます。

![pipeline-example.png](/img/_paligo/uuid-e85b689a-0101-6664-7f58-6e9ae5c851a7.png)

この例では、Aが成功すると、BとCが並行して実行されます。BとCの両方が成功すると、Dが実行されます。
