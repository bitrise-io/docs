Pipelineビルドは、スタンドアロンのWorkflowsのビルドを実行する場合と同じ方法で実行できます:

- [Pipelineビルドを手動で開始できます](/bitrise-ci/run-and-analyze-builds/starting-builds/starting-builds-manually)。
- [Pipelineビルドをスケジュールする](/bitrise-ci/run-and-analyze-builds/starting-builds/scheduling-builds)。
- [Pipelineビルドを自動的にトリガーする](/bitrise-ci/run-and-analyze-builds/build-triggers/configuring-build-triggers)。PipelineトリガーはWorkflow EditorまたはYAMLで設定できます: [ビルドトリガー用のYAML構文](/bitrise-ci/run-and-analyze-builds/build-triggers/yaml-syntax-for-build-triggers)。

Pipelineビルドはビルドステータスレポートを送信できます。Pipelineビルドは、Pipeline自体と、テスト結果をエクスポートするStepsのステータスレポートを送信します: [Gitホスティングプロバイダーへのビルドステータスの報告](/bitrise-ci/configure-builds/configuring-build-settings/reporting-the-build-status-to-your-git-hosting-provider)。

Pipelineビルドのすべてのアーティファクトは、<strong>Artifacts</strong>ページで確認できます: [オンラインでのビルドアーティファクト](/bitrise-ci/run-and-analyze-builds/managing-build-files/build-artifacts-online)。

モバイルアプリをテスターに配布したり、アプリをオンラインストアでリリースしたりするために、Pipelineビルドを使用してインストール可能なアーティファクトをRelease Managementにアップロードできます。必要なのは、インストール可能なAPK、AAB、またはIPAファイルを生成するWorkflowだけです: [トピックを参照](urn:resource:component:92027)。
