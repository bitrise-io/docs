Bitrise<GlossTerm baseform="workflow">Workflow</GlossTerm>は<GlossTerm baseform="step">Steps</GlossTerm>の集まりです。プロジェクトのビルドの実行中、各StepはWorkflowで定義されている順序で実行されます。Workflowsは、次の二つの方法で作成、定義、変更できます。

- [bitrise.io](https://www.bitrise.io)上のグラフィカルな<GlossTerm baseform="workflow editor">Workflow Editor</GlossTerm>を使用する方法、または[お使いのデバイス上のオフライン版](/bitrise-ci/bitrise-cli/installing-and-upgrading-the-offline-workflow-editor)を使用する方法。
- プロジェクトの<GlossTerm baseform="bitrise.yml">`bitrise.yml`</GlossTerm>ファイルを直接編集する方法。

最終的には、どちらの方法でも`bitrise.yml`ファイルが変更されます。<strong>Workflow Editor</strong>は、単にそれをより使いやすくする方法です。

デフォルトでは、1つのビルドは1つのWorkflowです。ただし、Workflowsを連結して順番に実行することも、複数のWorkflowを同時に実行するように<GlossTerm baseform="trigger">トリガー</GlossTerm>することもできます。

Workflowsは[Pipelines](/bitrise-ci/workflows-and-pipelines/build-pipelines/pipelines-with-stages/configuring-a-pipeline-with-stages)に配置することもできます。Pipelineは複数のステージで構成され、各ステージは並列実行される1つ以上のWorkflowsで構成されます。
