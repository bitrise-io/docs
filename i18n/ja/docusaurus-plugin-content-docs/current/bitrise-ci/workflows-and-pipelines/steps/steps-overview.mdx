<GlossTerm baseform="step">Steps</GlossTerm>はBitriseの中核です。Stepとはビルドタスクのことです。たとえば、[<strong>Git Clone Repository</strong>](https://github.com/bitrise-steplib/steps-git-clone) Stepはビルド開始時にGitリポジトリをクローンし、[<strong>Google Play Deploy</strong>](https://github.com/bitrise-io/steps-google-play-deploy) Stepは完成したアプリをPlay Storeにデプロイできます。

Stepには、ビルドタスクを実行するコードが含まれています。タスクを定義する入力とパラメータを設定できるほか、Stepが生成する出力を表示して再利用することもできます。出力を再利用するとは、別のStepがその出力を自身の入力の値として使用できるということです。

StepsはYAML形式で定義されており、bashまたはGoで記述されています。

Stepsの一覧は以下で確認できます。

- [Integrationsページ](https://www.bitrise.io/integrations)
- [Bitrise StepLib](https://github.com/bitrise-io/bitrise-steplib)
- <GlossTerm baseform="workflow editor">Workflow Editor</GlossTerm>

[<strong>Script</strong>](https://github.com/bitrise-io/steps-script) Stepを使用すると、Bitriseビルドの一部として任意のカスタムスクリプトを作成して実行することもできます。スクリプトランナー(デフォルトはbash)を指定し、スクリプトを追加してビルドを実行するだけです。これらのカスタムスクリプトの設定方法の詳細については、[Bitrise Script Step - Running (Bash, Python, NodeJS, Ruby, Swift, Kotlin)](https://support.bitrise.io/hc/en-us/articles/8932506599955-Bitrise-Script-Step-Running-Bash-Python-NodeJS-Ruby-Swift-Kotlin-)をご覧ください。

ビルドのために、Stepsは<GlossTerm baseform="workflow">Workflow</GlossTerm>Editorから直接管理できます。順序の変更、バージョンの設定、Stepsの追加や削除をいつでも行えます。


## Stepsの種類 {#types-of-steps}

Bitriseには[Step Library (StepLib)](https://github.com/bitrise-steplib)に400以上のStepsがあり、サードパーティ企業やオープンソースチームが自社のサービスやツールに基づいてStepsを追加し、充実させることができます。

Bitriseには3種類のStepsがあります。それぞれはGUI上のラベルで識別できます。

- <strong>公式Bitrise Steps</strong>: これらのStepsはBitriseが作成・管理しています。これらのStepsには緑のバッジと「B」のマークが付いています。
- <strong>Verified Steps</strong>: これらのStepsはコミュニティによって作成・管理されていますが、その所有者はサービスやツール、またはオープンソースチームであり、Bitriseを使用するすべてのユーザーに対して安全性、メンテナンス、一貫性、高品質なパフォーマンスを保証しています。これらのStepsには青いバッジとチェックマークが付いています。Verified Stepsの詳細については、[こちらのガイド](/bitrise-ci/workflows-and-pipelines/developing-your-own-bitrise-step/verified-steps#about-verified-steps)をご覧ください。
- <strong>コミュニティSteps</strong>: これらのStepsはコミュニティの誰でも作成できます。これらのStepsにはラベルやバッジは付いていません。Stepsを開発してBitriseコミュニティと共有する方法について知りたい場合は、[新しいStep](/bitrise-ci/workflows-and-pipelines/developing-your-own-bitrise-step/developing-a-new-step)をご覧ください。
