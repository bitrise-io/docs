このガイドでは、Bitrise APIを使ってシークレットを管理する方法について説明します。UIで同様の操作を行う方法について詳しくは、[Secrets](/bitrise-ci/configure-builds/secrets)をご覧ください。

| エンドポイント | 機能 | appのチームに必要なロール |
| --- | --- | --- |
| GET/apps/\{app-slug\}/secrets | 指定したappのSecretsの一覧を取得します。 | Owner または Admin |
| GET/apps/\{app-slug\}/secrets/\{secret-name\}/value | （保護されていない）シークレットの値を取得します。 | Owner または Admin |
| PUT/apps/\{app-slug\}/secrets/\{secret-name\} | シークレットを作成または更新します。 | Owner または Admin |
| DELETE/apps/\{app-slug\}/secrets/\{secret-name\} | シークレットを削除します。 | Owner または Admin |


## appのSecretsを表示する {#viewing-the-secrets-of-an-app}

:::important[必要なロール]

Bitrise APIを使ってSecretsを表示するには、appのチームでadminまたはownerロールを持っている必要があります。

ユーザーロールとロールチートシートの完全な一覧については、[appのチームにおけるユーザーロール](/bitrise-platform/projects/roles-and-permissions-for-bitrise-ci)をご確認ください。

:::

APIを使って、appのSecretsを表示できます。

`GET/apps/{app-slug}/secrets`エンドポイントを使うと、appのすべてのSecretsの一覧を取得できます。

特定のシークレットは、その`is_protected`の値が`false`に設定されている場合に表示できます。

<strong>「test」という名前のappのシークレットを表示する</strong>

リクエスト:

```bash
curl -X GET -H  'Authorization: THE-ACCESS-TOKEN' 'https://api.bitrise.io/v0.1/apps/APP-SLUG/secrets/test/value'
```

`is_protected`の値が`false`に設定されている場合、レスポンスにシークレットの値が返されます。

```json
{
  "value": "123ld"
}
```


## Secretsを作成または更新する {#creating-or-updating-secrets}

:::important[必要なロール]

Bitrise APIを使ってSecretsを作成または更新するには、appのチームでadminまたはownerロールを持っている必要があります。

ユーザーロールとロールチートシートの完全な一覧については、[appのチームにおけるユーザーロール](/bitrise-platform/projects/roles-and-permissions-for-bitrise-ci)をご確認ください。

:::

`secrets`エンドポイントのPUTメソッドを使って、Secretsを作成または更新できます。

指定した`secret-name`のシークレットが存在しない場合は、新しいシークレットが作成されます。すでにシークレットが存在する場合は、指定した新しい値で更新されます。

必須のパラメーターは次のとおりです:

- app slug
- シークレットの名前

オプションのパラメーターは次のとおりです:

- expand_in_step_inputs: <GlossTerm baseform="step">Steps</GlossTerm>に渡す前にBitrise CLIでシークレットを展開したい場合はtrueに設定します。
- is_exposed_for_pull_requests: シークレットをプルリクエストに公開したい場合はtrueに設定します。
- is_protected: シークレットの値を保護したい場合はtrueに設定します（GETメソッドでシークレットの値を表示できなくなります）。
- value: シークレットに保存される値です。

<strong>「test」という名前の新しいシークレットを作成する</strong>

リクエスト:

```bash
curl -X PUT -H 'Authorization: THE-ACCESS-TOKEN' 'https://api.bitrise.io/v0.1/apps/THE-APP-SLUG/secrets/test' -d '{"expand_in_step_inputs": true, "is_exposed_for_pull_requests": true, "is_protected": false, "value": "123ld2"}'
```
