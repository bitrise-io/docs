Bitrise APIを使用すると、お好みのツールやプロセスと連携した高度なカスタム統合を構築し、開発パイプラインをさらに効率化できます。

APIを使用すると、Bitrise websiteおよびCLIを通じて利用できる機能やデータを制御し、アクセスできます。APIを使用することで、プロセスに合わせてBitriseの機能を完全にカスタマイズできます。

:::note[APIは開発中です]

APIは開発中です。今後、新しいエンドポイントを追加し、既存のエンドポイントも更新する可能性があります。

APIの進捗は[ディスカッションに参加](https://discuss.bitrise.io/t/bitrise-api-v0-1-work-in-progress/1554)して確認できます。フォローすると、新しいエンドポイントや変更についての通知を受け取れます。それらはそこで発表されます。

:::

ぜひご協力ください。新しいAPI機能や新しいエンドポイントをリクエストしたい場合は、[こちらから行えます](http://discuss.bitrise.io/t/bitrise-public-api/37)。

Bitrise APIのホストは次のとおりです: [https://api.bitrise.io/](https://api.bitrise.io/)

ルートエンドポイントを除くすべてのエンドポイントはバージョン管理されています。バージョンはホストの直後のURLに含める必要があります。たとえば、[https://api.bitrise.io/v0.1/me](https://api.bitrise.io/v0.1/me)は自分自身のユーザーアカウント用のエンドポイントです。

現在、バージョンは`v0.1`のみです。

`v0.1`については長期的な互換性の保証はありませんが、やむを得ない場合を除いて破壊的変更を行わないよう最善を尽くしています。`v0.1`に満足したら、それを`v1.0`として「フリーズ」し、長期的なサポートを提供します。
