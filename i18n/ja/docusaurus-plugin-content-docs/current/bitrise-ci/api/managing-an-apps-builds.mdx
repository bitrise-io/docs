Bitrise API を使用すると、アプリのビルドの一覧表示、特定のビルドに関するすべての情報の取得、ビルドログの表示、200日以上前のアーカイブ済みビルドの表示を行うことができます。

| エンドポイント | 機能 | アプリのチームで必要なロール |
| --- | --- | --- |
| GET /apps/\{app-slug\}/archived-builds | 指定したアプリのアーカイブ済みビルドを一覧表示します。 | Tester/QA |
| GET /apps/\{app-slug\}/build-workflows | 指定したアプリに対してこれまでにトリガーされたワークフローを一覧表示します。 | Tester/QA |
| GET /apps/\{app-slug\}/builds | 指定したアプリのすべてのビルドを一覧表示します。 | Tester/QA |
| GET /apps/\{app-slug\}/builds/\{build-slug\} | 指定したアプリの指定したビルドを取得します。 | Tester/QA |
| GET /apps/\{app-slug\}/builds/\{build-slug\}/<GlossTerm baseform="bitrise.yml">bitrise.yml</GlossTerm> | 指定したアプリのビルドの `bitrise.yml` ファイルを取得します。 | Developer |
| GET /apps/\{app-slug\}/builds/\{build-slug\}/log | アプリの指定したビルドのビルドログを取得します。 | Developer |
| GET /builds | 認証済みアカウントでアクセスできる Bitrise のすべてのビルドを一覧表示します。 | N/A |


## アプリのビルドデータを表示する {#viewing-the-build-data-of-an-app}

API を使用すると、ビルドに関するすべての関連情報にアクセスできます。

`GET /apps/{app-slug}/builds` エンドポイントを使用すると、アプリのすべてのビルドを取得できます。ビルドに使用された <GlossTerm baseform="workflow">Workflow</GlossTerm> など、additional parameters をフィルターとして設定できます。パラメータは次の形式で設定してください。

```text
GET /apps/{app-slug}/builds?parameter_name=parameter_value&other_parameter_name=other_parameter_value
```

パラメータの全一覧については、[API リファレンス](/bitrise-api/api-reference/bitrise-api)ドキュメントを参照してください。

:::note[200日間のビルド保持]

アプリの <strong>Builds</strong> ページには、過去200日間のビルドのみが表示されます。ページ上で[特定のビルドを検索する](/bitrise-ci/run-and-analyze-builds/finding-a-specific-build)場合も同じ制限が適用されます。この制限はほとんどの API 呼び出しにも適用され、`GET/apps/{app-slug}/builds` エンドポイントおよび関連するエンドポイントでは過去200日間のビルドのみを返すことができます。

ただし、200日以上前のビルドを取得する方法が2つあります。

- 正確なビルドの URL がわかっている場合は、そのビルドにアクセスできます。
- `GET/apps/{app-slug}/archived-builds` API エンドポイントを使用できます。[アプリのアーカイブ済みビルドを一覧表示する](/bitrise-ci/api/managing-an-app-s-builds#listing-the-archived-builds-of-an-app)。

:::

<strong>プライマリ Workflow で `development` ブランチをビルドしたビルドを一覧表示する</strong>

リクエスト:

```bash
curl -X GET 'https://api.bitrise.io/v0.1/apps/$APP-SLUG/builds?branch=development&workflow=primary' -H 'accept: application/json' -H 'Authorization: $ACCESS_TOKEN'
```

<strong>ステータス整数を使用して失敗したビルドを一覧表示する</strong>

ステータス整数を使用すると、ビルドステータスに基づいてビルドをフィルタリングできます。ステータス整数は次のとおりです。

- 0 - 未完了(開始中、実行中、または保留中のビルド)
- 1 - 成功
- 2 - 失敗
- 3 - 失敗による中断
- 4 - 成功による中断

リクエスト:

```bash
curl -X GET 'https://api.bitrise.io/v0.1/apps/$APP-SLUG/builds?branch=development&status=2' -H 'accept: application/json' -H 'Authorization: $ACCESS_TOKEN'
```

## アプリのアーカイブ済みビルドを一覧表示する {#listing-the-archived-builds-of-an-app}

デフォルトでは、200日以内のビルドのみを表示できます。これはほとんどの API エンドポイントにも当てはまります。ただし、`GET /apps/{app-slug}/archived-builds` エンドポイントを呼び出すことで、それより古いアーカイブ済みビルドを表示することもできます。

このエンドポイントには、必須のパラメータが2つあります。

- after
- before

どちらのパラメータもUnixタイムスタンプで表される日付であり、両方とも必須です。つまり、アーカイブ済みビルドを表示したい正確な期間を指定する必要があります。

<strong>2021-01-01から2022-01-01までのすべてのアーカイブ済みビルドを一覧表示する</strong>

```bash
curl -X 'GET' \
  'https://api.bitrise.io/v0.1/apps/APP-SLUG/archived-builds?after=1609459200&before=1640995200' \
  -H 'accept: application/json' \
  -H 'Authorization: THE_ACCESS_TOKEN'
```
