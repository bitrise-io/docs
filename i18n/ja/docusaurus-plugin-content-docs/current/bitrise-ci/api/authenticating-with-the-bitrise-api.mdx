現在のAPIは、2種類の認証をサポートしています。

- ユーザーが生成した<strong>personal access tokens</strong>
- Workspace API tokens

「root」URL([https://api.bitrise.io](https://api.bitrise.io))を除き、すべてのAPIエンドポイントで認証が必要です。

1. [個人アクセストークン](/bitrise-platform/accounts/personal-access-tokens#creating-a-personal-access-token)または[Workspace API トークン](/bitrise-platform/workspaces/workspace-api-token#creating-a-workspace-api-token)のいずれかを作成します。
1. 安全な方法で保存します。
1. API呼び出しに、アクセストークンを含む`Authorization`ヘッダーを追加します。

   例えば、次の呼び出しでは、ユーザーまたはWorkspaceがアクセス権を持つアプリの一覧を取得します。

   ```yaml
   curl -X 'GET' \
     'https://api.bitrise.io/v0.1/apps' \
     -H 'Authorization: <ACCESS-TOKEN>'
     -H 'accept: application/json'
   ```
