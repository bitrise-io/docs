API(およびBitriseサポートチーム)は、<GlossTerm baseform="Workspace">Workspace</GlossTerm>のスラッグやプロジェクトのスラッグをよく尋ねます。スラッグは、これらのリソースを一意に識別するもので、16進数で構成されます。特定のWorkspaceまたはプロジェクトのスラッグは、UIとAPIの両方で確認できます。

## Bitrise websiteでスラッグを確認する {#finding-a-slug-on-the-bitrise-website}

Workspaceのスラッグとプロジェクトのスラッグはどちらも、Bitrise websiteで確認できます。

<Tabs>
<TabItem value="workspace-slugs" label="Workspace slugs" default>

1. <Partial_OpeningTheWorkspaceSettingsPage />
1. <strong>Workspace settings</strong>ページで、`**General settings** from the left navigation menu.
1. Find the Workspace slug in the **Workspace information** section. You can copy the slug by clicking the copy button next to it.

   ![workspace-slug.png](/img/_paligo/uuid-c82d552a-8d31-148f-82e4-bb4ec929c183.png)

</TabItem>
<TabItem value="project-slugs" label="Project slugs">

1. Open [Bitrise CI](https://app.bitrise.io/ci) and select your project.
1. Once on the project's page, go to your browser's address bar.

   The URL will look like this: `https://app.bitrise.io/app/5c89d92-8be6-4892-b11d-efbc1fdd607`.
1. Find the hexadecimal number after the `/app/` section of the URL. That is your project's slug.

</TabItem>
</Tabs>

## Bitrise APIを使用したスラッグの確認 {#finding-a-slug-with-the-bitrise-api}

You can get the slug for all Workspaces and apps you have access to with simple API calls.

<Tabs>
<TabItem value="workspace-slugs" label="Workspace slugs" default>

1. [Authenticate](/bitrise-ci/api/authenticating-with-the-bitrise-api) with the Bitrise API.
1. Call the `GET /organizations` endpoint with your Personal Access Token:

   ```yaml
   curl -X 'GET' \
     'https://api.bitrise.io/v0.1/organizations' \
     -H 'accept: application/json' \
     -H 'Authorization: <ACCESS-TOKEN>'
   ```
1. Find the slug in the response:

   ```json
   {
     "data": [
       {
         "name": "TestOrg",
         "slug": "2dec5c71bbce73d9",
         "avatar_icon_url": "https://bitrise-public-content-production.s3.amazonaws.com/org-icons/default_avatar-09.png",
         "concurrency_count": null,
         "owners": [
           {
             "slug": "1b3f130835b1c09ef2",
             "username": "bitbot",
             "email": "bit.bot@bitrise.io"
           }
         ]
       }
     ]
   }
   ```

</TabItem>
<TabItem value="app-slugs" label="App slugs">

1. [Authenticate](/bitrise-ci/api/authenticating-with-the-bitrise-api) with the Bitrise API.
1. Call the `GET /apps`エンドポイントをPersonal Access Tokenで選択します。

   ```yaml
   curl -X 'GET' \
     'https://api.bitrise.io/v0.1/apps' \
     -H 'accept: application/json' \
     -H 'Authorization: <ACCESS-TOKEN>'
   ```
1. レスポンスからスラッグを確認します:

   ```json
   {
     "data": [
       {
         "slug": "13aa9897-3891-4fe7-8cf5-5b2f75638b0e",
         "title": "TestApp",
         "project_type": "ios",
         "provider": "github",
         "repo_owner": "bitrise",
         "repo_url": "git@github.com:bitrise/TestApp.git",
         "repo_slug": "TestApp",
         "is_disabled": false,
         "status": 1,
         "is_public": false,
         "is_github_checks_enabled": false,
         "owner": {
           "account_type": "organization",
           "name": "Bitrise",
           "slug": "03a9543ede4d12bd"
         },
         "avatar_url": null
       },
   ```

</TabItem>
</Tabs>
