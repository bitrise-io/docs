アプリケーションに関する多くのインサイトも得られるデプロイサービスをお探しの場合は、[TestFairy](https://www.testfairy.com/)がおすすめのサービスです。

不特定多数のユーザーでアプリをテストする場合、実際に何がテストされ、クライアント側で何が問題だったのかを正確に把握することはできません。TestFairyはこの問題を解決するため、CPU、メモリ、GPS、ネットワーク、ログ、クラッシュレポートなどの詳細な内部メトリクスを含む、モバイルデバイス上で起きたすべてのことを記録した動画を提供します。iOSでこれらのインサイトを得るには、[TestFairyのiOS SDKをアプリに統合する](http://docs.testfairy.com/iOS_SDK/Integrating_iOS_SDK.html)必要があります。

TestFairyプラットフォームにアプリをデプロイするには、[bitrise.io](https://www.bitrise.io)上のアプリの<GlossTerm baseform="Workflow">Workflow</GlossTerm>に<strong>TestFairy</strong> <GlossTerm baseform="Step">Step</GlossTerm>を追加するだけです。

追加する必要がある唯一のパラメーターは、TestFairyのAPI Keyです。これを取得するには、TestFairyの[アカウント設定](https://app.testfairy.com/settings/)に移動し、API Keyメニューの下にあるキーを見つけてください。

:::note[メール通知と自動アップデート]

メール通知の有効・無効を切り替えたり、通知するテスターグループを設定したりすることもできます。Stepで自動アップデートを有効にすると、ユーザーが常に最新のビルドにアップグレードするようにできるほか、動画の録画を開始してその長さを設定することもできます。

:::

あとは特に何もする必要はありません。あなたはただ素晴らしいアプリの開発に専念してください。コードを更新するたびに、アプリが自動的にTestFairyにデプロイされるようにします。
