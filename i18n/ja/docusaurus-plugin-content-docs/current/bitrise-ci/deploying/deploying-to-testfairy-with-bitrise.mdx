アプリケーションに関する豊富なインサイトも得られるデプロイサービスをお探しなら、[TestFairy](https://www.testfairy.com/)がおすすめです。

不特定多数のユーザーでアプリをテストする場合、実際に何がテストされ、クライアント側で何が問題だったのかを正確に把握することはできません。TestFairyは、モバイルデバイス上で起きたすべての出来事の動画に加え、CPU、メモリ、GPS、ネットワーク、ログ、クラッシュレポートなどの詳細な内部メトリクスを提供することで、この問題を解決します。iOSでこれらのインサイトを得るには、[TestFairyのiOS SDKをアプリに組み込む](http://docs.testfairy.com/iOS_SDK/Integrating_iOS_SDK.html)必要があります。

TestFairyプラットフォームにアプリをデプロイするには、アプリの<GlossTerm baseform="Workflow">Workflow</GlossTerm>（[bitrise.io](https://www.bitrise.io)上）に、<strong>TestFairy Deploy</strong> <GlossTerm baseform="Step">Step</GlossTerm>（iOS用）または<strong>TestFairy Deploy Android</strong> Step（Android用）を追加します。

2つのStepsは、ほとんどの入力を共有しています。違いは次のとおりです。

- <strong>TestFairy Deploy</strong>は、IPAファイルをアップロードします（デフォルトでは`$BITRISE_IPA_PATH`環境変数）。また、オプションの<strong>dSYM path</strong>入力と<strong>Private cloud endpoint</strong>入力もあります。
- <strong>TestFairy Deploy Android</strong>は、APKファイルをアップロードします（デフォルトでは`$BITRISE_APK_PATH`環境変数）。また、<strong>Icon Watermark</strong>入力もあります。

必須のパラメーターは、TestFairyのAPI Keyのみです。これを取得するには、TestFairyの[アカウント設定](https://app.testfairy.com/settings/)に移動し、API Keyメニューの下にあるキーを確認します。

:::note[メール通知と自動アップデート]

メール通知の有効化・無効化や、通知するテスターグループの設定もできます。Stepで自動アップデートを有効にすると、ユーザーが常に最新のビルドにアップグレードするようにでき、動画の録画開始とその長さの設定もできます。

:::

ほかにやることはありません。素晴らしいアプリの開発に集中してください。コードを更新するたびに、アプリは自動的にTestFairyにデプロイされます。
