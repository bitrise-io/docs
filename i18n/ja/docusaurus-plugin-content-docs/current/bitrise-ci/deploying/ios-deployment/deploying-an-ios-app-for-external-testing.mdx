アプリをApp Storeにデプロイする前に、開発環境の外部でデバイス上でテストできる外部テスターにアプリをリリースしたい場合があります。Testflightを使用しない場合は、`ad-hoc`エクスポート方法でIPAファイルをエクスポートすることでこれを行えます。

:::important[Testflightを使う]

Testflightを使用して外部テスターを招待する場合、`ad-hoc`エクスポート方法は使用できません。`app-store`エクスポート方法でIPAが必要です。

:::

1. 自分のマシンでIPAファイルを少なくとも一度生成してください。
1. Bitriseに、[必要なcode signingファイルをすべてアップロード](/bitrise-ci/code-signing/ios-code-signing/creating-a-signed-ipa-for-xcode-projects)してください。

   `ad-hoc`エクスポート方法では、Distributionタイプの証明書とAd Hocタイプのプロビジョニングプロファイルが必要です。手動プロビジョニングを使用する場合のみ、プロビジョニングプロファイルをアップロードしてください。[iOSのcode signingファイルの管理 - 手動プロビジョニング](/bitrise-ci/code-signing/ios-code-signing/managing-ios-code-signing-files---manual-provisioning)。
1. [<strong>Xcode Archive & Export for iOS</strong>](https://github.com/bitrise-steplib/steps-xcode-archive) <GlossTerm baseform="Step">Step</GlossTerm>が<GlossTerm baseform="Workflow">Workflow</GlossTerm>にあることを確認してください。
1. Stepの<strong>Distribution method</strong>入力を`ad-hoc`に設定してください。
1. <strong>Automatic code signing method</strong>入力を、code signingに使用するApple service connectionに設定してください。使用できるオプションは次のとおりです。

   - automatic code signingを行わない場合は`off`。
   - `api-key` [if you use API key authorization](/bitrise-platform/integrations/apple-services-connection/about-connecting-to-apple-services)。
   - `apple-id` [if you use Apple ID authorization](/bitrise-platform/integrations/apple-services-connection/about-connecting-to-apple-services)。
1. [<strong>Deploy to Bitrise.io</strong>](https://github.com/bitrise-steplib/steps-deploy-to-bitrise-io) StepがWorkflowにあることを確認してください。
1. ビルドを開始してください。
1. ビルドが完了したら、アプリの<strong>Builds</strong>ページに移動し、最新のビルドをクリックしてください。
1. <strong>Artifacts</strong>タブをクリックして、配布可能なIPAファイルを見つけてください。
