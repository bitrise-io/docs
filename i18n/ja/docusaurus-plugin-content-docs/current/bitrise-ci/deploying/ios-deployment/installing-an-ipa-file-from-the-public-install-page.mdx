Bitrise ビルドで生成された .ipa ファイルは、次の 2 つの方法でテストデバイスにインストールできます。

- [公開インストールページを使用する](#installing-an-ipa-file-on-test-devices-from-the-public-install-page)。公開インストールページは、生成された URL で、アプリのプロビジョニングが済んでいる iPhone または iPad を持つ人であれば誰とでも共有できます。 Bitrise アカウントは不要です。
- Bitrise のビルドページの <strong>Artifacts</strong> タブを[使用する](#installing-an-ipa-file-on-test-devices-from-the-artifacts-tab)。この方法は Bitrise ユーザーのみが利用できます。

## 公開インストールページの表示内容 {#what-the-public-install-page-shows}

ページには、アプリ、そのバージョン、ビルドの詳細が表示されます。 <strong>Install this version</strong> セクションの表示内容は、ページを開いたデバイスによって異なります。

| 表示 | 意味 | 対処方法 |
|---|---|---|
| <strong>Install through Safari</strong> | Safari 以外のブラウザーでページを開いています。 | Safari でページを開いてください。 |
| <strong>Check compatibility</strong> | Bitrise がデバイスをまだ認識しておらず、 Safari で Bitrise にログインしていません。 | <strong>Check compatibility</strong> をタップして、[登録プロファイルをインストール](#installing-an-app-on-a-test-device-without-a-bitrise-account)します。 |
| <strong>Register device</strong>（デバイスがアカウントに登録されていないというメッセージ付き） | Safari で Bitrise にログインしていますが、デバイスがアカウントに登録されていません。 | <strong>Register device</strong> をタップして、[デバイスを登録](#installing-an-app-on-a-test-device-not-registered-to-bitrise)します。 |
| <strong>App not allowed to be installed on this device</strong> | デバイスがアプリのプロビジョニングプロファイルに含まれていません。 | チームの管理者にデバイスの追加とアプリの再ビルドを依頼してください。古いデバイスの設定をこのデバイスに復元した場合は、 <strong>clear your cache</strong> を選択してから、もう一度デバイスを登録してください。 |
| <strong>App cannot be installed on this device</strong> | デバイスタイプまたは iOS バージョンがアプリの要件を満たしていません。メッセージに理由が表示されます。 | 互換性のあるデバイスを使用するか、 iOS を更新してください。 |
| <strong>Install</strong> | デバイスはインストールの準備ができています。 | <strong>Install</strong> をタップします。 |
| <strong>This version is intended for distribution via the App Store</strong> | .ipa ファイルが App Store 配布向けです。 | テストデバイスにインストールするには、開発、アドホック、またはエンタープライズ配布向けにアプリをビルドしてください。 |

:::note[Safari 16.3 以前]

Safari 16.3 以前では、ページのレイアウトがよりシンプルになります。実行できる操作とボタンの名前は同じで、一部のメッセージの表現のみが少し異なります。

:::

## 公開インストールページからテストデバイスに .ipa ファイルをインストールする {#installing-an-ipa-file-on-test-devices-from-the-public-install-page}

公開インストールページは、アプリの latest version を、チームメンバーや、アプリを確認したいその他の関係者と共有するのに便利な方法です。

<strong>Deploy to Bitrise.io</strong> <GlossTerm baseform="step">Step</GlossTerm> を設定すると、公開インストールページへのリンクを記載したメールをユーザーに送信できます。このリンクは誰とでも共有できます。

:::tip[アプリをダウンロードしたい場合]

アプリをダウンロードして手動で別の場所にアップロードするだけの場合は、ビルドの <strong>Artifacts</strong> タブで、ファイルの横にあるダウンロードアイコンを使用してください。アプリをダウンロードしても、テストデバイスにインストールできるわけではありません。

:::

### Bitrise アカウントなしでテストデバイスにアプリをインストールする {#installing-an-app-on-a-test-device-without-a-bitrise-account}

1. <Partial_CheckingTheRequirementsForInstallingAnIpaFile />
1. 公開インストールページへのリンクを、アプリ内ブラウザーではなく、 Safari の通常モード（非プライベートモード）で開きます。

   リンクをコピーした場合は、 Safari に貼り付けてください。他のブラウザーでは、ページに <strong>Install through Safari</strong> メッセージが表示され、 .ipa ファイルのダウンロードしかできません。 iPad では、デフォルト設定の Safari を使用してください。モバイル版のウェブサイトをリクエストする必要はありません。

1. <strong>Check compatibility</strong> をタップします。

   このボタンは、互換性チェックのために、デバイスの UDID を Bitrise に提供する構成プロファイルをダウンロードします。

1. <Partial_InstallingTheDeviceRegistrationProfile />
1. 公開インストールページで <strong>Install</strong> をタップします。

   このボタンは、デバイスに互換性があり、アプリのプロビジョニングプロファイルに含まれている場合にのみ利用できます。

   <img src={require('@site/static/img/ios-deployment/2026-11-12-public-install-page-install-button.png').default} alt="The Install this version section of the public install page with the Install button" width="260" />

1. アプリをインストールするかどうかを尋ねる iOS のプロンプトを確認し、ホーム画面に移動してインストールの進行状況を確認します。

インストールが完了すると、テストデバイスのホーム画面にアプリが表示されます。

### Bitrise に登録されていないテストデバイスにアプリをインストールする {#installing-an-app-on-a-test-device-not-registered-to-bitrise}

Safari で Bitrise にログインしていて、公開インストールページにデバイスがアカウントに登録されていないことと <strong>Register device</strong> ボタンが表示されている場合は、 Bitrise にデバイスを登録する必要があります。上記のフローと比べて、手順が少し増えるだけです。

テストデバイスを登録できるのは、 Bitrise アカウントをお持ちの場合のみです。詳細は[テストデバイスの登録](/bitrise-ci/testing/testing-ios-apps/registering-a-test-device)を参照してください。

1. <Partial_CheckingTheRequirementsForInstallingAnIpaFile />
1. Safari で Bitrise にログインした状態で、公開インストールページへのリンクを Safari の通常モード（非プライベートモード）で開きます。

   iPad では、デフォルト設定の Safari を使用してください。

1. <strong>Register device</strong> をタップします。
1. <Partial_InstallingTheDeviceRegistrationProfile />
1. 登録ページで、 <strong>Title</strong> と <strong>Device Unique Identifier</strong> の各フィールドを確認します。

   Bitrise は、両方のフィールドにデバイスの名前と UDID を入力します。変更できるのはタイトルのみです。

1. <strong>Register device</strong> をタップします。

   Bitrise が公開インストールページに戻します。

1. <strong>Install</strong> をタップします。

   代わりにページに <strong>App not allowed to be installed on this device</strong> と表示される場合は、デバイスがまだアプリのプロビジョニングプロファイルに含まれていません。 Apple Developer アカウントでデバイスを追加し、アプリを再ビルドしてください。

1. アプリをインストールするかどうかを尋ねる iOS のプロンプトを確認し、ホーム画面に移動してインストールの進行状況を確認します。

インストールが完了すると、テストデバイスのホーム画面にアプリが表示されます。

## Artifacts タブからテストデバイスに .ipa ファイルをインストールする {#installing-an-ipa-file-on-test-devices-from-the-artifacts-tab}

ビルドの <strong>Artifacts</strong> タブから .ipa ファイルをインストールできます。この方法は公開インストールページよりも安全ですが、テストデバイスで Bitrise アカウントにログインする必要があります。そのため、外部のテスターには適していません。

<strong>Artifacts</strong> タブから .ipa ファイルをインストールするには、次の手順を実行します。

1. <Partial_CheckingTheRequirementsForInstallingAnIpaFile />
1. <Partial_AccessingBuildsTabAndSelectingABuild />
1. <strong>Artifacts</strong> タブを開きます。
1. <strong>Installable app packages</strong> セクションで .ipa ファイルを見つけ、横にある矢印アイコン（<strong>View artifact</strong>）をクリックします。

   ダウンロードアイコンでは、ファイルがダウンロードされるだけです。

1. アーティファクトページで、テストデバイスで QR コードをスキャンするか、 <strong>Copy page URL</strong> をクリックして、デバイスでリンクを開きます。

   Safari の通常モードで開き、 Safari からログインを求められた場合は Bitrise にログインしてください。このページでは認証が必要です。

1. ページに <strong>Register this device</strong> と表示された場合は、 <strong>Register device</strong> をタップして、画面の指示に従います。

   詳細は[テストデバイスの登録](/bitrise-ci/testing/testing-ios-apps/registering-a-test-device)を参照してください。

1. <strong>Install</strong> をタップし、アプリをインストールするかどうかを尋ねる iOS のプロンプトを確認します。

:::note[コンピューターへのインストール]

アーティファクトページを Safari 以外のブラウザーで開くと、 <strong>Install</strong> は表示されません。 <strong>Install through Safari</strong> メッセージ、 <strong>Download artifact</strong> 、 <strong>Copy page URL</strong> のみが表示されます。

:::

同じページには <strong>Public install link</strong> セクションがあり、公開インストールページへのリンクを取得したり、使用できるユーザーを管理したりできます。
