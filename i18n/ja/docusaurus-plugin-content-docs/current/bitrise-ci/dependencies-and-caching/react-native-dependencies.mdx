[npm](https://docs.npmjs.com/)と[Yarn](https://yarnpkg.com/)はどちらもNode.jsのパッケージマネージャーです。プロジェクトの依存関係や、グローバルにインストールされたJavascriptツールを管理できます。モバイル開発では、React Nativeプロジェクトのパッケージマネージャーとしてよく使用されます。Bitrise上にReact Nativeアプリがある場合は、専用のnpmまたはYarnの<GlossTerm baseform="Step">Steps</GlossTerm>を使用して依存関係をインストールし、キャッシュできます。

専用のStepsを使用してネイティブの依存関係をインストールすることもできます: [React Nativeアプリのネイティブ依存関係をインストールする](#installing-native-dependencies-for-a-react-native-app)。

## Installing dependencies with npm and Yarn

<Tabs>
<TabItem value="npm" label="npm" default>

1. プロジェクトに[package.jsonファイル](https://docs.npmjs.com/creating-a-package-json-file)が定義されていることを確認してください。
1. [<strong>Run npm command</strong>](https://github.com/bitrise-steplib/steps-npm) Stepを<GlossTerm baseform="Workflow">Workflow</GlossTerm>に追加してください。
1. <strong>The npm command with arguments to run</strong>を`install`に設定してください。

   `install`コマンドには追加のオプションを指定できます。たとえば、[React Nativeプロジェクトにネイティブ依存関係を持つライブラリをリンクする](https://docs.flutter.dev/development/packages-and-plugins/developing-packages#dependencies)必要がある場合は、`--save`または`--save-dev`フラグを使用してください。使用できるオプションについては、[npmドキュメント](https://docs.npmjs.com/cli/v9/commands/npm-install)を参照してください。

   ![run-npm-command.png](/img/_paligo/uuid-676b848d-85db-ff48-883e-6ca489d799d3.png)
1. 必要に応じて、<strong>使用するnpmのVersion</strong>入力で、`npm install`コマンドを実行する[npmのバージョン](https://www.npmjs.com/package/npm?activeTab=versions)を設定できます。

</TabItem>
<TabItem value="yarn" label="Yarn">

1. プロジェクトに[package.jsonファイル](https://docs.npmjs.com/creating-a-package-json-file)が定義されていることを確認してください。
1. [<strong>Run yarn command</strong>](https://github.com/bitrise-community/steps-yarn) StepをWorkflowに追加してください。
1. <strong>実行するYarnコマンド</strong>を`install`に設定してください。
1. 必要に応じて、<strong>Arguments for running yarn commands</strong>でyarnコマンドに引数を追加してください。

   複数の引数を指定する場合は、スペースで区切ります。

</TabItem>
</Tabs>

## Caching npm and Yarn dependencies

キー基準のキャッシュを使う場合、node_modulesをキャッシュするには[<strong>NPMキャッシュを復元する</strong>](https://github.com/bitrise-steplib/bitrise-step-restore-npm-cache)と[<strong>Save NPMキャッシュ</strong>](https://github.com/bitrise-steplib/bitrise-step-save-npm-cache)のStepsのみが必要です。これらのStepsは、依存関係に必要なcache keysを自動的に設定するため、設定は不要です。

1. [<strong>NPMキャッシュを復元する</strong>](https://github.com/bitrise-steplib/bitrise-step-restore-npm-cache) StepをWorkflowの最初に追加してください。

   ![restore-npm-cache.png](/img/_paligo/uuid-68fb84b2-a10a-f7b9-f1e3-7ab0accbae3a.png)
1. [<strong>Save NPMキャッシュ</strong>](https://github.com/bitrise-steplib/bitrise-step-save-npm-cache) StepをWorkflowの最後に追加してください。

## Installing native dependencies for a React Native app

`ios`フォルダーと`android`フォルダーで宣言されているネイティブ依存関係をインストールする必要がある場合があります。たとえば、`Podfile`で定義されているCocoaPodsの依存関係です。これはBitriseでも簡単に行えます: React NativeアプリをAndroidとiOSのバイナリをビルドできる状態にバンドルすれば、AndroidとiOSアプリ向けの依存関係マネージャーStepsを使用するだけです。

:::tip[デモアプリ]

動作する例としてReact Nativeデモアプリをご確認ください。このアプリをBitriseに追加すると、たとえば<strong>deploy-ios-release</strong>Workflowに、npmパッケージとpodsの両方をインストールするための[<strong>Run npm command</strong>](https://github.com/bitrise-steplib/steps-npm)と[<strong>Run CocoaPods install</strong>](https://github.com/bitrise-io/steps-cocoapods-install)Stepsの両方が含まれていることがわかります: [React Nativeデモアプリ](https://github.com/bitrise-io/react-native-demo-app)。

:::

1. Workflowがnpmパッケージをインストールすることを確認してください: [npmとYarnで依存関係をインストールする](#installing-dependencies-with-npm-and-yarn)。

   npmパッケージのインストールのみを担当する別のWorkflowを用意し、メインのWorkflowの前に実行されるように挿入することもできます: [Workflowsを連結する](/bitrise-ci/workflows-and-pipelines/workflows/managing-workflows#chaining-workflows-together)。これは[ユーティリティWorkflow](/bitrise-ci/workflows-and-pipelines/workflows/managing-workflows#utility-workflows)にすることもできます。
1. [<strong>React Native Bundle</strong>](https://github.com/bitrise-steplib/steps-react-native-bundle) StepをWorkflowに追加してください。

   これはnpmパッケージのインストール後に実行される必要があります。
1. 必要な依存関係マネージャーのStepsまたはビルドStepsをWorkflowに追加してください。必要なStepsは、プロジェクトの種類と使用する依存関係マネージャーによって異なります。

   - [Androidの依存関係](/bitrise-ci/dependencies-and-caching/android-dependencies)
   - [SPMでの依存関係の管理](/bitrise-ci/dependencies-and-caching/ios-dependencies/managing-dependencies-with-spm)
   - [CocoaPodsでの依存関係の管理](/bitrise-ci/dependencies-and-caching/ios-dependencies/managing-dependencies-with-cocoapods)
   - [Carthageでの依存関係の管理](/bitrise-ci/dependencies-and-caching/ios-dependencies/managing-dependencies-with-carthage)
