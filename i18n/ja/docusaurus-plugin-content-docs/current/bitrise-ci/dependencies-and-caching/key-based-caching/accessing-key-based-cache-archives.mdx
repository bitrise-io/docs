ビルドを実行しなくても、キャッシュアーカイブに個別にアクセスできます。これにより、次のような情報を確認できます。

- どのcache keysが各キャッシュアーカイブに関連付けられているか。
- キャッシュアーカイブが占有しているストレージ容量。
- 各キャッシュアーカイブの有効期限。

さらに、有効期限が切れていないキャッシュアーカイブはダウンロードでき、cache keysをコピーしたり、アーカイブを削除したりすることもできます。

アーカイブにアクセスするには:

1. <Partial_GettingToTheProjectSettingsPage />
1. 左側で<strong>Dependency cache</strong>を選択します。
1. キャッシュアーカイブの横にあるアクションメニューをクリックし、次のいずれかを選択します。

   - <strong>Copy key</strong>: cache keyをコピーします。
   - <strong>Download</strong>: キャッシュアーカイブをダウンロードします。
   - <strong>Delete</strong>: キャッシュアーカイブを削除します。

:::note
キャッシュアーカイブは[Zstandard](https://github.com/facebook/zstd)で圧縮されています。ダウンロードしたアーカイブを解凍するには、`zstd`をインストールしてから`zstd -d cache.tzst`を実行してください。
:::
