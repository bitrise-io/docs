キー基準のキャッシュは強力で柔軟です。[<strong>Save cache</strong>](https://github.com/bitrise-steplib/bitrise-step-save-cache) と [<strong>Restore cache</strong>](https://github.com/bitrise-steplib/bitrise-step-restore-cache) <GlossTerm baseform="Step">Steps</GlossTerm>は、プラットフォームやキャッシュしたいデータの種類を問わず、どのプロジェクトでも使用できます。ただし、これらのStepsには慎重な設定が必要で、ミスが発生する可能性もあります。よく使われる依存関係マネージャーの依存関係をキャッシュするシンプルな方法をお探しの場合は、設定が一切不要な専用のStepsを提供しています。

専用のキャッシュStepsは、[<strong>Save cache</strong>](https://github.com/bitrise-steplib/bitrise-step-save-cache) と [<strong>Restore cache</strong>](https://github.com/bitrise-steplib/bitrise-step-restore-cache) Stepsと同じストレージ領域にアーカイブを保存しますが、この2つとは異なり、適切なキャッシュパスとcache keysを自動的に設定します。

次の専用のStepsを利用できます。

- [<strong>Save Cocoapods Cache</strong>](https://github.com/bitrise-steplib/bitrise-step-save-cocoapods-cache) と [<strong>Restore Cocoapods Cache</strong>](https://github.com/bitrise-steplib/bitrise-step-restore-cocoapods-cache): [CocoaPodsを使った依存関係の管理](/bitrise-ci/dependencies-and-caching/ios-dependencies/managing-dependencies-with-cocoapods).
- [<strong>Save SPM Cache</strong>](https://github.com/bitrise-steplib/bitrise-step-save-spm-cache) と [<strong>Restore SPM Cache</strong>](https://github.com/bitrise-steplib/bitrise-step-restore-spm-cache): [SPMを使った依存関係の管理](/bitrise-ci/dependencies-and-caching/ios-dependencies/managing-dependencies-with-spm).
- [<strong>Save NPM Cache</strong>](https://github.com/bitrise-steplib/bitrise-step-save-npm-cache) と [<strong>Restore NPM Cache</strong>](https://github.com/bitrise-steplib/bitrise-step-restore-npm-cache): [React Nativeの依存関係](/bitrise-ci/dependencies-and-caching/react-native-dependencies).
- [<strong>Save Gradle Cache</strong>](https://github.com/bitrise-steplib/bitrise-step-save-gradle-cache) と [<strong>Restore Gradle Cache</strong>](https://github.com/bitrise-steplib/bitrise-step-restore-gradle-cache): [Androidの依存関係](/bitrise-ci/dependencies-and-caching/android-dependencies).
- [<strong>Save Carthage Cache</strong>](https://github.com/bitrise-steplib/bitrise-step-save-carthage-cache) と [<strong>Restore Carthage Cache</strong>](https://github.com/bitrise-steplib/bitrise-step-restore-carthage-cache): [Carthageを使った依存関係の管理](/bitrise-ci/dependencies-and-caching/ios-dependencies/managing-dependencies-with-carthage).
- [<strong>Save Dart Cache</strong>](https://github.com/bitrise-steplib/bitrise-step-save-dart-cache) と [<strong>Restore Dart Cache</strong>](https://github.com/bitrise-steplib/bitrise-step-restore-dart-cache): [Flutterの依存関係](/bitrise-ci/dependencies-and-caching/flutter-dependencies).

これらのStepsを使用するには、<GlossTerm baseform="Workflow">Workflow</GlossTerm>の先頭にRestoreバージョンを追加し、Workflowの末尾にSaveバージョンを追加するだけです。他の設定は必要ありません。
