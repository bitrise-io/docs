<GlossTerm baseform="Stack">スタック</GlossTerm>をすべて永久に維持し続けるわけではありません。目的は、できる限り優れたアプリをビルドするのに役立つ最新のツールを提供することです。ただし、スタックが更新されるたびにビルド設定を見直す必要はありません。信頼できる古いスタックを長期間使い続けることができます。

Xcodeの新しいメジャーバージョンがリリースされると、一部の古いスタックは凍結されます。スタックが凍結されても引き続き使用できますが、それ以降は更新が提供されなくなるため、その時点で新しいアクティブなスタックに切り替えることを強くおすすめします。

スタックが凍結されてから1年が経過すると、Xcodeの次のメジャーバージョンがリリースされたタイミングで削除されます。
