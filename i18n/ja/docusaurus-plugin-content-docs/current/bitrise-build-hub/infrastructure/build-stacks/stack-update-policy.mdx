Bitrise<GlossTerm baseform="stack">スタック</GlossTerm>には、モバイル開発に欠かせない主要なツールがあらかじめインストールされており、すぐに使用できます。私たちの目標は、<GlossTerm baseform="Workflow">Workflows</GlossTerm>をシンプルにし、ビルドを高速かつ効率的にすることです。これらのツールは継続的に変化します。古いバージョンは非推奨となりサポートが終了する一方、新しいバージョンは新機能や破壊的変更を伴ってリリースされます。

Stacksは、[bitrise.io](https://www.bitrise.io)で定期的に更新されます。更新には、次のいずれか、または複数の変更が含まれます。

- ツールのアップグレード: すでにインストールされているツールがlatest versionにアップグレードされます(例: gitのCLIが2.9.1から2.9.5にアップグレードされます)。
- ツールの追加: 新しいツールが追加されます(例: 新しいAndroidバージョンがリリースされると、最新のAndroidエミュレーターシステムイメージがプリインストールされます)。
- ツールの削除: ツールのバージョンがエンドオブライフを迎えセキュリティリスクとなる場合は削除され、別のバージョンがデフォルトになります(例: Ruby 2.7が削除され、Ruby 3.0が新しいデフォルトになります)。
- プラットフォームの変更: macOSスタック上のXcode、OSのバージョン、AndroidSDKなど、主要コンポーネントへの変更。

LinuxとMacOSのスタック更新ポリシーについて詳しくは、以下をご覧ください。

- [macOSスタック更新ポリシー](/bitrise-build-hub/infrastructure/build-stacks/macos-stack-update-policy)
- [Linuxスタック更新ポリシー](/bitrise-build-hub/infrastructure/build-stacks/linux-stack-update-policy)

:::note[以前のバージョンのスタックを使用する]

スタックを新しいバージョンに更新すると、一部のビルドで問題が発生することがあります。移行をスムーズにするため、更新後2〜3日間は以前のバージョンのスタックを使用できます。詳しくは[以前のバージョンのスタックを使用する](/bitrise-build-hub/infrastructure/build-stacks/stack-update-policy#using-the-previous-version-of-a-stack)をご覧ください。

:::

さまざまなスタックで利用可能なツールの詳細については、関連ガイドをご覧ください: [Bitriseスタックにプリインストールされているツール](/bitrise-platform/infrastructure/build-stacks/preinstalled-tools-on-bitrise-stacks)
