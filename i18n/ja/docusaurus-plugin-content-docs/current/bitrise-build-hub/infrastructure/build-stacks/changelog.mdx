## 2025年6月

<strong>変更</strong>

Linuxスタックの更新ポリシーについての記載は、専用ページの[Linuxスタックの更新ポリシー](/bitrise-build-hub/infrastructure/build-stacks/linux-stack-update-policy)に移動しました。Edge、Stable、Frozenの各スタックに関するより詳しい情報に加えて、新しいLinuxスタックの年次リリースサイクルや、古いLinuxスタックの非推奨化および削除についても説明しています。

以前のバージョンのスタックの使用方法をこのページから削除し、[Stack更新ポリシー](/bitrise-build-hub/infrastructure/build-stacks/stack-update-policy)に追加しました。

## 2024年7月

<strong>削除</strong>:

依存関係マネージャーのキャッシュ更新についての記載。CocoapodsとHomebrewはいずれも、レジストリのgitリポジトリ全体をクローンするよりも優れた仕組みを備えるようになり、これらの新しい仕組み(Cocoapods CDN、Homebrew API)が現在スタックで有効になっています。スタックが更新されると、ディスク上のリポジトリは最新の状態になりますが、ほかにリリースすべき変更がない場合、Stableスタックは毎週厳密に更新されるわけではなくなりました。

<strong>変更</strong>:

stable macOSスタックへの破壊的変更(新しいXcodeメジャーバージョンがリリースされる年1回のタイミング)は、既存の古いstableスタックには適用されなくなり、新しくリリースされるstableスタックにのみ適用されます。例えば、Xcode 16.0がリリースされると、計画されている破壊的変更はXcode 16.0のstableスタックにのみ適用されます。Xcode 14.xおよび15.xのstableスタックには破壊的変更は適用されません。

## 2024年3月

<strong>New</strong>:

Edgeスタックが新しいEdgeスタックに置き換えられて段階的に廃止される際の挙動を定義しました。

<strong>削除</strong>:

新しいXcode Edgeスタックがリリースされても、Stableスタックにツールの変更がもたらされることはなくなりました。

<strong>変更</strong>:

新しく、よりシンプルなシミュレーターランタイムポリシーです。従来と同じ数の古いiOSメジャーバージョンがインストールされますが、それぞれ最新のマイナーバージョンのみがインストールされます。
