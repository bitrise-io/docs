ビルド<GlossTerm baseform="Stack">スタック</GlossTerm>は、ビルドの実行に使用する仮想マシンのバージョンを示します。主なスタックの種類は次のとおりです。

- <strong>macOSスタック</strong>: これらのスタックはmacOSオペレーティングシステム上で実行され、それぞれ複数のXcodeバージョンが含まれています。iOSアプリのビルドに最適です。クロスプラットフォームアプリをビルドする場合に使用できるAndroidツールもインストールされています。
- <strong>Android & Docker</strong> スタック: これらのスタックはDocker環境のLinuxオペレーティングシステム上で実行されます。すべてのAndroidツールがインストールされており、ネイティブAndroidアプリのビルドに最適です。

:::note[空きディスク容量]

各スタックには少なくとも100 GBの空きディスク容量があります。各スタックの正確な利用可能ディスク容量は、関連するスタックレポートページで確認できます: [Bitriseスタックレポート](https://stacks.bitrise.io/stack_reports/)。

:::

各ビルドは専用の仮想マシンで実行され、ビルドが完了すると、仮想マシンは保存された状態(「ベースボックス」状態)にロールバックされます。これにより、<strong>ビルドは常に保護され</strong>、他のユーザーや過去のビルドによる変更の影響を受けません。また、ビルドが完了するたびに状態がリセットされるため、<strong>安定した環境</strong>を使ってビルドワークフローを定義できます。

:::note[パスワードなしのsudoが有効]

ビルドに使用されるユーザーアカウントは、<strong>パスワードなしのsudo</strong>が有効になるように設定されています。これにより、ビルドやその他の自動化に必要な追加のものをすべて自分でインストールできます。選択したスタックにツールがプリインストールされていない場合は、ガイドを参照して自分でインストールできます。

:::

アプリをBitriseに追加すると、適切なスタックが自動的に選択されます。スタックは、<GlossTerm baseform="workflow editor">Workflow Editor</GlossTerm>の<strong>Stacks & Machines</strong>タブでいつでも変更できます。

![xcode_image.png](/img/_paligo/uuid-fc53715a-add5-8c4c-d4a6-9a04f5da6d3b.png)

使用したいスタックを選択すると、そのスタックの簡単な説明と、その特定のスタックについて詳しく知るための追加リンクが表示されます(たとえば、選択したスタックにどのツールがプリインストールされているか、またそのバージョンを確認できます)。

| Type | Description |
| --- | --- |
| Stable | 一般提供されており、当面の間サポートされる見込みです。スタックの主要ツールの更新が利用可能になると更新されます。例: Xcode 7.3.1がリリースされたとき、Xcode 7.3スタックは7.3(.0)ではなく7.3.1に更新されました。 |

| Type | Description |
| --- | --- |
| Pre-booted | スタックがプリブート済みとして利用可能で、そのスタック構成のプリブート済みマシンが十分にある場合、ビルド環境の起動を待たずに、ビルドをすぐに開始できます。そのスタック構成のプリブート済みマシンが利用できなくなった場合、ビルドはオンデマンド構成で開始されます。 |
| On-demand | スタックがオンデマンド構成として利用可能で、そのスタックのプリブート済み構成が(利用可能なものが)ない場合、ビルドが開始されるときにシステムが選択した構成の仮想マシンを作成する必要があります。これは、関連する仮想マシンが作成・起動されている間、ビルドが環境準備中の状態になることを意味します。macOS構成の場合、起動プロセスには通常1〜1.5分かかります。準備時間はもちろんビルド時間にはカウントされず、ビルドを実行できる時間には影響しません。 |
