Bitriseは、計画からモニタリングまで、モバイル開発プロセスのあらゆる段階を支えるMobile DevOpsプラットフォームです。このプラットフォームは、インフラストラクチャや環境の管理に伴う中断や負荷を取り除きながら、モバイル開発チームが好みのツールで高品質なアプリを構築するために必要なリソースを提供します。

サインアップしてworkspaceを作成すると、Bitriseが提供するすべての機能の基盤が整います。

- [Bitrise CI](/bitrise-ci): 自動化されたWorkflowとトリガーにより、テスト、オンボーディング、メンテナンスにかかる時間を削減します。
- [Release Management](/release-management): iOSおよびAndroidアプリを、テスターへ、またはアプリストアへ直接、簡単に配布できます。すべて、お好みのCIから1つのプラットフォームで行えます。
- [Build Cache](/bitrise-build-cache): 完全マネージド型のリモートキャッシュソリューションです。Gradle、Bazel、Xcodeで構築されたアプリや、React NativeプロジェクトのCIビルドとテストの所要時間を短縮します。
- [Insights](/insights): Insightsのビルド、テスト、クレジットのデータにより、優先すべき事項を把握し、CI/CDWorkflowを最適化できます。

プラットフォームのドキュメントでは、これらの製品に共通する構造について説明します。内容は次のとおりです。

- [アカウント](/bitrise-platform/accounts/accounts-overview): Bitriseアカウントへのサインアップ方法と、アカウントを管理するためのオプションについて説明します。
- [Workspaces](/bitrise-platform/workspaces/workspaces-overview): Workspacesでは、プロジェクトの管理やチームメンバーとの共同作業を行えます。CIビルドの実行、Release Managementアプリの管理、BitriseBuild Cacheの利用には、workspaceが必要です。
- [プロジェクト](/bitrise-platform/projects/projects-overview): Bitriseprojectは、モバイルアプリのビルド、テスト、配布など、Mobile DevOpsプロセスのすべての段階に対応できます。
- [連携](/bitrise-platform/integrations/about-integrations): Bitriseは、あらゆる段階で好みのツールや環境を使用できるよう、多数の連携をサポートしています。
