複数のチームにデプロイする場合や、これまで使用していた接続とは異なる認証を使用するチームにデプロイする場合は、<GlossTerm baseform="step">Step</GlossTerm>の入力に希望する認証情報を追加できます。これにより、<strong>Bitrise Developer Connection</strong>で以前に設定した接続が上書きされます。

この方法により、接続は認証を設定したStepに制限されます。

:::important[2FAとApple ID認証]

Apple IDに2FAが必要な場合は、Step inputs経由で認証する代わりに、[<strong>Deploy to App Store Connect with Deliver (formerly iTunes Connect)</strong>](https://github.com/bitrise-steplib/steps-deploy-to-itunesconnect-deliver)と[<strong>fastlane</strong>](https://github.com/bitrise-io/steps-fastlane)のStepsでApple ID認証を使用する必要があります。

:::


## APIキーを使用したStepでの認証 {#authenticating-in-a-step-with-api-key}

<Tabs>
<TabItem value="api-key-apple-id" label="API-key & Apple ID" default>

1. 次のいずれかのStepsを<GlossTerm baseform="workflow">Workflow</GlossTerm>に追加します：

   - fastlane
   - Deploy to App Store Connect with Deliver (formerly iTunes Connect)
   - Deploy to App Store Connect - Application Loader (formerly iTunes Connect)

   :::caution[Step inputsにおけるAPIキーまたはApple ID認証のいずれか]

   Stepに追加できる認証の種類は、APIキーまたはApple IDのいずれか一方のみです。いずれの場合も、<strong>Bitrise Apple Developer Connection</strong>入力が`off`に設定されていることを確認してください。設定されていない場合、Stepは<strong>Apple Service connection</strong>で設定された認証方法を使用します（<strong>Stores</strong>タブで接続を削除することを選択しない限り）。

   :::
1. <strong>Code Signing & Files</strong>タブの<strong>GENERIC FILE STORAGE</strong>セクションにAPIキーをアップロードします。
1. <strong>Bitrise Apple Developer Connection</strong>入力を`off`に設定します。
1. Stepの該当するフィールドで、<strong>Issuer ID</strong>をシークレットの環境変数として設定します。
1. <strong>API Keyパス</strong>と<strong>API Issuer</strong>の入力を設定します。
1. 変更を保存し、新しいビルドを実行します。

</TabItem>
<TabItem value="api-key-only-steps" label="API-key only Steps">

1. 次のいずれかのStepsをWorkflowに追加します：

   - Manage iOS Code Signing
   - Xcode Archive & Export for iOS
   - iOSおよびtvOSのXcode archiveをエクスポート
   - Xcode Build for testing for iOS
1. <strong>Code Signing & Files</strong>タブの<strong>Generic File Storage</strong>に、App Store Connect APIのプライベートキーファイル（.p8ファイル）をアップロードします。
1. <strong>Automatic code signing method</strong>を`api-key`に設定します。Manage iOS Code Signingの場合、対応する入力は<strong>Apple service connection method</strong>という名前です。
1. <strong>App Store Connect connection override</strong>入力グループで、次のStep inputsを設定します：

   - <strong>App Store Connect API private key</strong>：App Store Connect API用のプライベートキー（.p8ファイル）へのローカルパスまたはリモートURL。この入力には、手順2でGeneric File StorageにアップロードしたApp Store Connect APIのプライベートキーファイル（.p8ファイル）に接続された、自動生成されるEnv Varを設定します。
   - <strong>App Store Connect API key ID</strong>：App Store Connect認証に使用するプライベートkey ID。
   - <strong>App Store Connect API issuer ID</strong>：App Store Connect認証に使用するプライベートキーissuer ID。

</TabItem>
</Tabs>


## Apple IDとパスワードを使用したStepでの認証 {#authenticating-in-a-step-with-apple-id-and-password}

:::caution[Step inputsにおけるAPIキーまたはApple ID認証のいずれか]

Stepに追加できる認証の種類は、APIキーまたはApple IDのいずれか一方のみです。いずれの場合も、<strong>Bitrise Apple Developer Connection</strong>入力が`off`に設定されていることを確認してください。設定されていない場合、Stepは<strong>Apple Service connection</strong>で設定された認証方法を使用します（<strong>Stores</strong>タブで接続を削除することを選択しない限り）。

:::

1. StepをWorkflowに追加します。
1. <strong>Apple ID</strong>と<strong>Password</strong>を設定します。
1. <strong>Bitrise Apple Developer Connection</strong>入力を`off`に設定します。
1. 変更を保存し、新しいビルドを実行します。
