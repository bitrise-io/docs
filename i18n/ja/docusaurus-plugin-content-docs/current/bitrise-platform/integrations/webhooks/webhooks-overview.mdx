Webhookは、リポジトリへのコードのプッシュなど、何らかのイベントによってトリガーされるユーザー定義のコールバックです。BitriseはWebhookを幅広く活用しています。

- Incoming webhooksはGitサービスプロバイダーに登録され、Bitrise上での[ビルドの自動トリガー](/bitrise-ci/run-and-analyze-builds/build-triggers/configuring-build-triggers)や、[Git Insights](/insights/git-insights)の利用を可能にするために使用されます。

  :::note[Webhookの問題]

  ビルドのトリガーが機能しない場合は、Webhookに問題がある可能性があります。[ビルドがトリガーされない](https://support.bitrise.io/hc/en-us/articles/360014238237)を参照してください。

  :::
- Outgoing webhooksは、Slackなどの他のサービスにビルドイベントのレポートを送信するために使用されます。

受信Webhookは、アプリの作成時またはその後に自動的に追加できます。また、サポートされている任意のサービスに手動でWebhookを追加することも可能です。

送信Webhookは、ウェブサイト上、または[BitriseのAPI](/bitrise-ci/api/incoming-and-outgoing-webhooks)から追加できます。
