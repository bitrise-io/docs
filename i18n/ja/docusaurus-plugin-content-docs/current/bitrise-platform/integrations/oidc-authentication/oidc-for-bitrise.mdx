Open ID Connect (OIDC) 信頼ポリシーを作成し、`app.bitrise.io`をオーディエンスとしてOIDCトークンを送信することで、OIDCの認証情報交換を行います。これにより、サードパーティサービスがBitrise <GlossTerm baseform="workspace">workspace</GlossTerm>に対して認証を行い、Bitriseリソースにアクセスできるようになります。

OIDCの仕組みについて詳しくは、[BitriseへのOIDCを使用した認証](/bitrise-platform/integrations/oidc-authentication/oidc-authentication-overview#authentication-to-bitrise-with-oidc)をご覧ください。


## Bitriseで信頼ポリシーを作成する

OIDCトークン交換を使用して外部サービスにBitriseリソースへのアクセスを許可するため、OIDC信頼ポリシーを作成します。

1. <Partial_OpeningTheWorkspaceSettingsPage />
1. <strong>Security</strong>を選択し、<strong>OIDC trust policies</strong>タブに移動します。

   ![2026-03-11-oicd-trust-policies.png](/img/_paligo/uuid-3424f770-b6c1-749a-b936-6d073bab7469.png)
1. <strong>New OIDC policy</strong>をクリックします。
1. policy detailsを入力します。

   - <strong>Policy name</strong>: ポリシーの識別子です。
   - <strong>Issuer (iss)</strong>: Bitriseが信頼するIDプロバイダーのHTTPS URLです。
   - <strong>Session duration</strong>: トークンの有効期間です。

   ![2026-03-11-oicd-new-policy.png](/img/_paligo/uuid-fb66f7d5-2c56-4480-4a54-4d79a29c6c67.png)
1. 次のページで、JSON形式でマッチングルールを設定します。

   マッチングルールは、信頼ポリシーに一致させるためにトークン内でBitriseが確認する必要があるクレームを定義します。

   :::important

   マッチングルールを少なくとも1つ設定する必要があります。`sub`クレームは必須で、トークン交換のトリガーとなったサブジェクトを識別します。

   :::

   例えば、リポジトリの特定のブランチに対するマッチングルールを作成し、<GlossTerm baseform="workflow">Workflow</GlossTerm>を指定できます。

   ```json
   {
     "sub": "repo:my-org/my-repo:environment:prod",
     "workflow": "CI",
     "ref": "refs/heads/main",
     "repository": "my-account/my-repo"
   }
   ```
1. 次のページで、短命トークン用にworkspaceロールを設定します。

   workspaceロールによってトークンのアクセスレベルが決まります。詳しくは、[workspacesのロールと権限](/bitrise-platform/workspaces/collaboration-and-permissions-in-workspaces/roles-and-permissions-in-workspaces)をご覧ください。
1. 次のページで、製品へのアクセスを設定します。すべての製品に対して完全な管理者アクセスを許可するか、Bitrise CIまたはRelease Management、あるいはその両方に対して詳細なアクセスを許可します。

   - <strong>Admin access</strong>を選択すると、workspaceが所有するすべてのプロジェクトに対して管理者アクセスを許可します。
   - <strong>Bitrise CI</strong>を選択し、トークンのプロジェクトまたはRelease Managementアプリとアクセスロールを選択します。プロジェクトごとに異なるアクセスレベルを設定できます。

     詳しくは、[Bitrise CIのロールと権限](/bitrise-platform/projects/roles-and-permissions-for-bitrise-ci)
   - <strong>Release Management</strong>を選択し、トークンのRelease Managementアプリとアクセスロールを選択します。Release Managementアプリごとに異なるアクセスレベルを設定できます。

     詳しくは、[Release Managementのロールと権限](/release-management/configuring-connected-apps/release-management-roles-and-permissions)
1. 準備ができたら、<strong>Create policy</strong>をクリックします。


## トークンリクエストを作成する

Bitriseで少なくとも1つの信頼ポリシーを作成すると、OIDCトークン交換リクエストを作成してBitriseから短命トークンを受け取れるようになります。

1. Bitriseへの認証に使用したいサービスからOIDCトークンを取得します。

   トークンの取得方法はサービスによって異なります。例: [GitHub Actionsからトークンをリクエストする](https://docs.github.com/en/actions/reference/security/oidc#methods-for-requesting-the-oidc-token)。
1. このトークンを使用して、Bitriseへの交換リクエストを行います。

   リクエストにはポリシーIDを含める必要があり、`app.bitrise.io`に送信する必要があります。

   ```yaml
   curl -i -X POST https://app.bitrise.io/oidc/token \                                                                                                                                                                                                                                      
       -H "Content-Type: application/x-www-form-urlencoded" \                                                                                                                                                                                                                                                                   
       -d "grant_type=urn:ietf:params:oauth:grant-type:token-exchange" \                                                                                                                                                                                                                                                       
       -d "subject_token_type=id_token" \
       -d "policy_id=<POLICY_UUID>" \                                                                                                                                                                                                                                                                                          
       -d "subject_token=<OIDC_TOKEN>"
   ```

   リクエストは`application/json`として送信することもできます。

   ```yaml
   curl -i -X POST https://app.bitrise.io/oidc/token \ 
       -H "Content-Type: application/json" \-d 
       "{ \"grant_type\": \"urn:ietf:params:oauth:grant-type:token-exchange\",
          \"subject_token_type\": \"id_token\",
          \"subject_token\": <OIDC_TOKEN>,
          \"policy_id\": <POLICY_ID> }"
   ```
