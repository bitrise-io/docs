Bitriseは、AWS MarketplaceでAmazon Machine Image(AMI)として提供されています。Bitrise AMIを使用すると、Bitrise <GlossTerm baseform="Workspace">workspace</GlossTerm>に接続されたAmazon EC2インスタンス上で、独自のAWSリソースを使用してBitriseビルドを実行できます。このセクションでは、Bitriseビルド用に完全にカスタマイズされたAWS設定を手動でセットアップする方法について説明します。

manual setupの実行には、Bitrise AMIへのアクティブなサブスクリプションも必要です:[AWS AMIでBitriseに登録する]](/bitrise-platform/infrastructure/bitrise-on-aws--cloud-controller/subscribing-to-the-bitrise-on-aws-ami)。

manual setupの代わりに、Bitriseビルド用のAWSのセットアップにはCloud Controllerを使用することを強くおすすめします:[AWSのBitrise:Cloud Controller](/bitrise-platform/infrastructure/bitrise-on-aws--cloud-controller/aws-cloudformation-templates)。

:::


## EC2 MacまたはLinuxインスタンスのセットアップ

Amazon EC2 MacまたはLinuxインスタンスでBitriseビルドを実行するには、次の作業が必要です:

1. [Bitriseでランナープールを設定する]](/bitrise-platform/infrastructure/bitrise-on-aws--manual-setup/launching-an-ec2-instance-for-the-bitrise-ami#configuring-the-instance):ビルド用のランナープールをセットアップし、Bitrise WorkspaceをAmazon EC2インスタンスに接続するために必要なトークンを取得します。
1. [Bitrise AMIに登録し、Amazon EC2インスタンスを起動する]](/bitrise-platform/infrastructure/bitrise-on-aws--manual-setup/launching-an-ec2-instance-for-the-bitrise-ami#preparing-your-ec2-mac-and-linux-instance)。EC2 MacまたはEC2 Linuxインスタンスのいずれかを起動できます。EC2 Macインスタンスの場合は、インスタンスを起動する前に専用ホストを割り当てる必要があります。
1. [トークンを使用してインスタンスをBitrise Workspaceに接続する]](/bitrise-platform/infrastructure/bitrise-on-aws--manual-setup/launching-an-ec2-instance-for-the-bitrise-ami#connecting-the-ec2-mac-or-linux-instance-to-your-bitrise-workspace)。これにより、BitriseエージェントがEC2 MacまたはLinuxインスタンスでビルドを実行できるようになります。
