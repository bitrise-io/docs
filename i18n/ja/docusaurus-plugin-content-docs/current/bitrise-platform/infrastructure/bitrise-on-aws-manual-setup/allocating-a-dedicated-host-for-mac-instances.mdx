すべてのAmazon EC2 Macインスタンスは、専用ホスト上で実行する必要があります。EC2 Macインスタンス上でBitrise AMIを実行するには、専用ホストを割り当てて、そのホスト上にEC2 Macインスタンスを起動する必要があります。これには、ホストを割り当てる際にAWSが自動生成するホストIDを把握しておく必要があります。

:::note[Mac専用ホストのAWS料金]

macOSインスタンスの場合、専用ホストを割り当てる必要があります。オンデマンドのEC2 Mac専用ホストには、最低24時間のホスト割り当ておよび課金期間があります。詳細については、公式のAWSドキュメントを確認してください: [Amazon EC2 Dedicated Hosts Pricing](https://aws.amazon.com/ec2/dedicated-hosts/pricing/#Pricing_for_Dedicated_Hosts)。

:::

:::important[サービスクォータ]

専用ホストを起動できるように、選択したリージョンで十分なサービスクォータがあることを確認してください。

- [現在のクォータを表示する](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-resource-limits.html#view-limits)。
- [引き上げをリクエストする](https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-resource-limits.html#request-increase)。

:::

1. EC2 Dashboardで、左側のナビゲーションバーにある<strong>Instance</strong>メニューを見つけます。
1. <strong>Dedicated Host</strong>を選択します。
1. <strong>Allocate dedicated host</strong>をクリックします。
1. 必須項目を入力します:

   - <strong>Name tag</strong>: これがホストの名前になります。

     :::note[ホストID]

     この名前は、専用ホスト上でEC2インスタンスを起動する際に必要なホストIDとは異なります。ホストIDはAWSによって自動生成されます。

     :::
   - <strong>Instance family</strong>: <strong>mac2</strong>または<strong>mac-m4</strong>(使用したいAppleのシリコン世代によって異なります)
   - <strong>Instance type</strong>: <strong>mac-m4.metal, mac-m4pro.metal, mac2.metal, mac2-m2.metal, mac2-m2pro.metal</strong>
   - <strong>Availability Zone</strong>: 使用予定のサブネットによって異なります。選択したゾーンにノードの空き容量がない場合は、AWSが通知します。
   - <strong>Quantity</strong>: 作成したいホストの数です。
   - <strong>Host maintenance</strong>: 無効。`mac2`および`mac-m4`インスタンスファミリーはホストメンテナンスをサポートしていません
1. 準備ができたら、<strong>Allocate</strong>をクリックします。

ホストの準備ができたら、EC2 Macインスタンスの起動に進むことができます。
