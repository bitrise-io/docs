すべての<GlossTerm baseform="Stack">スタック</GlossTerm>を永久に維持するわけではありません。目的は、最高のアプリを構築するために役立つ最新のツールを提供することです。ただし、スタックが更新されるたびにビルド設定を作り直す必要はありません。信頼性の高い古いスタックは長期間使い続けることができます。

Xcodeの新しいメジャーバージョンがリリースされると、一部の古いスタックはフリーズされます。スタックがフリーズされても引き続き使用できますが、それ以降アップデートは提供されなくなります。その時点で、より新しいアクティブなスタックへの切り替えを強くお勧めします。

スタックがフリーズされてから1年が経過すると、Xcodeの次のメジャーバージョンがリリースされたタイミングで削除されます。
