Bitrise<GlossTerm baseform="stack">スタック</GlossTerm>には、モバイル開発に必要な主要なツールがあらかじめインストールされており、すぐに使用できます。私たちの目標は、<GlossTerm baseform="Workflow">Workflows</GlossTerm>をシンプルにし、ビルドを高速かつ効率的にすることです。これらのツールは継続的に変化しており、古いバージョンは非推奨となりサポートが終了する一方で、新しいバージョンには新機能や破壊的変更が加えられてリリースされます。

Stacksは[bitrise.io](https://www.bitrise.io)上で定期的に更新されます。更新には、次のいずれか、または複数の種類の変更が含まれます。

- ツールのアップグレード: すでにインストールされているツールがlatest versionにアップグレードされます(たとえば、gitのCLIが2.9.1から2.9.5にアップグレードされます)。
- ツールの追加: 新しいツールが追加されます(たとえば、新しいAndroidバージョンがリリースされると、最新のAndroidエミュレーターのシステムイメージがプリインストールされます)。
- ツールの削除: ツールのバージョンがエンドオブライフを迎えセキュリティリスクとなる場合、そのバージョンは削除され、別のバージョンがデフォルトになります(たとえば、Ruby 2.7が削除され、Ruby 3.0が新しいデフォルトになります)。
- プラットフォームの変更: macOSスタックのXcode、OSバージョン、AndroidSDKなど、主要コンポーネントへの変更です。

LinuxおよびMacOSスタックの更新ポリシーについて詳しく知りたい場合は、以下をご確認ください。

- [macOSスタックの更新ポリシー](/bitrise-build-hub/infrastructure/build-stacks/macos-stack-update-policy)
- [Linuxスタックの更新ポリシー](/bitrise-build-hub/infrastructure/build-stacks/linux-stack-update-policy)

:::note[スタックの以前のバージョンの使用]

スタックを新しいバージョンに更新すると、一部のビルドで問題が発生する場合があります。移行をスムーズにするため、更新後2〜3日間はスタックの以前のバージョンを使用できます: [スタックの以前のバージョンの使用](/bitrise-build-hub/infrastructure/build-stacks/stack-update-policy#using-the-previous-version-of-a-stack)。

:::

各スタックで利用可能なツールの詳細については、関連ガイドをご確認ください: [Bitriseスタックにプリインストールされているツール](/bitrise-platform/infrastructure/build-stacks/preinstalled-tools-on-bitrise-stacks)
