## 2025年6月 {#june-2025}

<strong>Changed</strong>

Linuxのスタック更新ポリシーに関する記載は、専用ページの[Linuxのスタック更新ポリシー](/bitrise-build-hub/infrastructure/build-stacks/linux-stack-update-policy)に移動し、Edge、Stable、Frozenの各スタックに関する詳細情報が追加されました。また、新しいLinuxスタックの年次リリースサイクルや、古いLinuxスタックの非推奨化および削除についても説明しています。

以前のバージョンのスタックの使用方法についての記載はこのページから削除し、[Stackの更新ポリシー](/bitrise-build-hub/infrastructure/build-stacks/stack-update-policy)に追加しました。

## 2024年7月 {#july-2024}

<strong>Removed</strong>:

依存関係マネージャーのキャッシュ更新についての記載。CocoapodsとHomebrewはどちらも、レジストリのgitリポジトリ全体をクローンするよりも優れた仕組みを備えており、これらの新しい仕組み(Cocoapods CDN、HomebrewのAPI)は現在スタックで有効になっています。スタックが更新されると、ディスク上のリポジトリは最新の状態になりますが、他にリリースすべき変更がない場合、Stableスタックは厳密には毎週更新されなくなりました。

<strong>Changed</strong>:

stable macOSスタックへの破壊的変更(新しいXcodeのメジャーバージョンがリリースされる年に一度)は、既存の古いstableスタックには適用されなくなり、新しくリリースされたstableスタックにのみ適用されます。たとえば、Xcode 16.0がリリースされた場合、予定されている破壊的変更はXcode 16.0のstableスタックにのみ適用されます。Xcode 14.xおよび15.xのstableスタックには破壊的変更は適用されません。

## 2024年3月 {#march-2024}

<strong>New</strong>:

新しいEdgeスタックに置き換えられてEdgeスタックが段階的に廃止される際の動作を定義。

<strong>Removed</strong>:

新しいXcodeのEdgeスタックがリリースされても、Stableスタックにツールの変更がもたらされなくなりました。

<strong>Changed</strong>:

新しく、よりシンプルなシミュレーターランタイムポリシー。従来と同じ数の古いiOSメジャーバージョンがインストールされますが、それぞれ最新のマイナーバージョンのみがインストールされます。
