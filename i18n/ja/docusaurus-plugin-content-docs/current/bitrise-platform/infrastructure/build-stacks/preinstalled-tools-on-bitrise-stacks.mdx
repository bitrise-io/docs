Bitriseの<GlossTerm baseform="stack">スタック</GlossTerm>には、<GlossTerm baseform="Project">プロジェクト</GlossTerm>のビルドプロセスができるだけスムーズかつ高速に進むよう、多数のツールとアプリケーションがプリインストールされています。

スタックを作成または更新するたびに、そのスタックのスタックレポートも公開します。スタックレポートには、スタック上にプリインストールされたツールとそのバージョンの一覧が含まれます。

macOSとLinuxの両方のスタックは、インストールされたツールの最新バージョンを提供するために定期的に更新されます：

- [macOSスタックの更新ポリシー](/bitrise-build-hub/infrastructure/build-stacks/macos-stack-update-policy)。
- [Linuxスタックの更新ポリシー](/bitrise-build-hub/infrastructure/build-stacks/linux-stack-update-policy)。

利用可能なすべてのスタックのスタックレポートは、専用ページの[Bitriseスタックレポート](https://stacks.bitrise.io/stack_reports/)で確認できます。

:::tip[ツールバージョンの設定]

Bitriseに使用するツールのバージョンを指定したり、build machinesにないツールをインストールするよう指示したりできます。詳細については、[ツールバージョンの設定](/bitrise-ci/configure-builds/configuring-build-settings/configuring-tool-versions)をご覧ください。

:::
