デフォルトでは、すべてのBitrise<GlossTerm baseform="Stack">スタック</GlossTerm>に[複数のJavaバージョン](https://stacks.bitrise.io/tools/java/)があらかじめインストールされており、すぐに使用できます。別のバージョンにdo not switch場合、ビルドではデフォルトのJavaバージョンが使用されます。

いつでもバージョンを切り替えられます。また、別のJavaバージョンをインストールすることもできます。

:::tip[その他のツールの設定]

その他のツールについては、ビルドで使用するバージョンを指定できます: [ツールバージョンの設定](/bitrise-ci/configure-builds/configuring-build-settings/configuring-tool-versions)。

:::


## Set Java version StepでJavaバージョンを設定する

各Bitriseスタックには、複数の異なる[Javaバージョン](https://stacks.bitrise.io/tools/java/)があらかじめインストールされており、すぐに使用できます。[<strong>Set Java version</strong> Step](https://www.bitrise.io/integrations/steps/set-java-version)を使用すると、異なるJavaバージョンを簡単に切り替えられます。<GlossTerm baseform="Step">Step</GlossTerm>を使用すると、ビルドを実行する仮想マシンのグローバルなJavaバージョンを設定できます。このStepでは、Javaバージョンをインストールすることはできません。スタックにあらかじめインストールされているバージョン間の切り替えのみ可能です。

1. <strong>Set Java version</strong> Stepを<GlossTerm baseform="Workflow">Workflow</GlossTerm>に追加します。Workflowの最初のStepとして設定することをお勧めします。
1. <strong>Java version</strong>の入力欄を見つけます。
1. 必要なバージョンに設定します。

<strong>YAMLの例</strong>

この例では、`bitrise.yml`ファイルでJavaバージョンを17に設定しています。

```yaml
primary:
  steps:
  - set-java-version@1:
      inputs:
      - set_java_version: '17'
```
