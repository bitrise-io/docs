Bitriseは何よりもまずプラットフォームです。利用するために何かをダウンロードする必要はなく、自分のコンピューターやサーバーで実行する必要もありません。その全てを弊社が担います。

つまり、インフラストラクチャについて心配する必要もありません。メンテナンス、ツール、仮想化はすべて弊社の仕事であり責任です。

Bitriseでは、ビルドの実行に仮想マシン(VM)を使用します。すべてのビルドは新しいVMで実行され、各VMはビルドの終了後すぐに破棄されます。

スタックとは、ビルドの実行に使用できる仮想マシンの種類です。たとえば、ネイティブiOSアプリの場合、最適なスタックは弊社のXcodeスタックのいずれかです。Stacksには必要なツールがすべて事前インストールされており、あらゆるニーズに対応できるよう定期的に更新されています。
