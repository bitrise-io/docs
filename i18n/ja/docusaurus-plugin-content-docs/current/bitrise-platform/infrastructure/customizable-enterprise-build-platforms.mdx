Bitriseは、[エンタープライズ](https://bitrise.io/pricing)のお客様のニーズに合わせて調整された、フルマネージドのビルドプラットフォームを提供します。カスタムエンタープライズビルドプラットフォームを使用するということは、専用に設定された仮想マシン(VM)上でBitriseのビルドを実行することを意味します。プライベートクラウドを使用すると、ビルドの実行方法とタイミングを完全に制御できます。

Bitriseは、エンタープライズ向けに3種類のカスタムビルドプラットフォームを提供しています:

- 専用ビルドプラットフォーム: Bitriseファイアウォールの内側にある専用マシン群で、パブリックプールと専用プールの両方に対応します。これらの仮想build machinesは[同じパブリックIPアドレスから、任意のBitrise build machine](/bitrise-platform/infrastructure/build-machines/configuring-your-network-to-access-our-build-machines)として認識されますが、ビルドノード(仮想build machinesを実行するハイパーバイザー)はビルド中お客様専用に予約されます。
- 専用プラスビルドプラットフォーム: 専用ビルドプラットフォームと同じ構成に加え、ネットワークのセキュアな接続を強化するため、お客様専用の追加IP範囲が予約されます。
- プライベートビルドプラットフォーム: プライベートマシンは常にお客様専用に予約されます。このソリューションはお客様専用にプロビジョニングされ、独自のファイアウォール、より柔軟なストレージ容量オプション、より柔軟なコンピューティング環境設定が含まれます。カスタム仮想化構成を作成できるほか、[サイト間VPNオプション](/bitrise-platform/integrations/connecting-to-a-vpn-during-a-build)も含まれます。

プライベートビルドプラットフォームは、豊富な設定オプションを備えた高度なセットアップです。詳細については、[お問い合わせください](https://bitrise.io/contact)。
