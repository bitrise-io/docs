[Bitrise CI](/bitrise-ci)では、LinuxとXcodeの両方の<GlossTerm baseform="stack">スタック</GlossTerm>を、複数の異なるbuild machineタイプで利用できます。各マシンタイプには、[サブスクリプションプラン](http://www.bitrise.io/pricing)に応じて、さまざまな処理能力のオプションが用意されています。

各プロジェクトにデフォルトのマシンタイプを設定できるほか、<GlossTerm baseform="Workflow">Workflow</GlossTerm>固有のマシンタイプを設定することもできます。これは、プロジェクトのスタックを選択する際に行えます: [ビルドのスタックの設定](/bitrise-ci/configure-builds/configuring-build-settings/setting-the-stack-for-your-builds)。

:::tip[APIを使用したマシンタイプの変更]

また、APIを使用して、単一のユーザーまたは<GlossTerm baseform="workspace">workspace</GlossTerm>が所有するすべてのプロジェクトのbuild machineタイプを変更することもできます: [すべてのアプリのマシンタイプを同時に変更する](/bitrise-ci/api/adding-and-managing-apps#changing-machine-types-in-all-apps-at-the-same-time)。

:::

Bitrisebuild machineにはそれぞれ独自のIPアドレス範囲があります。これらのIPアドレスをアローリストに登録すると、たとえばプライベートクラウドなどからbuild machinesにアクセスできるようになります: [build machinesにアクセスするためのネットワークの設定](/bitrise-platform/infrastructure/build-machines/configuring-your-network-to-access-our-build-machines)

ビルドとコードのセキュリティについて詳しくは、[コードセキュリティ](/bitrise-platform/infrastructure/code-security)をご覧ください。
