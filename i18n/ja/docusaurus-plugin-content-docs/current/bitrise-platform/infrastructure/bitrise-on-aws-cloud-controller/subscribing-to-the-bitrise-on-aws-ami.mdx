AWS AMI の Bitrise が Linux と macOS の両方で利用可能になりました。これにより、Amazon EC2 インスタンス上で Bitrise ビルドを実行できるようになります。

AWS の Bitrise は AWS Private Offer 経由で販売されており、Bitrise が提供する AMI を使用する前に Bitrise アカウントが必要です。パブリックの AWS Marketplace 経由でこれらのオファリングを購入しないでください。

AWS リスティングで Bitrise のプライベートオファーを取得できます。

1. [Bitrise に問い合わせた](https://bitrise.io/contact)後、注文書をpdf形式で送付します。このドキュメントには、関連する顧客データ、提供されるサービス、サービスの価格など、AWS における Bitrise オファリングの詳細がすべて記載されています。
1. 契約条件に問題がなければ、再度 Bitrise に連絡し、AWS のプライベートオファーを作成する権限を付与してください。オファーは AWS Marketplace で確認できるようになります。
1. 次に、注文書が添付された AWS プライベートオファーへのリンクが届きます。このリンクをクリックすると AWS Marketplace に移動します。

   ![aws-offer-1.png](/img/_paligo/uuid-286c4817-1c22-6e11-06ec-26a34ce81273.png)
1. 必要に応じて、請求書発行のために発注書IDをここで入力できます。<strong>発注書をAdd</strong>をクリックしてください。

   発注書について詳しくは、AWS の公式ドキュメント「[Managing your purchase orders](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/manage-purchaseorders.html)」を参照してください。
1. 契約条件を確認してください。pdfドキュメントは、<strong>Create Contract</strong> ボタンの下にあるEnd User License Agreementリンクから入手できます。

   なお、右下には Bitrise のパブリックオファーなど、他に利用可能なオファーが表示される場合があります。これらは今回とは関係ありません。受け取ったリンクは、直接プライベートオファーへ移動するものです。
1. 問題がなければ、右側の <strong>Create Contract</strong> をクリックしてください。この時点以降、AWS ページで契約内容を変更することはできません。

   ![aws-offer-2.png](/img/_paligo/uuid-dd9a98bf-41aa-d933-c06f-34d69bb56148.png)
1. 契約の準備が整うと、AWS にライセンスを受け取った旨のメッセージが表示されます。この時点で、<strong>Continue to Configuration</strong> をクリックして AMI の設定に進むことができます。

   ![license-mgt.png](/img/_paligo/uuid-594370f7-8b76-f5b1-3042-d09c9f06bfe7.png)
1. 起動する前に、フルフィルメントオプション、バージョン、リージョンを選択してください。AWS Marketplace からのソフトウェアの起動について詳しくは、AWS の公式ドキュメント「[Launching container software from AWS Marketplace](https://docs.aws.amazon.com/marketplace/latest/buyerguide/buyer-configuring-a-product.html)」を参照してください。
1. 準備ができたら、<strong>Continue to Launch</strong> をクリックしてソフトウェアを起動してください。

   ![continue-to-launch.png](/img/_paligo/uuid-d1f6b886-e707-4116-3eb6-331b765507ba.png)

Amazon EC2 インスタンスの設定方法や、そこでのビルドの実行について詳しくは、[Launching an EC2 instance for the Bitrise AMI](/bitrise-platform/infrastructure/bitrise-on-aws--manual-setup/launching-an-ec2-instance-for-the-bitrise-ami) を参照してください。
