:::tip[Onboarding with an AI agent]

Bitrise を AIエージェント（Claude Code や Cursor など）経由でセットアップする場合は、先にここでサインアップする必要はありません。エージェントが Bitrise のサインインページを案内するので、そこでアカウントを作成できます。承認すると、アカウントは自動的に接続されます。

このガイドの代わりに、[Bitrise for AI agents onboarding runbook](/bitrise-platform/ai/onboarding-for-agents) に従ってください。

:::

Bitrise には、メールアドレスで、または GitHub、Bitbucket、GitLab、Google のアカウントで認証して、サインアップできます。Git プロバイダーのアカウントでサインアップすると、ワンクリックでログインできるほか、これらのプロバイダーでホストされているリポジトリを追加するときに Git アカウントを再度認可する必要がないなど、実用的なメリットがあります。

## Git プロバイダーでサインアップする {#signing-up-with-a-git-provider}

1. Bitrise へのサインアップは、[Bitrise](https://www.bitrise.io/) の右上にある <strong>Start for free</strong> ボタンから行います。<strong>Sign up</strong> ページが表示されます。
1. <strong>Sign up</strong> ページで、<strong>Or sign up with your git provider</strong> セクションまでスクロールし、Git プロバイダーを選択します。
1. 選択した Git プロバイダーを認可します。

   - GitHub を選択した場合は、<strong>Authorize bitrise-io</strong> ボタンを押すと、Bitrise にリダイレクトされます。

     ![authorize_github.png](/img/_paligo/uuid-245d62ac-c277-cae8-0f6d-6d60ae23bb70.png)

   - Bitbucket を選択した場合は、Bitbucket で <strong>Grant access</strong> ボタンを押すと、Bitrise にリダイレクトされます。

     ![authorize-bitbucket.png](/img/_paligo/uuid-2b51312c-d04b-29f9-c83a-14dcfa9306d2.png)

   - GitLab を選択した場合は、<strong>Authorize</strong> ボタンを押すと、Bitrise にリダイレクトされます。

     ![authorize-gitlab.png](/img/_paligo/uuid-78feab6d-8731-8d33-b453-bbf6b14a781c.png)
1. ユーザー名とパスワードを設定します。完了したら、<strong>Sign up</strong> をクリックします。

   :::important[Strong password]

   パスワードは、次の要件を満たす <strong>強力なパスワード</strong> にしてください。

   - 8 文字以上であること。
   - 大文字を 1 文字含むこと。
   - 小文字を 1 文字含むこと。
   - 数字を 1 文字含むこと。
   - 同じ文字を 4 回以上連続して使用しないこと（aaa は可）。
   - メールアドレスやユーザー名を含まないこと。

   :::

以上で準備は完了です。最初の <GlossTerm baseform="Workspace">workspace</GlossTerm> が自動的に作成され、<strong>Getting Started</strong> ページにリダイレクトされます。そこから Bitrise CI、Build Cache、Release Management を始められます。


## メールでサインアップする {#signing-up-with-email}

1. Bitrise へのサインアップは、[Bitrise](https://www.bitrise.io/) の右上にある <strong>Start for free</strong> ボタンから行います。<strong>Sign up</strong> ページが表示されます。
1. メールアドレス、ユーザー名、パスワードを入力します。

   :::important[Strong password]

   パスワードは、次の要件を満たす <strong>強力なパスワード</strong> にしてください。

   - 8 文字以上であること。
   - 大文字を 1 文字含むこと。
   - 小文字を 1 文字含むこと。
   - 数字を 1 文字含むこと。
   - 同じ文字を 4 回以上連続して使用しないこと（aaa は可）。
   - メールアドレスやユーザー名を含まないこと。

   :::
1. <strong>I agree to the Bitrise Terms of Service</strong> にチェックを入れ、<strong>Sign up</strong> ボタンをクリックします。
1. Bitrise からの確認メールが受信トレイに届いているか確認し、記載の手順に従ってください。確認メールが届かない場合は、<strong>Re-send confirmation email</strong> ボタンをクリックします。

   ![checkyourinbox.png](/img/_paligo/uuid-06a9ef1f-701a-678b-cc0c-8aad5c078cd2.png)

以上です。アカウントを確認すると、最初の Workspace が自動的に作成され、<strong>Getting Started</strong> ページにリダイレクトされます。そこから Bitrise CI、Build Cache、Release Management を始められます。

![gettingstarted.png](/img/_paligo/uuid-4f8203e0-c79b-b9ec-7537-53e96b0f1924.png)
