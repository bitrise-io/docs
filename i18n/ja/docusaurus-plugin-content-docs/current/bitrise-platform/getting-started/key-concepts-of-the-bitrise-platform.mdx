Bitrise Mobile DevOps プラットフォームは、計画からモニタリングまで、モバイル開発プロセスのあらゆる工程でユーザーをサポートします。このプラットフォームには、全体構造を理解するのに役立ついくつかの主要な概念があります。

## Workspaces

[workspace](/bitrise-platform/workspaces/workspaces-overview)は、Bitriseのprojectとプロジェクトに携わるチームメンバーを管理できる環境です。Bitriseの各種製品ソリューションを利用するには、workspaceが必要です。Bitrise Dashboardに表示される内容はすべて、選択したworkspaceに属します。

各workspaceにはオーナーがいて、メンバーには、Viewer、Contributor、Managerのいずれかのworkspaceロールを割り当てることができ、これによってworkspace自体へのアクセス権が決まります。メンバーはグループに分けることができ、グループを使うことでオーナーは大規模なチームを特定のプロジェクトにすばやく割り当てられます。

## プロジェクト {#projects}

[Bitrise project](/bitrise-platform/projects/projects-overview)は、開発作業におけるMobile DevOpsプロセス全体を格納するコンテナです。各workspaceは複数のプロジェクトを所有できます。プロジェクトでは、次のことができます。

- CI設定を作成する: プロジェクトのCI設定はGitリポジトリに紐づいています。
- モバイルアプリをテスターやオンラインストアに配信するためにSet up Release Managementを行う。

プロジェクトには、個々のユーザーやworkspaceグループを、詳細なアクセス権を持つコラボレーターとして追加できます。

## アカウント {#accounts}

ユーザーアカウントは個々のユーザーに属します。ユーザーアカウントはプロジェクトを所有できません。Bitrise platformで作業するには、各ユーザーアカウントがworkspaceに所属している必要があります。

ユーザーアカウントにはサブスクリプションプランやRelease Managementライセンスがありません。これらはそれぞれworkspacesとRelease Managementアプリに紐づいています。

個々のユーザーを、プロジェクトチームとworkspacesの両方に招待できます。
