このガイドでは、[OneLogin](https://www.onelogin.com/)で Bitrise を SAML アプリケーションとして設定する手順をステップごとに説明します。

<Partial_CAUTIONSAMLSSORestrictions />

SAML SSO を <GlossTerm baseform="workspace">Workspace</GlossTerm> に接続する前に:

- Bitrise で SAML SSO 接続を設定する間、OneLogin の管理者がすぐに対応できる状態にしておいてください。
- <Partial_SAMLSSOBeforeYouStart />

OneLogin で Bitrise を設定するには:

1. 管理者として [OneLogin](https://www.onelogin.com/) にログインします。
1. 上部バーの <strong>Administration</strong> をクリックします。

   ![Setting_up_OneLogin_SSO_for_Bitrise.png](/img/_paligo/uuid-e05bd9fd-2b96-f6dd-9d2b-b3ad8ba5510e.png)
1. <strong>Applications</strong> を選択し、<strong>Add App</strong> をクリックします。これにより <strong>Find Applications</strong> ページに移動します。

   ![Setting_up_OneLogin_SSO_for_Bitrise.png](/img/_paligo/uuid-90d0f8f9-8de5-2c9c-f8e7-2279dc5d48ef.png)
1. 検索バーに `Bitrise` と入力し、検索結果から <strong>SAML2.0</strong> タイプを選択します。

   ![Setting_up_OneLogin_SSO_for_Bitrise.jpg](/img/_paligo/uuid-ba3b2ff2-116c-1ae2-0e8d-72c0e73826ee.jpg)
1. 左サイドバーの <strong>Configuration</strong> タブをクリックします。アイコンの変更や説明の追加は任意で行えます。<strong>Organization (Bitrise)</strong> にチェックが入っていることを確認します。Hit <strong>Save</strong>。

   ![Setting_up_OneLogin_SSO_for_Bitrise.jpg](/img/_paligo/uuid-97037eee-6e35-4a1f-1e4e-a252c78b2317.jpg)
1. 再度 <strong>Configuration</strong> タブをクリックし、Bitrise Workspace の <strong>Single Sign-On</strong> タブにある <strong>Assertion Consumer Service URL (ACS URL)</strong> を OneLogin の <strong>Single Sign-On URL</strong> フィールドに貼り付けます。<strong>OneLogin</strong> で <strong>Save</strong> を押します。

   ![Setting_up_OneLogin_SSO_for_Bitrise.jpg](/img/_paligo/uuid-74f65dc6-6662-db11-e97a-9ba3d039cea9.jpg)
1. 左サイドバーで <strong>SSO</strong> を選択します。
1. <strong>View details</strong> for the X.509 Certificate をクリックします。<strong>X.509 Certificate</strong> の内容をコピーし、Bitrise の <strong>Enable Single Sign-On</strong> ページにある <strong>SAML SSO provider certificate</strong> フィールドに貼り付けます。
1. OneLogin で Go back して <strong>SSO</strong> ページに移動し、<strong>SAML 2.0 Endpoint (HTTP)</strong> リンクをコピーします。Bitrise の <strong>SAML SSO provider Single Sign-On URL (SSO URL)</strong> フィールドに貼り付けます。
1. Bitrise に Go back し、<strong>Configure SSO</strong> をクリックします。

:::important[OneLogin と Bitrise のユーザー]

Bitrise Workspace のユーザーが全員 OneLogin の <strong>Users</strong> ページに追加されていることを確認してください。追加されていない場合は、<strong>Users</strong> に移動し、次に <strong>New User</strong> から新しいユーザーを追加します。新しいユーザーが OneLogin でアカウントを有効化できるよう、招待(<strong>More actions</strong> ドロップダウンメニューの <strong>Send Invitation</strong>)を送信するのを忘れないでください。ユーザーは <strong>User Info</strong> の下にある <strong>Applications</strong> をクリックし、<strong>+</strong> 記号をクリックすることで、新しく作成した Bitrise アプリに追加する必要があります。追加したユーザーが全員 Bitrise の Workspace メンバーであることを確認してください。

![application-onelogin.jpg](/img/_paligo/uuid-f6505a6f-5c4e-7cf1-8a81-f8325898b1be.jpg)

:::

OneLogin で Bitrise の設定を完了し、Bitrise Workspace と接続していれば、Workspace のメンバー全員に Bitrise からメールが届きます。このメールには、Bitrise Workspace への SSO 接続を有効化するリンクが含まれています。
