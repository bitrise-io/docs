Bitrise にサインアップすると、個人のユーザーアカウントが作成されます。ユーザーアカウントだけでは、プロジェクトの追加やビルドの実行はできません。そのためには、workspace のメンバーになるか、外部コントリビューターとしてプロジェクトに招待される必要があります。

個人アカウントは、次のものに接続できます。

- OAuth 経由の Git プロバイダーアカウント。Git プロバイダー経由での Bitrise へのログインや、Bitrise CI のリポジトリアクセスの設定ができます。[Repository access with OAuth](/bitrise-platform/repository-access/repository-access-with-oauth)を参照してください。
- Bitrise GitHub App。SSH キーなしで認証とリポジトリアクセスが可能になります。[GitHub app integration](/bitrise-platform/repository-access/github-app-integration)を参照してください。
- Your Apple ID。Bitrise project を Apple サービスに接続できます。[Connecting to an Apple service with Apple ID](/bitrise-platform/integrations/apple-services-connection/connecting-to-an-apple-service-with-apple-id)を参照してください。

## Account settings ページ {#account-settings-page}

Bitrise アカウントは、[Account settings ページ](http://app.bitrise.io/me/account)から管理します。このページでは、次の操作ができます。

- ユーザー名、メールアドレス、パスワード、アバターなどの[プロファイルを編集します](/bitrise-platform/accounts/editing-your-profile-settings)。
- Set up [Apple ID connection](/bitrise-platform/integrations/apple-services-connection/connecting-to-an-apple-service-with-apple-id#adding-apple-id-authentication-data-on-bitrise)。
- [2 要素認証を有効にします](/bitrise-platform/accounts/two-factor-authentication#enabling-two-factor-authentication)。
- Release Management 用に [LaunchDarkly feature flags](/release-management/configuring-connected-apps/integrating-launchdarkly-feature-flags)を接続します。
- [Bitrise API](/bitrise-ci/api/api-overview)および[Bitrise CLI](/bitrise-ci/bitrise-cli/authenticating-with-the-bitrise-cli)へのアクセスに使用するパーソナルアクセストークンを作成、管理します。
- [テストデバイスを登録します](/bitrise-ci/testing/testing-ios-apps/registering-a-test-device)。

## SAML SSO

SAML SSO 経由で Bitrise にログインできます。Bitrise は複数の SAML Identity Provider をサポートしています。SAML SSO 経由でログインするには、次の条件を満たす必要があります。

- workspace で SAML SSO が有効になっていること。
- 個人の Bitrise アカウントに紐づくメールアドレスが、SAML Identity Provider にも登録されていること。

設定方法の詳細については、[Configuring SAML SSO on Bitrise](/bitrise-platform/accounts/saml-sso-in-bitrise/configuring-saml-sso-on-bitrise)を参照してください。
