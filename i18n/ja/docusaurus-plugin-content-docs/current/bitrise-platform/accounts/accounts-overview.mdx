Bitriseに登録すると、個人のユーザーアカウントが作成されます。ユーザーアカウントがあるだけでは、プロジェクトを追加してビルドを実行するには不十分です。そのためには、workspaceに所属するか、外部コントリビューターとしてプロジェクトに招待される必要があります。

個人アカウントは、次のものに接続できます。

- OAuthを使用して、Git プロバイダーのアカウントを接続できます。これにより、Git プロバイダー経由でBitriseにログインし、Bitrise CIのリポジトリアクセスを設定できます。[OAuthによるリポジトリアクセス](/bitrise-platform/repository-access/repository-access-with-oauth)。
- Bitrise GitHubアプリを使用すると、SSHキーを使用せずに認証とリポジトリアクセスが可能になります。[GitHubアプリの統合](/bitrise-platform/repository-access/github-app-integration)。
- Your Apple IDを使用すると、Bitrise projectをAppleサービスに接続できます。[Apple IDを使用したAppleサービスへの接続](/bitrise-platform/integrations/apple-services-connection/connecting-to-an-apple-service-with-apple-id)。

## Account settingsページ {#account-settings-page}

Bitriseアカウントは、[Account settingsページ](http://app.bitrise.io/me/account)から管理します。このページでは、次のことができます。

- [プロフィールの編集](/bitrise-platform/accounts/editing-your-profile-settings): ユーザー名、メールアドレス、パスワード、アバターなど。
- Set up [Apple ID connection](/bitrise-platform/integrations/apple-services-connection/connecting-to-an-apple-service-with-apple-id#adding-apple-id-authentication-data-on-bitrise)。
- [二要素認証の有効化](/bitrise-platform/accounts/two-factor-authentication#enabling-two-factor-authentication)。
- Release Management向けに[LaunchDarkly フィーチャーフラグ](/release-management/configuring-connected-apps/integrating-launchdarkly-feature-flags)を接続します。
- [Bitrise API](/bitrise-ci/api/api-overview)へのアクセスに使用するパーソナルアクセストークンを作成、管理します。
- [テストデバイスの登録](/bitrise-ci/testing/testing-ios-apps/registering-a-test-device)。

## SAML SSO

SAML SSO経由でBitriseにログインできます。Bitriseは複数のSAMLアイデンティティプロバイダーをサポートしています。SAML SSOでログインするには、次の条件を満たす必要があります。

- workspaceでSAML SSOが有効になっている必要があります。
- 個人のBitriseアカウントに登録されているメールアドレスが、SAMLアイデンティティプロバイダーにも登録されていることを確認してください。

設定方法の詳細については、[BitriseでのSAML SSOの設定](/bitrise-platform/accounts/saml-sso-in-bitrise/configuring-saml-sso-on-bitrise)を参照してください。
