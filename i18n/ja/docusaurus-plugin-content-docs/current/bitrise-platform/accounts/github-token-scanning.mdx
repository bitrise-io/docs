Bitriseは、[GitHubのシークレットスキャニングプログラム](https://docs.github.com/en/code-security/secret-scanning/secret-scanning-partnership-program/secret-scanning-partner-program)のパートナーです。GitHubは既知のシークレット形式についてリポジトリをスキャンし、誤ってコミットされた認証情報が不正に使用されるのを防ぎます。

Bitriseはこのスキャン機能を使用して、リポジトリ内の[個人アクセストークン](/bitrise-platform/accounts/personal-access-tokens)や[Workspace APIトークン](/bitrise-platform/workspaces/workspace-api-token)を検出します。スキャンでいずれかの種類のトークンがリポジトリにコミットされていることが検出された場合、セキュリティ上の理由から、Bitriseはメールとアプリ内通知の両方でトークンの削除を通知します。

トークンが正しい形式であれば、スキャンは自動的に有効になります。設定は必要ありません。

:::important[トークンの再生成]

2024年11月より前にトークンを生成した場合は、正しい形式になっていることを確認するため、再生成してください。

その他の問題が発生した場合も、トークンの再生成をおすすめします。

- [個人アクセストークンの再生成](/bitrise-platform/accounts/personal-access-tokens#regenerating-a-personal-access-token)。
- [Workspace APIトークンの再生成](/bitrise-platform/workspaces/workspace-api-token#regenerating-a-workspace-api-token)。

:::
