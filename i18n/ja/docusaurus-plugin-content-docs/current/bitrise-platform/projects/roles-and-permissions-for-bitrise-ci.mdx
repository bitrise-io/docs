ロールはBitriseに対するアクセス制御を提供します。ユーザーがBitrise<GlossTerm baseform="project">プロジェクト</GlossTerm>に対して実行できる操作とできない操作を制限するものです。Bitrise CIには専用のロールがあります。

これらに当てはまるロールがない場合、EnterpriseプランではBitrise CIに限定した正確な権限セットを持つ[カスタムロール](/bitrise-platform/workspaces/collaboration-and-permissions-in-workspaces/custom-roles/custom-roles-overview)を作成できます。

:::note[Release Management]

このページでは、Bitrise CIのロールと権限について説明します。

Release Managementには独自のロールと権限があります。Bitrise CIと共有しているロールはプロジェクト管理者のみです。詳細については、[Release Managementのロールと権限](/release-management/configuring-connected-apps/release-management-roles-and-permissions)をご覧ください。

:::

ロールはプロジェクト単位で機能します。同じユーザーでも、プロジェクトが異なれば異なるロールを持つことができます。

ロールは[workspaceグループ](/bitrise-platform/workspaces/collaboration-and-permissions-in-workspaces/workspace-groups)に割り当てることもできます。仕組みは同じで、グループ内の各ユーザーは、そのグループに割り当てられたロールに関連付けられたすべての権限を受け取ります。

プロジェクトのチームでユーザーに割り当てられるロールには、次の4種類があります。

- [Admin](/bitrise-platform/projects/roles-and-permissions-for-bitrise-ci#admins)

  :::note[Release Managementへの完全なアクセス]

  プロジェクト管理者は、プロジェクトのBitrise CI設定とRelease Managementアプリの両方に完全にアクセスできます。

  :::
- [Platform Engineer](/bitrise-platform/projects/roles-and-permissions-for-bitrise-ci#platform-engineers)
- [Developer](/bitrise-platform/projects/roles-and-permissions-for-bitrise-ci#developers)
- [Tester/QA](/bitrise-platform/projects/roles-and-permissions-for-bitrise-ci#testersqa)

また、各プロジェクトにはOwnersが存在します。


## Owners

BitriseのprojectはWorkspacesが所有します。プロジェクトのチームでは、Workspace内でオーナーであるユーザーが、そのプロジェクトに対する<strong>owner</strong>アクセス権を持ちます。

Ownersは無制限のaccess to projectsを持ちます。プロジェクトを削除したり、プロジェクトの所有権を移転したりできるのはOwnersのみで、支払い情報にアクセスできるのもOwnersだけです。


## Admins

プロジェクト管理者はプロジェクトを削除できませんが、次の2つの方法でプロジェクトに他のメンバーを招待して作業してもらうことができます。

- workspaceグループをプロジェクトチームに追加できます：[Workspaceグループをプロジェクトに追加する](/bitrise-platform/projects/managing-user-access-to-a-project#adding-workspace-groups-to-a-project)
- チームに外部コントリビューターを招待できます：[外部コントリビューターをプロジェクトに追加する](/bitrise-platform/projects/managing-user-access-to-a-project#adding-an-outside-contributor-to-a-project)

管理者は他のユーザーに管理者権限を付与することもできます。ただし、プロジェクトの所有権を移転することはできません。それができるのはOwnersだけです。

管理者は、Release ManagerやApp Testerなどの[Release Management](/release-management/configuring-connected-apps/release-management-roles-and-permissions)ロールを含め、プロジェクトのコントリビューターとそのロールを管理できます。


## Platform Engineers

Platform Engineersは、Developersができることをすべて実行できるほか、<GlossTerm baseform="workflow">Workflows</GlossTerm>を編集したり、project settingsにアクセスしたりできます。チームメンバーの管理やプロジェクトの削除はできません。


## Developers

Developersは、チームメンバーのロールの変更、新しいチームメンバーの追加、既存のチームメンバーの削除、Workflowsの作成・編集・削除を行うことはできません。ただし、ビルドの実行やビルドログの閲覧は可能です。

支払い情報、アクセストークン、Webhookなどの機密データにはアクセスできません。


## Testers/QA

Testersはビルドの閲覧のみ可能です。ビルドログにはアクセスできず、いかなる形であってもプロジェクトを変更することはできません。

支払い情報、アクセストークン、Webhookなどの機密データにはアクセスできません。
