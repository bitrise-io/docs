Bitriseproject](/bitrise-platform/projects/projects-overview)は、開発作業におけるMobile DevOpsプロセス全体を格納するコンテナです。各workspaceは複数のプロジェクトを所有できます。プロジェクトでは、次のことができます。

- CIの設定を作成する：プロジェクトのCI設定はGitリポジトリに紐づいています。
- モバイルアプリをテスターやオンラインストアに配布するためにSet upRelease Managementします。

プロジェクトには、個々のユーザーやworkspaceグループを、詳細なアクセス権を持つコラボレーターとして追加できます。

[workspace](/bitrise-platform/workspaces/workspaces-overview)にアクセスできるようになったら、プロジェクトの追加や管理を始められます。初期設定が完了した後は、プロジェクトのほぼすべての側面をいつでも設定できます。具体的には、次のようなことができます。

- [プロジェクトのリポジトリURLを変更する](/bitrise-platform/projects/configuring-the-repository-url-and-the-default-branch#changing-the-repository-url)。
- [サービス認証情報を設定する](/bitrise-platform/integrations/the-service-credential-user#changing-the-service-credential-user)。
- [プロジェクトのSSHキーを更新する](/bitrise-platform/repository-access/configuring-ssh-keys)。
- [新しいWebhookを登録し、既存のものを更新する](/bitrise-platform/integrations/webhooks/adding-incoming-webhooks)。
