新しい<GlossTerm baseform="Project">プロジェクト</GlossTerm>をBitriseに追加する際は、ソースコードの保存に使用するリポジトリと、Bitriseがdefault branchとして使用するブランチを指定します。

プロジェクトのセットアップ後は、いつでもこれらを変更できます。


## リポジトリのURLを変更する {#changing-the-repository-url}

リポジトリのURLは、Bitriseがリポジトリにアクセスするためのアドレスです。SSH URLまたはHTTPS URLのいずれかを使用できますが、セキュリティ上の理由から、非公開のプロジェクトではSSH URLの使用を強くお勧めします。

:::tip[HTTPS URLの使用]

HTTPS GitのURLを使用して、個人アクセストークンで認証することもできます。この場合、SSHキーは不要です。[HTTPSの認証情報を設定する](/bitrise-platform/repository-access/configuring-https-authorization-credentials)

:::

プロジェクトのリポジトリを移動した場合や、その他の理由でURLが変更された場合は、Bitriseで更新すれば、問題なくビルドを続行できます。

1. <Partial_GettingToTheProjectSettingsPage />
1. 左側のメニューから、<strong>Repository</strong> を選択します。
1. <strong>Repository URL</strong> カードで、<strong>Change</strong> をクリックします。
1. ダイアログで新しいURLを入力します。

   ![SCR-20260331-przw.png](/img/_paligo/uuid-fa95efd5-ff6f-a7a3-2dc3-7ccc5878cd47.png)
1. <strong>Save</strong> をクリックして変更を保存します。


## default branchを変更する {#changing-the-default-branch}

default branchは、他の設定で指定がない限りBitriseが使用するリポジトリのブランチです。

default branchはいつでも変更できます。

1. <Partial_GettingToTheProjectSettingsPage />
1. 左側のメニューから、<strong>Repository</strong> を選択します。
1. <strong>Repository URL</strong> カードで、<strong>Change</strong> をクリックします。
1. ダイアログの <strong>Default branch</strong> フィールドにbranch nameを入力します。

   ![SCR-20260331-przw.png](/img/_paligo/uuid-fa95efd5-ff6f-a7a3-2dc3-7ccc5878cd47.png)
1. default branchとして使用したいブランチの名前を入力します。
1. <strong>Save</strong> をクリックして変更を保存します。
