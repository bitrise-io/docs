# CursorにBitrise MCPサーバーをインストールする {#install-bitrise-mcp-server-in-cursor}

## 前提条件 {#prerequisites}

1. [Cursor](https://cursor.com/download) IDEがインストールされていること(latest version、MCP OAuthのサポートを含む — Streamable HTTPにはCursor v0.48.0以降、OAuthには最新のビルドが必要)
2. Bitriseアカウント
3. ローカルセットアップの場合: [Go](https://go.dev/)(1.25以上)がインストールされていること、およびBitriseのPAT

## リモートサーバーのセットアップ(推奨) {#remote-server-setup-recommended}

最近のバージョンのCursorはMCP OAuthをサポートしています。初回のツール使用時に、Cursorがブラウザを開いてBitriseへのサインインを求めます。トークンを貼り付ける必要はありません。

### インストール手順 {#install-steps}

1. グローバルなMCP設定ファイル(`~/.cursor/mcp.json`)を開き(または、プロジェクトローカルの`.cursor/mcp.json`を使用し)、以下の設定を追加します
2. ファイルを保存します
3. Cursorを再起動します
4. 初回のツール呼び出し時に、ブラウザベースのサインインフローを完了します

### Streamable HTTPの設定 {#streamable-http-configuration}

```json
{
  "mcpServers": {
    "bitrise": {
      "url": "https://mcp.bitrise.io"
    }
  }
}
```

### フォールバック: PATベースの認証 {#fallback-pat-based-authentication}

CursorのバージョンがMCP OAuthにまだ対応していない場合は、パーソナルアクセストークンを使用できます。[Account Settings → セキュリティ](https://app.bitrise.io/me/account/security)から[作成](https://devcenter.bitrise.io/api/authentication)し、次の手順を行います。

```json
{
  "mcpServers": {
    "bitrise": {
      "url": "https://mcp.bitrise.io",
      "headers": {
        "Authorization": "Bearer YOUR_BITRISE_PAT"
      }
    }
  }
}
```

## ローカルサーバーのセットアップ {#local-server-setup}

ローカルのBitrise MCPサーバーはGo経由で動作し、パーソナルアクセストークンを使用します(stdioモード、OAuthなし)。

[![MCPサーバーをインストール](https://cursor.com/deeplink/mcp-install-dark.svg)](https://cursor.com/en-US/install-mcp?name=bitrise&config=eyJlbnYiOnsiQklUUklTRV9UT0tFTiI6IllPVVJfQklUUklTRV9QQVQifSwiY29tbWFuZCI6ImdvIHJ1biBnaXRodWIuY29tL2JpdHJpc2UtaW8vYml0cmlzZS1tY3AvdjJAdjIifQo%3D)

### インストール手順 {#install-steps-1}

1. 上のインストールボタンをクリックして手順に従うか、`~/.cursor/mcp.json`を開いて以下の設定を追加します
2. [Tools & Integrations] > MCPツールで、「bitrise」の横にある鉛筆アイコンをクリックします
3. `YOUR_BITRISE_PAT`を実際のパーソナルアクセストークンに置き換えます
4. ファイルを保存します
5. Cursorを再起動します

### ローカル設定 {#local-configuration}

```json
{
  "mcpServers": {
    "bitrise": {
      "command": "go",
      "args": [
        "run",
        "github.com/bitrise-io/bitrise-mcp/v2@v2"
      ],
      "env": {
        "BITRISE_TOKEN": "YOUR_BITRISE_PAT"
      }
    }
  }
}
```

## 設定ファイル {#configuration-files}

- <strong>グローバル(all projects)</strong>: `~/.cursor/mcp.json`
- <strong>プロジェクト固有</strong>: プロジェクトのルートにある`.cursor/mcp.json`

## インストールの確認 {#verify-installation}

1. Cursorを完全に再起動します
2. [設定] → [Tools & Integrations] → [MCP Tools]で緑色のドットを確認します
3. チャットまたはコンポーザーで「Available Tools」を確認します
4. 「List my Bitrise apps」でテストします(サインインしていない場合、最初のツール呼び出しでOAuthフローがトリガーされます)

## 詳細設定 {#advanced-configuration}

特定のAPIグループの有効化・無効化については、[Tools](/bitrise-platform/ai/bitrise-mcp/tools)を参照してください。

## トラブルシューティング {#troubleshooting}

### リモートサーバーの問題 {#remote-server-issues}

- <strong>OAuth flow doesn't open browser</strong>: Cursorを最新のビルドに更新してください。Streamable HTTPには対応しているもののOAuthには対応していない古いビルドの場合は、上記のPATベースのフォールバックを使用できます。
- <strong>Streamable HTTPが動作しない</strong>: Cursor v0.48.0以降を使用していることを確認してください
- <strong>接続エラー</strong>: ファイアウォールやプロキシの設定を確認してください

### 全般的な問題 {#general-issues}

- <strong>MCPが読み込まれない</strong>: 設定後にCursorを完全に再起動してください
- <strong>Invalid JSON</strong>: json形式が正しいことを確認してください
- <strong>Tools not appearing</strong>: MCPの設定でサーバーが緑色のドットを表示しているか確認してください
- <strong>Checkのログ</strong>: CursorのログでMCP関連のエラーを確認してください

## 重要な注意事項 {#important-notes}

- <strong>Cursor固有の仕様</strong>: プロジェクトおよびグローバルの両方の設定に対応し、`mcpServers`キーを使用します
