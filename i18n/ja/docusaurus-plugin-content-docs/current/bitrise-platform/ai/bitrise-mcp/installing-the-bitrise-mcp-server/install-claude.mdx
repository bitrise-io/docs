## Claude Code CLI

### 前提条件 {#prerequisites}
- Claude Code CLI がインストールされていること（MCP OAuth サポートを含む最新バージョン）
- Bitrise アカウント
- プロジェクトのディレクトリ内で Claude Code を開いてください（最適な使用感と設定範囲の明確化のため推奨）

### リモートサーバーのセットアップ（Streamable HTTP）— 推奨 {#remote-server-setup-streamable-http--recommended}

リモートサーバーはOAuthを使用して、お使いのBitriseアカウントで認証します。トークンをコピーして貼り付ける必要はありません。

1. サーバーを追加します。
   ```bash
   claude mcp add --transport http bitrise "https://mcp.bitrise.io/?toolset=all"
   ```
2. Claude Codeを再起動します。
3. 初めてツールを使用すると、Claude Codeがブラウザーを開いてサインインを求めます。Bitriseにログインし（または既存のセッションを確認し）、同意画面を承認してください。
4. `claude mcp list`を実行して、サーバーが設定されていることを確認します。

#### フォールバック：PATによる認証 {#fallback-pat-based-authentication}

Claude CodeのバージョンがMCP OAuthをサポートしていない場合、または個人用アクセストークンを使用する場合は、次の手順に従います。

1. [Account Settings → Security](https://app.bitrise.io/me/account/security)で[Bitrise API Token](https://devcenter.bitrise.io/api/authentication)を作成します。
2. トークンをBearerヘッダーとして指定して、サーバーを追加します。
   ```bash
   claude mcp add --transport http bitrise "https://mcp.bitrise.io/?toolset=all" -H "Authorization: Bearer YOUR_BITRISE_PAT"
   ```

<details>
<summary><b>PATを安全に保管する</b></summary>
<br/>

セキュリティのため、トークンをハードコードしないでください。一般的な方法の1つを紹介します。

1. トークンを`.env`ファイルに保存します。

   ```
   BITRISE_PAT=your_token_here
   ```

2. .gitignoreに追加します。

   ```bash
   echo -e ".env\n.mcp.json" >> .gitignore
   ```

3. 追加時に参照します。

   ```bash
   claude mcp add --transport http bitrise "https://mcp.bitrise.io/?toolset=all" -H "Authorization: Bearer $(grep BITRISE_PAT .env | cut -d '=' -f2)"
   ```

</details>

### ローカルサーバーのセットアップ（Goが必要）{#local-server-setup-go-required}

ローカルサーバーはstdioモードで動作し、個人用アクセストークンで認証します（stdioモードではブラウザーのOAuthフローはありません）。

前提条件：[Go](https://go.dev/)（1.25以上）がインストールされていること、およびBitriseのPATがあること。

1. 次のコマンドを実行します。
   ```bash
   claude mcp add bitrise -e ENABLED_TOOLSET=all -e BITRISE_TOKEN=YOUR_BITRISE_PAT -- go run github.com/bitrise-io/bitrise-mcp/v2@v2
   ```

   環境変数を使用する場合：
   ```bash
   claude mcp add bitrise -e ENABLED_TOOLSET=all -e BITRISE_TOKEN=$(grep BITRISE_PAT .env | cut -d '=' -f2) -- go run github.com/bitrise-io/bitrise-mcp/v2@v2
   ```
2. Claude Codeを再起動します。
3. `claude mcp list`を実行して、Bitriseサーバーが設定されているか確認します。

### 検証 {#verification}
```bash
claude mcp list
claude mcp get bitrise
```

## Claude Desktop

### 前提条件 {#prerequisites-1}
- Claude Desktop がインストールされていること(latest version)
- Bitrise アカウント

### 設定ファイルの場所 {#configuration-file-location}
- <strong>macOS</strong>: `~/Library/Application Support/Claude/claude_desktop_config.json`
- <strong>Windows</strong>: `%APPDATA%\Claude\claude_desktop_config.json`
- <strong>Linux</strong>: `~/.config/Claude/claude_desktop_config.json`

### リモートサーバーのセットアップ（Streamable HTTP）— 推奨 {#remote-server-setup-streamable-http--recommended-1}

最近のClaude Desktopのバージョンは、MCP OAuthをネイティブでサポートしています。[Claude | Connecting to a Remote MCP Server](https://modelcontextprotocol.io/docs/develop/connect-remote-servers#connecting-to-a-remote-mcp-server)を参照してください。初回接続時に、Claude Desktopがブラウザーを開いてBitriseで認証します。トークンは不要です。

お使いのClaude DesktopのバージョンがリモートMCPサーバーをまだネイティブでサポートしていない場合は、アダプターとして[mcp-remote](https://www.npmjs.com/package/mcp-remote)を使用できます。

```json
{
  "mcpServers": {
    "bitrise": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://mcp.bitrise.io/?toolset=all"
      ]
    }
  }
}
```

`mcp-remote`がOAuthフローを代行します。お使いの`mcp-remote`のバージョンがOAuthをまだサポートしていない場合は、PATを指定する方法に切り替えられます。

```json
{
  "mcpServers": {
    "bitrise": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://mcp.bitrise.io/?toolset=all",
        "--header",
        "Authorization: Bearer YOUR_BITRISE_PAT"
      ]
    }
  }
}
```

設定ファイルを保存して、Claude Desktopを再起動します。正しく設定されていれば、メッセージ入力欄の横にハンマーのアイコンが表示されます。

`npx`がClaudeに見つからない場合（`ENOENT`）は、`env`セクションで`npx`バイナリーのパスを指定します。

```json
{
  "mcpServers": {
    "bitrise": {
      ...
      "env": {
        "PATH": "PATH to bin of npx"
      }
    }
  }
}
```

### ローカルサーバーのセットアップ（Goが必要）{#local-server-setup-go-required-1}

ローカルサーバーは、個人用アクセストークンとstdioを使用します。

```json
{
  "mcpServers": {
    "bitrise": {
      "command": "go",
      "args": [
        "run",
        "github.com/bitrise-io/bitrise-mcp/v2@v2"
      ],
      "env": {
        "BITRISE_TOKEN": "YOUR_BITRISE_PAT",
        "ENABLED_TOOLSET": "all",
        "PATH": "PATH to bin directory of go:PATH to directory of git",
        "GOPATH": "your GOPATH",
        "GOCACHE": "your GOCACHE"
      }
    }
  }
}
```

### Manual Setup Steps
1. Claude Desktop を開きます
2. Go to Settings → Developer → Edit Config
3. 上記のコードブロックを設定ファイルに貼り付けます
4. アプリ外から設定ファイルに移動する場合：
   - <strong>macOS</strong>: `~/Library/Application Support/Claude/claude_desktop_config.json`
   - <strong>Windows</strong>: `%APPDATA%\Claude\claude_desktop_config.json`
5. テキストエディタでファイルを開きます
6. 選択した設定（リモートまたはローカル）に応じて、上記のコードブロックのいずれかを貼り付けます
7. ファイルを保存します
8. Claude Desktop を再起動します
9. OAuth を使用している場合： ツールを初めて使用する際に、ブラウザでサインインフローを完了してください

### 詳細設定 {#advanced-configuration}

特定のツールセットを有効または無効にする方法については、[ツール](/bitrise-platform/ai/bitrise-mcp/tools)を参照してください。

上記のセットアップ手順では、サーバーURLの`?toolset=all`、またはローカルサーバーの`ENABLED_TOOLSET=all`により、すべてのツールセットを有効にします。Claudeではこの設定をお勧めします。Claudeはツールを動的に読み込むため、ツールセットが大きくてもコンテキストを圧迫せず、タスクで別のツールセットのツールが必要になってもサーバーを再設定する必要がありません。省略すると、デフォルトのツールセットになります。

## トラブルシューティング {#troubleshooting}

<strong>OAuth flow doesn't open browser：</strong>
- お使いのClaudeのバージョンがMCP OAuthをサポートしていることを確認してください（最近のビルドのみ）
- PATによる認証に切り替えてみてください

<strong>Authentication Failed：</strong>
- OAuthの場合：Claude Codeの`/mcp`コマンドで再認証するか、サーバーを削除して追加し直してください
- PATの場合：トークンの有効期限が切れていないか、無効化されていないかを確認してください

<strong>リモートサーバー：</strong>
- URLを確認してください：`https://mcp.bitrise.io/?toolset=all`

<strong>サーバーが起動しない / ツールが表示されない：</strong>
- `claude mcp list`を実行して、現在設定されているMCPサーバーを確認してください
- JSONの構文を検証してください
- Claude Codeを再起動して、`/mcp`コマンドを確認してください
- `claude mcp remove bitrise`を実行してBitriseサーバーを削除し、別の方法でセットアップをやり直してください
- ログを確認します。
  - Claude Code：`/mcp`コマンドを使用します
  - Claude Desktop：`ls ~/Library/Logs/Claude/`と`cat ~/Library/Logs/Claude/mcp-server-*.log`（macOS）、または`%APPDATA%\Claude\logs\`（Windows）

## 重要な注意事項 {#important-notes}

- リモートサーバーには Streamable HTTP サポートが必要です（Claude のバージョンを確認してください）。OAuth には、基本的な Streamable HTTP よりも新しいビルドが必要です。
- Claude Code の設定スコープ：
  - `-s user`: すべてのプロジェクトで利用可能
  - `-s project`: `.mcp.json` ファイル経由で共有
  - デフォルト： `local`（現在のプロジェクトのみ）
