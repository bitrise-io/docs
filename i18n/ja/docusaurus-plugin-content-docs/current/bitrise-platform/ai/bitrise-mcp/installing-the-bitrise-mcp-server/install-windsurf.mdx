# Bitrise MCP サーバーを Windsurf にインストールする

## 前提条件
1. [Windsurf IDE](https://windsurf.com/) がインストールされていること（latest version）
2. Bitrise アカウント
3. ローカルセットアップの場合: [Go](https://go.dev/)（1.25 以上）がインストールされていること、および Bitrise PAT

## リモートサーバーのセットアップ（推奨）

リモート Bitrise MCP サーバーは Bitrise によって `https://mcp.bitrise.io` でホストされており、Streamable HTTP をサポートしています。最近の Windsurf のビルドは MCP OAuth をサポートしています。最初にツールを使用する際にブラウザが開き、Bitrise へのサインインを求められます。トークンを貼り付ける必要はありません。

### Streamable HTTP の設定

```json
{
  "mcpServers": {
    "bitrise": {
      "serverUrl": "https://mcp.bitrise.io"
    }
  }
}
```

### フォールバック: PAT ベースの認証

Windsurf のビルドがまだ MCP OAuth をサポートしていない場合は、[Account Settings → セキュリティ](https://app.bitrise.io/me/account/security) の下で [Bitrise PAT を作成](https://devcenter.bitrise.io/api/authentication)し、ヘッダーとして追加してください。

```json
{
  "mcpServers": {
    "bitrise": {
      "serverUrl": "https://mcp.bitrise.io",
      "headers": {
        "Authorization": "Bearer YOUR_BITRISE_PAT"
      }
    }
  }
}
```

## ローカルサーバーのセットアップ（Go が必要）

```json
{
  "mcpServers": {
    "bitrise": {
      "command": "go",
      "args": [
        "run",
        "github.com/bitrise-io/bitrise-mcp/v2@v2"
      ],
      "env": {
        "BITRISE_TOKEN": "YOUR_BITRISE_PAT"
      }
    }
  }
}
```

## インストール Steps

### 手動設定
1. Cascade でハンマーアイコン（🔨）をクリックします。
2. <strong>Configure</strong> をクリックして `~/.codeium/windsurf/mcp_config.json` を開きます。
3. 上記から選択した設定を追加します。
4. ファイルを保存します。
5. MCP ツールバーの <strong>Refresh</strong>（🔄）をクリックします。
6. 最初のツール呼び出し時に、ブラウザベースのサインインフローを完了させます（OAuth のセットアップの場合のみ）。

## 設定の詳細

- <strong>ファイルパス</strong>: `~/.codeium/windsurf/mcp_config.json`
- <strong>Scope</strong>: グローバル設定のみ（プロジェクト単位の設定はサポートされません）
- <strong>Format</strong>: 有効な JSON である必要があります（リンターで確認してください）

## 確認

インストール後:
1. MCP ツールバーに「1 available MCP server」と表示されることを確認します。
2. ハンマーアイコンをクリックして、利用可能な Bitrise ツールを確認します。
3. 「List my Bitrise apps」と入力してテストします（リモートサーバーを使用している場合、最初の呼び出しで OAuth のサインインがトリガーされます）。
4. サーバー名の横に緑色のドットが表示されていることを確認します。

## 高度な設定

特定の API グループを有効化・無効化する方法については、[Tools](/bitrise-platform/ai/bitrise-mcp/tools)を参照してください。

## トラブルシューティング

### リモートサーバーの問題
- <strong>OAuth flow doesn't open browser</strong>: Windsurf を最新のビルドに更新してください。古いバージョンでは PAT ベースの認証にフォールバックしてください。
- <strong>Authentication の失敗（PAT）</strong>: PAT の有効期限が切れていないか、失効していないかを確認してください。
- <strong>接続エラー</strong>: HTTPS 接続に関するファイアウォール/プロキシの設定を確認してください。
- <strong>Streamable HTTP が機能しない</strong>: 正しい `serverUrl` フィールド形式を使用しているか確認してください。

### 一般的な問題
- <strong>Invalid JSON</strong>: [jsonlint.com](https://jsonlint.com) で検証してください。
- <strong>Tools not appearing</strong>: Windsurf を完全に再起動してください。
- <strong>Check ログ</strong>: `~/.codeium/windsurf/logs/`

## 重要な注意事項
- <strong>Windsurf の制限事項</strong>: 環境変数の展開はサポートされておらず、グローバル設定のみ利用可能です。
