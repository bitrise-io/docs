## 前提条件 {#prerequisites}
- [VS Code](https://code.visualstudio.com/Download) がインストールされていること（MCP OAuth をサポートする最近のバージョン）
- Bitrise アカウント
- ローカルセットアップの場合： [Go](https://go.dev/)（1.25以上）がインストールされていること、および Bitrise PAT

## リモートサーバーのセットアップ(Streamable HTTP)(推奨) {#remote-server-setup-streamable-http--recommended}

VS Code の MCP 統合が OAuth を自動的に処理します。初回接続時にブラウザが開き、Bitrise へのサインインを求められます。トークンは不要です。

[VS Code | MCP サーバーを追加する](https://code.visualstudio.com/docs/copilot/customization/mcp-servers#_add-an-mcp-server)の手順に従い、次の内容を設定に追加してください。

```json
{
  "servers": {
    "bitrise": {
      "type": "http",
      "url": "https://mcp.bitrise.io"
    }
  }
}
```

設定を保存します。VS Code が変更を認識し、初回のツール使用時にブラウザ経由でサインインを求め、Copilot Chat にツールを読み込みます。

### フォールバック: PATベースの認証 {#fallback-pat-based-authentication}

お使いの VS Code ビルドがまだ MCP OAuth をサポートしていない場合は、個人アクセストークン(Personal Access Token)を使用できます。

```json
{
  "servers": {
    "bitrise": {
      "type": "http",
      "url": "https://mcp.bitrise.io",
      "headers": {
        "Authorization": "Bearer ${input:bitrise-token}"
      }
    }
  },
  "inputs": [
    {
      "id": "bitrise-token",
      "type": "promptString",
      "description": "Bitrise token",
      "password": true
    }
  ]
}
```

プロンプトが表示されたら、[Account Settings → Security](https://app.bitrise.io/me/account/security)の下にある[Bitrise API トークンを作成](https://devcenter.bitrise.io/api/authentication)してください。

## ローカルサーバーのセットアップ(Go が必要) {#local-server-setup-go-required}

ローカルの stdio モードでは、個人アクセストークンで認証します。

```json
{
  "servers": {
    "bitrise-local": {
      "type": "stdio",
      "command": "go",
      "args": [
        "run",
        "github.com/bitrise-io/bitrise-mcp/v2@v2"
      ],
      "env": {
        "BITRISE_TOKEN": "${input:bitrise-token}"
      }
    }
  },
  "inputs": [
    {
      "id": "bitrise-token",
      "type": "promptString",
      "description": "Bitrise token",
      "password": true
    }
  ]
}
```

## 詳細設定 {#advanced-configuration}

VS Codeでは、1回のチャットリクエストで使用できるツールは最大128個で、組み込みツールもこの上限に含まれます。デフォルトのツールセットはBitriseのツールを88個公開し、`all`は136個公開します。そのため、組み込みツールや他のMCPサーバーと合わせると、チャットリクエストが「Cannot have more than 128 tools per request」というエラーで失敗することがあります。GitHub Copilotはツールを動的に読み込まないため、サーバーURLの`toolset`クエリパラメーターで、必要なツールセットのみを有効にすることをお勧めします。次の例では、CIのツールのみを残します。

```json
{
  "servers": {
    "bitrise": {
      "type": "http",
      "url": "https://mcp.bitrise.io/?toolset=apps,builds,workspaces,outgoing-webhooks,artifacts,group-roles,cache-items,pipelines,account,configuration,insights"
    }
  }
}
```

ローカルサーバーの場合は、同じカンマ区切りのリストを、代わりに`ENABLED_TOOLSET`環境変数に指定します。チャットビューのツールピッカーで、個別のツールをオフにすることもできます。

有効にしていないツールセットのツール（ストアリリースのツールなど）がタスクで必要な場合、エージェントは`list_toolset`を呼び出して、追加するツールセットを確認できます。

すべてのツールセットと、一般的なツール数の上限に収まる組み合わせについては、[ツールセット](/bitrise-platform/ai/bitrise-mcp/tools#advanced-configuration)を参照してください。
