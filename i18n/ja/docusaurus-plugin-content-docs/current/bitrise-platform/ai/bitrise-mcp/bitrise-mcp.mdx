Bitrise Model Context Protocol（MCP）Serverを使うと、AIクライアントからBitriseとやり取りできます。既存のCI環境とシームレスに連携します。

- 直接失敗の原因を尋ねることで、問題のトラブルシューティングができます。AIがログや設定を解析し、実行可能な推奨事項を提示します。
- AIに改善案を提案するよう指示することで、設定を最適化できます。即座にインサイトと実用的な提案が得られます。
- 権限の管理、プロジェクトへのメンバーの招待、古いビルドの検索といった手作業のタスクを自動化できます。要件をAIエージェントに伝えると、レビュー用の提案手順が送られ、各アクションを実行する前に許可を求められます。プロセスの各ステップで結果を確認できます。

リモートのMCPサーバーはmcp.bitrise.ioでホストされています。ほとんどのMCPクライアント（Claude Code、Cursor、VS Codeなど）はOAuth経由で認証します。URLを指定すると、初回利用時にBitriseへのログインを求められます。MCPOAuthにまだ対応していないクライアントは、HTTPヘッダーにPersonal Access Tokenを渡すことで認証できます`Authorization: Bearer <YOUR_BITRISE_PAT>`。

[Bitrise MCPリポジトリはGitHubにあります](https://github.com/bitrise-io/bitrise-mcp)。主に次の内容が含まれます。

- 特定のMCPクライアント向けのインストールガイド。現在サポートされているクライアントは、VS Code、他のIDEのGitHub Copilot、Claude Applications（DesktopおよびCode CLI）、Cursor、Windsurf、AWS Kiro、Gemini CLIです。
- リモートのサーバーではなく、ローカルのMCPサーバーを使う方法。
- 利用可能なツールと、その使用を制限する方法。
