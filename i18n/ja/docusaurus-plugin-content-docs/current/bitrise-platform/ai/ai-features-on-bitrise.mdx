Bitriseでは、Mobile DevOpsプロセスを強化するための複数のAI機能を提供しています。個々の機能を有効または無効にすることも、AI機能全体を完全に無効にすることもできます。詳細は[BitriseでのAI機能の有効化](/bitrise-platform/ai/enabling-ai-features-on-bitrise)をご覧ください。

利用できる機能は次のとおりです。

## コードレビュー

AIの[コードレビュー](/bitrise-platform/integrations/ai-code-reviewer)は、GitHubで新しいプルリクエストが作成されるたびに、またユーザーがプルリクエストに新しいコミットを追加するたびにコメントを作成します。次のような情報を提供できます。

- サマリー: 主要なコードの変更点とその影響を強調します。
- ウォークスルー: コンテキストを考慮したドキュメントを生成し、チームメンバーがコードの変更をすばやく理解できるようにします。
- Code review: 潜在的な問題を検出し、改善案を提案し、コードの品質を向上させます。

コードレビュー機能は、Bitrise GitHubアプリまたはOAuth接続のいずれかを介したGitHub接続でのみ動作します。

:::note[コードレビューとクレジットの使用]

[ProプランまたはEnterpriseプラン](https://bitrise.io/pricing)をお持ちの場合、3つのプロジェクトでコードレビュー機能を有効にできます。コードレビューを実行すると、レビュー1回につきAIクレジットを1つ消費します。

プロジェクトやAIクレジットを追加する必要がある場合は、<strong>Workspace settings</strong> → <strong>Planと請求</strong> → <strong>Bitrise AI</strong>に移動し、アドオンに登録してください。たとえば、追加プロジェクトを1つ登録すると、プロジェクトが4つになり、base planのAIクレジットに加えて、AIクレジットが100増えます。

:::

## AIビルドサマリー

[AIビルドサマリー](/bitrise-ci/run-and-analyze-builds/build-data-and-troubleshooting/ai-build-summary)は、CIのビルドが失敗した理由の要約を提供し、ビルドページ上でその場で修正方法を提案します。この機能はいつでもオフにできます。

![Bitrise AIパネル（失敗の詳細、理由、推奨される解決策を表示）](/img/run-and-analyze-builds/2026-07-14-bitrise-ai-failure-details-panel.png)

## AIビルド修正機能

ビルドが失敗した場合、[AIビルド修正機能](/bitrise-ci/run-and-analyze-builds/build-data-and-troubleshooting/ai-build-fixer)は、他のツールやプロセスに切り替えることなく、ビルドの詳細ページ上でその場で修正します。AIビルド修正機能は、提案されたコードの変更を実行し、GitHubリポジトリにPRをプッシュします。変更内容は、リポジトリへのリンクから確認できます。設定されたビルドトリガーに基づいて、BitriseはAIによる変更を検証するために新しいCIビルドを開始します。これにより、作業の分断が減り、デバッグがより迅速になります。

AIビルド修正機能を使用するには、事前にAIビルドサマリーを有効にしておく必要があります。

## AI設定アシスタント

[AI設定アシスタント](/bitrise-ci/workflows-and-pipelines/ai-configuration-assistant)は、Workflow Editorに組み込まれたチャット形式のアシスタントです。実現したい内容を平易な言葉で説明すると、アシスタントが検証済みのYAMLで動作するWorkflowまたはPipelineを生成します。生成されたものは、アシスタントを使って、または手動でさらに調整できます。

アシスタントは、次のこともできます。

- 既存のWorkflowやPipelineについて、各Stepが何を行うかを含めて平易な言葉で説明する。
- 既存の設定に対する改善案を提案する。

AI設定アシスタントを使用するには、各プロジェクトの<strong>Project settings > Bitrise AI</strong>で<strong>Configuration generator</strong>機能を有効にしておく必要があります。

## Bitrise MCP

[Bitrise Model Context Protocol（MCP）サーバー](/bitrise-platform/ai/bitrise-mcp)を使用すると、お好みのAIクライアントを介してBitriseとやり取りできます。既存のCI環境とのシームレスな連携が可能です。

- 失敗の理由について直接質問することで、問題のトラブルシューティングができます。AIがログと設定を分析し、実行可能な推奨事項を提供します。
- AIに改善案の提案を指示することで、設定を最適化できます。即座にインサイトと実用的な提案を受け取れます。
- 権限の処理、プロジェクトへのメンバーの招待、古いビルドの検索など、手動タスクを自動化できます。要件をAIエージェントに伝えると、確認用の提案手順が送られ、各アクションを実行する前に許可を求められます。プロセスの各ステップで結果を確認できます。

Bitrise MCPは、Claude、Cursor、VS Code、Windsurf、Gemini CLI、AWS Kiroなど、複数のAIクライアントをサポートしています。サポートされているクライアントの全リストとセットアップ手順については、[Bitrise MCP](/bitrise-platform/ai/bitrise-mcp)をご覧ください。
