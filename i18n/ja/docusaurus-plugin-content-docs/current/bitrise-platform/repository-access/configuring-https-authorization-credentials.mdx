非公開プロジェクトの場合、Personal Access Tokenを使って、HTTPS URL経由でBitriseにリポジトリへのアクセスを許可できます。これは、新しいビルドを開始する際にBitriseがリポジトリを[仮想マシン](/bitrise-platform/infrastructure/build-machines/about-build-machines)にクローンできるようにするために必要です。認証は次のタイミングで設定できます。

- [新しいプロジェクトを追加するとき](/bitrise-ci/getting-started/adding-a-new-project)。
- <strong>Project settings</strong>ページでいつでも設定できます。

<strong>Project settings</strong>ページで、HTTPS URLを使ってリポジトリの認証を設定するには、次の手順を行います。

1. Gitプロバイダーで Personal Access Token を作成し、保存します。

   - [GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)
   - [Gitlab](https://docs.gitlab.com/ee/user/profile/personal_access_tokens.html)
   - [Bitbucket](https://support.atlassian.com/bitbucket-cloud/docs/create-a-repository-access-token/)

   :::note[きめ細かなアクセス]

   Personal Access Token には、リポジトリへの<strong>読み取り</strong>権限が必要です。リポジトリやGitプロバイダーのアカウントに対して追加の権限を持たない、きめ細かなPersonal Access Tokenの使用をお勧めします。

   :::
1. <Partial_GettingToTheProjectSettingsPage />
1. HTTPS URLがあることを確認します。左側で<strong>Basic settings</strong>を選択し、<strong>Repository URL</strong>を見つけます。
1. 左側で<strong>Repository</strong>を選択します。
1. <strong>Authorization</strong>セクションで、<strong>Authorization method</strong>カードを見つけて、<strong>Add credentials</strong>をクリックします。

   ![SCR-20260331-prho.png](/img/_paligo/uuid-3de8dcba-e678-997e-20f0-3055cd889bb0.png)
1. ダイアログでPersonal Access Tokenを追加します。

   :::note[Bitbucket ユーザー名]

   リポジトリがBitbucket上にある場合は、Bitbucketのユーザー名も入力する必要があります。

   :::

   ![change-https-credentials.png](/img/_paligo/uuid-c1bacf0c-d211-9674-a2d6-625665e9b381.png)
1. 完了したら、<strong>Save changes</strong>をクリックします。
