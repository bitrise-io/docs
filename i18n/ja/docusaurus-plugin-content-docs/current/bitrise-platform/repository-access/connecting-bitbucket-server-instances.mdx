プライベートにホストされたリポジトリに CI ビルドでアクセスするには、Bitrise workspace を Bitbucket Server に接続します。次の対応が必要です。

- サーバーで新しい Application Link を作成します。
- Authorize Bitriseし、必要な権限を割り当てます。
- 必要な認証情報を workspace settings にコピーします。

1. <strong>admin</strong> 権限で Bitbucket Server インスタンスに Log inします。
1. 上部メニューバーの設定アイコンをクリックして <strong>Administration</strong> にアクセスします。
1. 左側のメニューバーで Integrations セクションを見つけ、<strong>Application Links</strong> を選択します。
1. <strong>Create link</strong> をクリックします。

   ![2025-11-13-bitbucket-app-links.png](/img/_paligo/uuid-f87af39b-bb44-1167-0051-389e3b38c612.png)
1. <strong>External Application</strong> を選択し、方向として <strong>Incoming</strong> を選択します。
1. Name フィールドに、アプリケーションを明確に識別できる名前を入力します。わかりやすくするため、<strong>Bitrise</strong> を推奨します。
1. <strong>Redirect URI</strong> フィールドに https://app.bitrise.io/users/auth/bitbucket_server/callback. を入力します。
1. <strong>Application permissions</strong> で <strong>Repositories</strong> を見つけて <strong>Admin</strong> を選択します。
1. <strong>Save</strong> をクリックすると、<strong>Credentials</strong> ページに移動します。

   ![20251113-bitbucket-credentials.png](/img/_paligo/uuid-dbf18dae-38c9-f32a-fb61-6afbb08edb2f.png)
1. <strong>Client ID</strong> と <strong>Client secret</strong> をコピーします。
1. Bitrise で <strong>Workspace settings</strong> ページを開き、<strong>Integrations</strong> を選択します。
1. <strong>Bitbucket Server</strong> を選択し、<strong>Add credentials</strong> をクリックします。

   ![2025-11-13-bitbucket-server-integration.png](/img/_paligo/uuid-6657cf32-779e-915b-aaea-453f88b28ec8.png)
1. 認証情報を追加します。

   - <strong>App ID</strong>: Bitbucket Server からコピーした Client ID
   - <strong>Secret</strong>: Bitbucket Server からコピーした Client secret
   - <strong>URL</strong>: サーバーのベース URL
