<GlossTerm baseform="workspace">workspace</GlossTerm>は、Bitriseの<GlossTerm baseform="project">プロジェクト</GlossTerm>とそのプロジェクトに携わるチームメンバーを管理するための環境です。workspacesを複数作成できるほか、workspacesに他のBitriseユーザーから招待されることもあります。

プロジェクトを追加してビルドを実行するには、workspaceに所属しているか、プロジェクトのチームに外部協力者として参加している必要があります。

また、workspaceは[有効なサブスクリプションプラン](https://www.bitrise.io/pricing)をBitriseで保持している必要があります。workspacesごとに異なるサブスクリプションプランを設定でき、そのプランによってworkspaceのプロジェクトが使用できるクレジット数が決まります。
