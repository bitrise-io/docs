Bitriseには、<GlossTerm baseform="workspace">workspace</GlossTerm>レベルとプロジェクトレベルの両方に組み込みのシステムロールが用意されていますが、アクセス権の管理方法はチームによって異なります。<GlossTerm baseform="custom role">カスタムロール</GlossTerm>を使用すると、ロールに名前を付け、用途を説明し、適用範囲を選択し、付与する権限を正確に指定できます。

組み込みのシステムロールとは異なり、カスタムロールはいつでも編集または削除できます。また、割り当て方法は他の組み込みロールと同じで、個人に直接割り当てるか、workspace グループに割り当てます。

:::important[Enterpriseプラン]

カスタムロールはEnterpriseプランで利用できます。UIは現在利用可能です。カスタムロールをプログラムで作成・変更するためのAPI、CLI、MCPアクセスはまだ利用できず、今後の段階的リリースで提供予定です。

:::

## カスタムロールの適用範囲

カスタムロールを作成する際は、次の2つのスコープのいずれかを選択します。

- <strong>Workspace</strong>: 課金、メンバー、workspace settings、セキュリティ。組み込みのWorkspaceレベルのロールについては、[workspacesのロールと権限](/bitrise-platform/workspaces/collaboration-and-permissions-in-workspaces/roles-and-permissions-in-workspaces)を参照してください。
- <strong>Bitrise CI</strong>: アプリ、ビルド、ワークフロー、シークレット、ビルド承認。組み込みのプロジェクトレベルのロールについては、[Bitrise CIのロールと権限](/bitrise-platform/projects/roles-and-permissions-for-bitrise-ci)を参照してください。

WorkspaceとBitrise CIは1つの階層内のレベルではなく、それぞれが独自の組み込みロールを持つ独立したスコープです。カスタムロールは第三のスコープではなく、これら2つのいずれかの中で追加のロールを作成できるようにするものです。

<strong>Bitrise CI</strong>スコープのカスタムロールは、Admin や Developer などの既存の組み込みプロジェクトロールと同様に、割り当てた特定のプロジェクトにのみ適用され、workspace内のすべてのBitrise CIプロジェクトに一括で適用されるわけではありません。カスタムロールは、Release Managementのような独自のアクセスモデルを持つ他のBitrise製品には拡張されません。

:::note

組み込みかカスタムかを問わず、保有するすべてのロールの権限は合算されます。あるロールを使って、別のロールが付与する権限を明示的にブロックしたり上書きしたりすることはできません。

:::

## ロールの作成と割り当て

workspace の Owner または Manager は、カスタムロールの作成、編集、削除を行えます。ロールが作成されると、他のロールと同じ方法で割り当てられます。個人に直接割り当てるか、workspace グループに割り当てます。

カスタムロールの作成、編集、削除、および再割り当ては、現在いずれもworkspaceの監査証跡の一部として記録されます。
