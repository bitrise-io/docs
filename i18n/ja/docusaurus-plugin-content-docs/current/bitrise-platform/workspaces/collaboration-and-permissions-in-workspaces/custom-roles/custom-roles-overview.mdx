Bitrise には、<GlossTerm baseform="workspace">workspace</GlossTerm> レベルとプロジェクトレベルの両方に組み込みのシステムロールが用意されていますが、アクセス管理の方法はチームごとに異なります。<GlossTerm baseform="custom role">カスタムロール</GlossTerm> では、ロールに名前を付け、用途を説明し、適用範囲を選択して、付与する権限を細かく指定できます。

組み込みのシステムロールとは異なり、カスタムロールはいつでも編集または削除でき、組み込みのシステムロールと同じ方法で割り当てられます。ユーザーに直接割り当てるか、workspace グループに割り当てます。

:::important[Enterprise plan]

カスタムロールは Enterprise プランで利用できます。UI は現在利用可能です。カスタムロールをプログラムで作成および変更するための API、CLI、MCP アクセスはまだ利用できません。これは、今後の段階的なリリースで提供予定です。

:::

## カスタムロールの適用範囲 {#where-custom-roles-apply}

すべてのカスタムロールは、作成時に次の 2 つのスコープのいずれかを選択します。

- <strong>Workspace</strong>: 請求、メンバー、workspace settings、セキュリティ。このスコープのカスタムロールで付与できるすべての権限については、[Workspace スコープの権限](/bitrise-platform/workspaces/collaboration-and-permissions-in-workspaces/custom-roles/permissions-reference#workspace-scoped-permissions)を、組み込みの Workspace レベルのロールについては、[Roles and permissions in workspaces](/bitrise-platform/workspaces/collaboration-and-permissions-in-workspaces/roles-and-permissions-in-workspaces)を参照してください。
- <strong>Bitrise CI</strong>: アプリ、ビルド、Workflow、シークレット、ビルド承認。このスコープのカスタムロールで付与できるすべての権限については、[Bitrise CI スコープの権限](/bitrise-platform/workspaces/collaboration-and-permissions-in-workspaces/custom-roles/permissions-reference#bitrise-ci-scoped-permissions)を、組み込みのプロジェクトレベルのロールについては、[Roles and permissions for Bitrise CI](/bitrise-platform/projects/roles-and-permissions-for-bitrise-ci)を参照してください。

Workspace と Bitrise CI は、1 つの階層構造のレベルではありません。それぞれが独自の組み込みロールを持つ独立したスコープです。カスタムロールは 3 つ目のスコープではなく、これら 2 つのスコープのいずれかの中で追加のロールを作成するための仕組みです。

<strong>Bitrise CI</strong> スコープのカスタムロールは、割り当てた特定のプロジェクトにのみ適用されます。これは、Admin や Developer などの組み込みのプロジェクトロールが現在動作する方法と同じで、workspace 内のすべての Bitrise CI プロジェクトに一度に適用されるわけではありません。カスタムロールは、Release Management など、独自のアクセスモデルを持つ他の Bitrise 製品には拡張されません。

:::note

保持しているすべてのロール(組み込みかカスタムかを問わず)の権限は、組み合わされて適用されます。あるロールを使って、別のロールで付与された権限を明示的にブロックしたり上書きしたりすることはできません。

:::

## ロールの作成と割り当て {#creating-and-assigning-a-role}

workspace の Owner または Manager は、カスタムロールの作成、編集、削除ができます。ロールを作成したら、他のロールと同じ方法で割り当てます。ユーザーに直接割り当てるか、workspace グループに割り当てます。

カスタムロールの作成、編集、削除、および再割り当てはすべて、現在、workspace の監査証跡の一部として記録されます。
