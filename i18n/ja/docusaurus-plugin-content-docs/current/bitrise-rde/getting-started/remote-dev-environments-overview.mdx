<GlossTerm baseform="remote dev environment">Remote Dev Environment</GlossTerm>(RDE)は、macOSまたはLinux上で動作するオンデマンドのクラウドマシンで、Bitrise CIと同じインフラストラクチャ、<GlossTerm baseform="stack">スタック</GlossTerm>、キャッシュを使用します。<GlossTerm baseform="rde session">セッション</GlossTerm>を数秒で起動し、ターミナル、IDE、またはAIコーディングエージェントから接続し、作業が終わったらアーカイブします。永続ディスクは保持されるため、作成元のスタックが利用可能である限り、セッションを復元して中断したところから作業を再開できます。

## RDEを使用する理由

Remote Dev Environmentを使用すると、自前のハードウェアを用意することなく、クラウド上で強力かつ事前設定済みのマシンを利用できます。次のような場合に適しています。

- ノートパソコンよりもはるかに強力なマシンで開発する(ツールチェーンはあらかじめインストールおよびキャッシュ済みです)。
- Claude CodeのようなAIコーディングエージェントを、アプリのビルドとテストが可能なサンドボックス内で、自分のAPIキーを使って実行する。
- ビルドが実行される環境と一致する環境で、CIの失敗を再現する。
- 短期的なタスク向けに、並行で使い捨て可能な環境を起動し、作業後に破棄する。
- セッションから直接ブランチをプッシュし、プルリクエストを作成する: [GitHub連携](/bitrise-rde/configuration/github-integration)により、gitおよびGitHub CLIはユーザー自身として認証されます。
- セッションでiOSシミュレーターまたはAndroidエミュレーターを起動してアプリをテストする、あるいはブラウザ上で実行できる[デバイスプレビューリンク](/bitrise-rde/devices/device-preview-links)を通じて誰とでもビルドを共有する。[Virtual devices](/bitrise-rde/devices/virtual-devices)を参照してください。

RDEはBitrise CIと同じマシンおよびスタックを使用するため、コードを記述する環境とテストする環境が一致します。

## サポートされているプラットフォーム

RDEは、米国およびEUのデータセンターにある本番グレードのBitriseインフラストラクチャ上で動作します。

- <strong>macOS</strong>: iOS、macOS、クロスプラットフォーム開発向けのAppleシリコンマシン(M2 Pro、M4、M4 Pro)。macOSセッションでは、VNC経由でグラフィカルデスクトップも利用できます。
- <strong>Linux</strong>: 専用および共有クラスター上で、2〜48 vCPUのマシンを提供し、Dockerを完全にサポートします。

セッションの作成時、直接またはテンプレート経由でマシンを選択します。利用可能な正確なスタックとマシンタイプについては、[セッションを作成](/bitrise-rde/rde-options/bitrise-rde-ui)する際に製品内の一覧を確認してください。

## RDEの利用方法

セッションの作成と接続には、複数のクライアントを利用できます。どれも同じセッション、<GlossTerm baseform="rde template">テンプレート</GlossTerm>、<GlossTerm baseform="saved input">保存済み入力</GlossTerm>を共有しているため、自分の作業スタイルに合ったものを選んでください。

- [Bitrise RDE CLI](/bitrise-rde/rde-options/bitrise-rde-cli): ターミナルからセッションを管理し、1つのコマンドでセッション内にAIコーディングエージェントを起動できます。最も素早く始められる方法です。
- [Bitrise RDE UI](/bitrise-rde/rde-options/bitrise-rde-ui): ブラウザからセッション、テンプレート、保存済み入力を作成・管理し、組み込みのWebターミナルで接続します。
- [MCPサーバー](/bitrise-rde/rde-options/bitrise-rde-mcp-server): Model Context Protocolをサポートする任意のAIアシスタントが、代わりにセッションを作成・操作できるようにします。
- [Bitrise VS Code プラグイン](/bitrise-rde/rde-options/bitrise-vscode-plugin): 新しいセッションでリポジトリを開き、VS Codeから編集します。このクライアントは近日公開予定です。

どこから始めればよいかわからない場合は、[Quickstart](/bitrise-rde/getting-started/quickstart)に従ってください。

## 必要なもの

Remote Dev Environmentsを使用するには、次のものが必要です。

- RDEアクセス権を持つBitrise <GlossTerm baseform="workspace">workspace</GlossTerm>。[Remote Dev Environmentsページ](https://bitrise.io/platform/remote-dev-environments)でサインアップするか、組織が営業経由で購入している場合はBitriseにお問い合わせください。
- そのworkspaceにおける<strong>RDE User</strong>ロール。メンバーに自動的には付与されません。workspaceのオーナーまたはマネージャーが付与します: [Managing RDE access](/bitrise-rde/configuration/managing-rde-access)を参照してください。
- 選択したクライアントに応じた接続手段: Bitrise CLI、サポートされているAIアシスタント、またはブラウザ。
