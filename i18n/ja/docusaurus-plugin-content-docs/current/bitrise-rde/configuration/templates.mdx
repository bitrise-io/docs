<GlossTerm baseform="rde template">テンプレート</GlossTerm>は、Remote Dev Environment設定を再利用可能にしたものです。マシンとそのセットアップを一度定義すれば、そのたびに同じ選択を繰り返すことなく、一貫した<GlossTerm baseform="rde session">セッション</GlossTerm>を作成できます。

## テンプレートの概要 

テンプレートには、次の内容を含めることができます。

- スタック、マシンタイプ、ターミナルの起動時の作業ディレクトリ。
- ツールのインストールや環境準備を行うウォームアップスクリプトとスタートアップスクリプト。
- 環境に必要な値を指定するテンプレート変数とセッション入力。
- Workspaceリンク: IDEで特定のフォルダを開くショートカットボタン。
- 仮想デバイス: テンプレートから作成するすべてのセッションで起動する、iOSシミュレーターまたはAndroidエミュレーター。

## ウォームアップスクリプトとスタートアップスクリプト

どちらのスクリプトもBashで記述し、セッションユーザーとして実行されますが、実行されるタイミングが異なります。

- ウォームアップスクリプトは、セッションが最初に作成されたときに一度だけ実行されます。依存関係のインストールなど、時間のかかる一度限りのセットアップに使用します。
- スタートアップスクリプトは、復元後を含め、セッションが開始するたびに実行されます。複数回実行されるため、冪等になるようにしてください。

## 変数と入力

テンプレートは2種類の値を保持でき、どちらもenvironment variablesとしてセッションに公開できます。

- テンプレート変数は、固定値としてテンプレートに組み込まれます。変数をシークレットとしてマークすると、保存時に暗号化されます。
- セッション入力は、セッションの作成時に入力されます。入力を必須としてマークし、default valueを指定できます。セッション入力は[保存済みの入力](/bitrise-rde/configuration/saved-inputs)から値を取得することもでき、その場合シークレットはサーバー側で解決され、UIには表示されません。

## Workspaceリンク

Workspaceリンクは、指定したフォルダパスをIDEで開くセッション上のボタンです。複数フォルダで構成されるプロジェクトで、目的のディレクトリに直接移動する際に便利です。

## 宣言済みデバイス

テンプレートは仮想デバイスを宣言でき、これによりテンプレートから作成されるすべてのセッションは、セッション側でデバイス設定を行わなくても、iOSシミュレーターまたはAndroidエミュレーターを起動します。テンプレートフォームで<strong>セッションごとにデバイスを起動する</strong>をオンにするか、CLIを使用してください。

```bash
bitrise-cli rde template create --file template.json --device-platform ios --device-model "iPhone 16"
```

テンプレートのstack and machine typeは、プラットフォームに適合している必要があります。iOSの場合はmacOSスタック、Androidの場合はLinux Androidスタックです。テンプレートからセッションを作成する際は、デバイスを宣言どおりに保持する、そのセッションのみ個別のフィールドを変更する、またはUI内の<strong>iOSシミュレーターをStart</strong>もしくは<strong>AndroidエミュレーターをStart</strong>とCLI内で`--no-device`操作によってオフにする、のいずれかを選択できます。テンプレートからすでに作成済みのセッションは、作成時のデバイス設定を維持します。デバイスオプション自体については、[デバイスセッション](/bitrise-rde/devices/device-sessions#device-options)で説明しています。

## テンプレートの管理

テンプレートの作成、編集、複製、削除は、[Bitrise RDE UI](/bitrise-rde/rde-options/bitrise-rde-ui)、または`bitrise-cli rde template`を使用したCLIから行えます。

セッションを作成すると、そのテンプレート設定はスナップショットとして記録されます。その後テンプレートを編集または削除しても、すでにそのテンプレートから作成されたセッションには影響しません。
