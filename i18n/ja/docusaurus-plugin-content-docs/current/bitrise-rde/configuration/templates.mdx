<GlossTerm baseform="rde template">テンプレート</GlossTerm>は、再利用可能な Remote Dev Environment の設定です。マシンとそのセットアップを一度定義すれば、毎回同じ選択を繰り返すことなく、そこから一貫した<GlossTerm baseform="rde session">セッション</GlossTerm>を作成できます。

## テンプレートの概要 {#template-overview}

テンプレートには次の内容を含められます：

- スタック、マシンタイプ、ターミナルが開始する作業ディレクトリ。
- ライフサイクルフック：セッションの作成時、誰かがセッションを取得したとき、復元のたびに実行されるセットアップスクリプト。
- 環境に必要な値のための変数と入力。
- Workspaceリンク：IDEで特定のフォルダーを開くショートカットボタン。
- 仮想デバイス：テンプレートから作成されるすべてのセッションが起動する、iOSシミュレーターまたはAndroidエミュレーター。

## ライフサイクルフック {#lifecycle-hooks}

テンプレートは、[ライフサイクルフック](/bitrise-rde/configuration/lifecycle-hooks)でセッションをセットアップします。各フックは、セッションの存続期間中の特定のタイミングで、セッションユーザーとして実行されるBashスクリプトです：

- <strong>On create</strong> は、セッションの作成時に1回実行されます。リポジトリのクローンや依存関係のインストールなど、時間がかかる1回限りのセットアップに使用します。
- <strong>On claim</strong> は、セッションが誰かに割り当てられたときに実行されます。その人固有のセットアップに使用します。
- <strong>On restore</strong> は、停止したセッションが復元されるたびに実行されます。サービスの再起動に使用します。

すべてのフックは任意です。ライフサイクルフックの導入前に作成されたテンプレートには、代わりにウォームアップスクリプトと起動スクリプトがあります。これらは引き続き動作し、[変換する](/bitrise-rde/configuration/lifecycle-hooks#converting-a-template-with-warmup-and-startup-scripts)こともできます。

## 変数と入力 {#variables-and-inputs}

テンプレートには2種類の値があります：

- 変数はテンプレートに保存され、すべてのセッションで同じ値になります。変数をシークレットとしてマークすると保存時に暗号化され、保護対象としてマークすると書き込み専用にもなります。
- 入力はセッションごとに入力します。入力を必須にしたり、default valueを設定したりできます。入力は[保存済み入力](/bitrise-rde/configuration/saved-inputs)から値を取得することもでき、シークレットはサーバー上で解決され、UIには表示されません。

すべての変数と入力にはスコープがあります：Sharedの値はすべてのフックに届き、フック固有の値はそのフックにのみ届きます。値をセッションのターミナルでも使えるようにするには、<strong>Also in terminal</strong> をオンにします。[変数と入力](/bitrise-rde/configuration/lifecycle-hooks#variables-and-inputs)を参照してください。

## Workspaceリンク {#workspace-links}

Workspaceリンクは、セッション上のボタンで、指定したフォルダーパスを IDE で開きます。複数フォルダーのプロジェクトで、目的のディレクトリにすばやく移動するのに便利です。

## 宣言済みデバイス {#declared-device}

テンプレートで仮想デバイスを宣言すると、そこから作成されるすべてのセッションで、セッション側のデバイス設定なしに iOS シミュレーターまたはAndroidエミュレーターが起動します。テンプレートフォームで <strong>Boot a device with every session</strong> をオンにするか、CLIを使用してください。

```bash
bitrise-cli rde template create --file template.json --device-platform ios --device-model "iPhone 16"
```

テンプレートのstack and machine typeは、プラットフォームに適合している必要があります。iOS の場合は macOS スタック、Androidの場合は Linux Android スタックです。テンプレートからセッションを作成するときは、デバイスを宣言どおりに維持するか、そのセッションに限って個々のフィールドを変更するか、UIの <strong>Start an iOS simulator</strong> または <strong>Start an Android emulator</strong>、およびCLIの`--no-device`でオフにできます。テンプレートからすでに作成されたセッションは、作成時のデバイスを保持します。デバイスオプション自体については、[Device sessions](/bitrise-rde/devices/device-sessions#device-options)で説明しています。

## テンプレートの管理 {#managing-templates}

[Bitrise RDE UI](/bitrise-rde/rde-options/bitrise-rde-ui)から、またはCLIから`bitrise-cli rde template`を使って、テンプレートの作成、編集、複製、削除ができます。

セッションを作成すると、そのテンプレート構成がスナップショットとして取得されます。その後にテンプレートを編集または削除しても、すでに作成されたセッションは変更されたり壊れたりしません。これはフックにも当てはまります：復元、失敗したフックの再実行、<strong>Rebuild</strong> はすべて、セッション作成時のスクリプトを使用します。修正したスクリプトを使うには、新しいセッションを作成してください。

## Warm pools

テンプレートのセッションを誰かが要求する前に準備しておくには、そこから[warm pool](/bitrise-rde/configuration/warm-pools)を作成します：テンプレートのページで <strong>Create warm pool</strong> をクリックすると、そのテンプレートが選択された状態でプールフォームが開きます。プールはテンプレートに従うため、テンプレートを編集するとプールのウォームセッションが置き換えられ、テンプレートを削除するとそのプールも削除されます。プールで適切に動作するテンプレートの書き方については、[warm poolでのフックの使用](/bitrise-rde/configuration/lifecycle-hooks#using-hooks-with-a-warm-pool)を参照してください。
