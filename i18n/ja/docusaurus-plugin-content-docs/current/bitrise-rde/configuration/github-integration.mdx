[Bitrise GitHub App](/bitrise-platform/repository-access/github-app-integration)連携を使って、<GlossTerm baseform="rde session">セッション</GlossTerm>を本人としてGitHubに対して認証します。新しいセッションではすべて、`git clone`、`git push`、およびGitHub CLI(`gh`)がHTTPS上でそのまま動作するため、個人アクセストークンを貼り付けたりSSHキーを管理したりする必要はありません。

## 概要 {#overview}

この連携を使用するには、Bitrise GitHub App を組織にインストールし、GitHub アカウントをGitHubアプリ経由でBitriseに接続します。

RDE ページで連携を有効にすると、Bitriseは新しいセッションマシンごとに、有効期間の短いGitHubアクセストークンを配置します。このトークンは、Bitrise(Bitrise GitHub App)上のGitHubアカウント接続を通じて発行されます。

- トークンの有効期間は最大 8 時間で、復元を含むセッションの存続期間全体にわたって自動的に更新されます。
- 長期間有効な認証情報がマシンに保存されることはありません。
- セッションで作成したコミットは、GitHubの noreply メールアドレスを使用してGitHubアカウントに紐付けられるため、実際のメールアドレスが公開されることはありません。

## GitHubアプリを組織にインストールする {#installing-the-github-app-to-your-organization}

この連携には、GitHub上で次の 2 つが別々に必要です。

- <strong>Bitrise GitHub App のインストール</strong>: アプリにリポジトリへのアクセス権を与えます。GitHub App は、GitHub上でリポジトリを所有するアカウントまたは組織にインストールされている必要があり、そのリポジトリに対してアプリのインストールが有効になっている必要があります。
- <strong>GitHub account 接続</strong>: Bitrise GitHub App があなたとして動作することを許可します。これはBitrise Connected accountsページで行います。アプリがすでに組織にインストールされている場合でも必要です。詳細は、[連携を有効にする](#enabling-the-integration)を参照してください。

:::important

アカウントを接続しても、アプリはインストールされません。Bitrise GitHub App がリポジトリを所有する組織にインストールされていない場合、連携は接続済みと表示されますが、プライベートリポジトリのクローンはすべて失敗します。

:::

WorkspaceがすでにCI用にGitHub App を使用している場合、アプリはインストール済みです。必要なリポジトリに対してインストールが有効になっていることを確認してください。

そうでない場合は、[Workspace settingsページからGitHubアプリを接続する](/bitrise-platform/repository-access/github-app-integration#connecting-a-github-app-from-the-workspace-settings-page)の説明に従ってアプリをインストールします。アプリをインストールする権限がGitHubにnot authorized場合でも、インストールをリクエストできます。GitHub Admin がインストールを承認すると、セッションからリポジトリにアクセスできるようになります。

## 連携を有効にする {#enabling-the-integration}

1. Bitriseを開きます。
1. <Partial_GettingToYourProfileSettings />
1. <strong>Connected accounts</strong> を選択し、<strong>Git providers</strong> タブを開きます。
1. <strong>GitHub</strong> カード(「Connect via the Bitrise GitHub App」と説明されています)で <strong>Connect</strong> を選択します。<strong>GitHub with OAuth</strong> カードは使用しないでください。この連携にはGitHub App の接続が必要です。

   :::info[Workspaceレベルの接続だけでは不十分です]

   この連携は、個人のGitHubアカウント接続を通じてトークンを発行します。組織の管理者がCI用にBitrise GitHub App をすでに接続している場合でも、<strong>Connected accounts</strong> ページで自分のアカウントを接続する必要があります。セッションがリポジトリにアクセスできるのは、Workspaceのアプリのインストールによるものです。

   :::

1. [Bitrise RDE UI](/bitrise-rde/rde-options/bitrise-rde-ui)で、左側の <strong>User settings</strong> の下にある <strong>Saved Inputs</strong> を選択します。
1. <strong>GitHub</strong> カードで、アカウントが接続済みと表示されていることを確認し、トグルを有効にします。

   ![Saved Inputs ページのGitHubカード。接続済みで、有効にできる状態](/img/rde/2026-07-31-rde-github-integration-card.png)

これ以降に作成した新しいセッションでは、自動的にGitHubアクセスが利用できます。連携を有効にする前に作成したセッションは変更されません。

## アクセスできるリポジトリ {#repositories-you-can-access}

セッションはBitrise GitHub App を通じてあなたとして動作するため、次の条件をすべて満たすリポジトリにアクセスできます。

- GitHub App が、GitHub上でリポジトリを所有するアカウントまたは組織にインストールされている。
- そのリポジトリに対してアプリのインストールが有効になっている。
- GitHubユーザーアカウントが、GitHub上でそのリポジトリにアクセスできる。

:::info[403 エラーまたは repository not found でクローンに失敗する]

ブラウザーで開けるプライベートリポジトリのクローンが`remote: Write access to repository not granted`、`The requested URL returned error: 403`、または`repository not found`で失敗する場合は、Bitrise GitHub App がリポジトリを所有する組織にインストールされていないか、そのリポジトリに対してインストールが有効になっていません。組織のGitHub Admin に、アプリのインストールまたはリポジトリに対する有効化を依頼してください。[GitHubアプリを組織にインストールする](#installing-the-github-app-to-your-organization)を参照してください。その後、アカウントを再接続する必要はありません。

:::

アプリがどのリポジトリにインストールされているかを確認するには、次の手順を実行します。

1. GitHubで、アカウントの[installed GitHub Apps](https://github.com/settings/installations)ページを開きます。アプリが組織レベルでインストールされている場合は、組織のページを開きます。
1. 一覧から <strong>Bitrise</strong> を見つけ、<strong>Configure</strong> を選択します。
1. <strong>Repository access</strong> で、インストールの対象となっているリポジトリを確認します。

## インテグレーションの無効化 {#disabling-the-integration}

連携を無効にすると、認証情報の発行は即座に停止します。新しいセッションは認証情報を受け取らなくなり、実行中のセッションはすぐにトークンを更新できなくなり、最後に発行されたトークンは8時間以内に失効します。

1. [Bitrise RDE UI](/bitrise-rde/rde-options/bitrise-rde-ui)で、左側の<strong>User settings</strong>の下にある<strong>Saved Inputs</strong>を選択します。
1. <strong>GitHub</strong>カードで、トグルをオフにします。
