Bitrise VS Code プラグインは、Remote Dev Environments をエディタに統合します。既存の<GlossTerm baseform="rde session">セッション</GlossTerm>に接続する代わりに、ローカルリポジトリから開始すると、プラグインがセッションを作成してリポジトリをそこにクローンし、VS Code を接続します。そのため、コードが自分のマシン上にあるかのように編集し、ターミナルを実行し、デバッグできます。

## 開始する前に {#before-you-start}

必要なもの:

- RDE アクセスを持つBitrise <GlossTerm baseform="workspace">workspace</GlossTerm>。
- VS Code。プラグインは [Remote - SSH](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-ssh) 拡張機能に依存しており、自動的にインストールされます。
- プライベートリポジトリの場合、セッションがリポジトリをクローンできるように、ローカルのSSHキーが必要です。

## プラグインのインストール {#installing-the-plugin}

[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=bitrise.bitrise) から <strong>Bitrise</strong> をインストールするか、VS Code の拡張機能ビューで `Bitrise` を検索してください。インストール後、アクティビティバーに <strong>Bitrise</strong> アイコンが表示されます。

## サインイン {#signing-in}

1. アクティビティバーから <strong>Bitrise</strong> ビューを開きます。
1. <strong>Sign in to Bitrise</strong> をクリックします。ブラウザが開いて認証します。
1. 使用するworkspaceを選択します。RDE アクセスを持つworkspaceを選択すると、セッションが表示されます。

## 新しいセッションでリポジトリを開く {#opening-a-repository-in-a-new-session}

ローカルリポジトリからセッションを作成するには、<strong>Sessions</strong> ビューの <strong>+</strong> である <strong>Open Repo in New Session</strong> を使用します。プラグインが次の手順を案内します。

1. セッションの名前。
1. 開くローカルリポジトリ。
1. 作業するブランチ。
1. マシンのスタック。
1. マシンの種類。

プラグインはその後、セッションを作成してリポジトリをそこにクローンし、セッションに接続されたリモート VS Code ウィンドウを開きます。

:::important[プッシュ済みのコミットのみがクローンされます]

プラグインは、選択したブランチのプッシュ済みの状態をクローンします。プッシュしていないローカルコミットや未コミットの変更は、セッションに転送されません。

:::

## セッションの管理 {#managing-sessions}

<strong>Sessions</strong> ビューには、workspace内のセッションが一覧表示されます。このビューから次の操作ができます。

- 実行中のセッションをリモートウィンドウで開く、または終了したセッションを復元して開く。
- 実行中のセッションを停止する。
- セッションを [Bitrise RDE UI](/bitrise-rde/rde-options/bitrise-rde-ui)で開く。
- セッションを検索する。

## クイック設定 {#quick-configuration}

<strong>Configuration</strong> ビューを使うと、環境を一度セットアップするだけで、新しいセッションがすぐに使えるようになります。

- <strong>パスワードレスSSH</strong>: SSH公開鍵を[保存された入力](/bitrise-rde/configuration/saved-inputs)として登録し、パスワードなしで接続できるようにします。
- <strong>Claude Code</strong>: Claude Code認証情報を保存し、新しいセッションがClaude Codeに認証済みの状態で開始されるようにします。
- <strong>SSH エージェントフォワーディング</strong>: セッションがローカルの Git キーを使用して push・pull できるようにします。
