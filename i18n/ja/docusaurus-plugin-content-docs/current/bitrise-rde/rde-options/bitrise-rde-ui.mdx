Bitrise RDE UIは、Remote Dev Environments用のWebインターフェースです。<GlossTerm baseform="rde session">セッション</GlossTerm>、<GlossTerm baseform="rde template">テンプレート</GlossTerm>、<GlossTerm baseform="saved input">保存済み入力</GlossTerm>を作成・管理するためのビジュアルな手段であり、ブラウザを離れずにセッション内で作業できる組み込みターミナルも備えています。

開始するには、Bitriseアプリの<strong>Remote Dev Environments</strong>セクションを開きます。表示されない場合は、まだ<strong>RDE User</strong>ロールを持っていません。付与するようworkspaceのオーナーまたはマネージャーに依頼してください。詳細は[Managing RDE access](/bitrise-rde/configuration/managing-rde-access)を参照してください。

## 認証

<strong>Saved inputs</strong>ページで、Claude Codeの認証情報とパスワードレスのSSHアクセスを設定できます。<GlossTerm baseform="saved input">保存済み入力</GlossTerm>は、一度保存してセッションにマッピングできる再利用可能な認証情報や値です。詳細は[Saved inputs](/bitrise-rde/configuration/saved-inputs)を参照してください。

## セッションの作成

1. Remote Dev Environmentsセクションで<strong>New session</strong>をクリックします。
1. セッションのタイトルを設定し、必要に応じて説明も入力します。

   セッションのタイトルは一意である必要があります。
1. 必要に応じて、セッションの起動時に自動的にClaude Codeを開始するAIプロンプトを入力します。これにはClaude Codeの認証情報の保存が必要です。
1. セッションを自動終了するタイミングを選択します。
1. テンプレートを選択するか、<strong>No template</strong>を選んでスタックとマシンタイプを直接指定します。
1. 必要な入力項目をすべて入力します。値を直接入力するか、既存の保存済み入力を選択できます。
1. <strong>Create</strong>をクリックします。

セッションはまもなく開始します。実行中になったら、開いて接続してください。

セッションでiOSシミュレーターまたはAndroidエミュレーターを起動するには、フォームのデバイスセクションを使用します。これは、選択したスタックまたはテンプレートがデバイスに対応している場合に表示されます。詳細は[Device sessions](/bitrise-rde/devices/device-sessions)を参照してください。

## セッションの管理

<strong>Sessions</strong>リストには、workspace内のすべてのセッションがステータスごとにグループ化され、検索機能とともに表示されます。セッションから次の操作を行えます。

- 終了済みのセッションを復元する、または実行中のセッションを終了する。
- 終了済みのセッションを完全に削除する。
- 名前と説明を編集し、自動終了の設定を変更する。

## セッションへの接続

セッション詳細ページは、接続のハブです。ここから次のことができます。

- 複数タブに対応した<strong>組み込みのWebターミナル</strong>を開く。
- <strong>SSH</strong>と<strong>VNC</strong>の認証情報をコピーして、自分のツールから接続する。
- <strong>Open in VS Code</strong>を使用して、VS Code Remote - SSH拡張機能で接続する。
- <strong>workspaceリンクボタン</strong>を使用して、IDEで特定のフォルダを開く。
- セッションがシミュレーターまたはエミュレーターを起動している場合、<strong>Device</strong>行の<strong>Open device view</strong>をクリックして、その画面を確認・操作する。

各方法の詳細は、[Connecting to a session](/bitrise-rde/rde-options/connecting-to-a-session)を参照してください。

## テンプレート

UIから、再利用可能なセッション構成を作成・管理できます。詳細は[Templates](/bitrise-rde/configuration/templates)を参照してください。

## Workspace使用状況

<strong>Usage</strong>ページには、workspaceのアクティブなセッションが現在消費しているリソース(セッション数、OS別に分けたvCPUとメモリの合計、ユーザーごとの内訳)が表示されます。このページを閲覧できるのは、workspaceのオーナーと、請求を管理できるメンバーのみです。同じレポートはプログラムからも取得できます。詳細は[Workspace usage report](/bitrise-rde/configuration/rde-api#workspace-usage-report)を参照してください。
