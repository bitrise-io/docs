Bitrise RDE UI は、Remote Dev Environments 用の Web インターフェースです。<GlossTerm baseform="rde session">セッション</GlossTerm>、<GlossTerm baseform="rde template">テンプレート</GlossTerm>、<GlossTerm baseform="saved input">保存済み入力</GlossTerm>をビジュアルに作成・管理でき、ブラウザーを離れずにセッション内で作業できる組み込みターミナルも備えています。

利用を開始するには、Bitrise アプリの <strong>Remote Dev Environments</strong> セクションを開きます。表示されない場合は、<strong>RDE User</strong> ロールがまだ付与されていません。workspace のオーナーまたはマネージャーにロールの付与を依頼してください。[RDE アクセスの管理](/bitrise-rde/configuration/managing-rde-access)を参照してください。

## 認証 {#authentication}

<strong>Saved inputs</strong> ページで、Claude Code の認証情報とパスワードレスの SSH アクセスを設定できます。<GlossTerm baseform="saved input">Saved inputs</GlossTerm>は、一度保存するだけでセッションにマッピングして再利用できる認証情報や値です。詳細は [Saved inputs](/bitrise-rde/configuration/saved-inputs)を参照してください。

## セッションの作成 {#creating-a-session}

1. Remote Dev Environments セクションで、<strong>New session</strong> をクリックします。
1. セッションのタイトルを設定し、必要に応じて説明も入力します。

   セッションのタイトルは一意である必要があります。
1. 必要に応じて、セッションの起動時に Claude Code を自動的に開始する AI プロンプトを入力します。これには、保存済みの Claude Code 認証情報が必要です。
1. セッションを自動終了するタイミングを選択します。
1. テンプレートを選択するか、<strong>No template</strong> を選択してスタックとマシンタイプを直接指定します。
1. そのテンプレートの [warm pool](/bitrise-rde/configuration/warm-pools)が存在する場合は、<strong>Start from warm pool</strong> を使うと、新しいマシンを起動する代わりに、プールから事前に起動済みのセッションを取得できます。
1. 必須の入力項目を入力します。値を直接入力するか、既存の保存済み入力を選択できます。
1. <strong>Create</strong> をクリックします。

セッションはしばらくすると開始します。実行中になったら、セッションを開いて接続します。

セッションと一緒に iOS シミュレーターまたは Android エミュレーターを起動するには、フォームのデバイスセクションを使用します。このセクションは、選択したスタックまたはテンプレートがデバイスをサポートしている場合に表示されます。[デバイスセッション](/bitrise-rde/devices/device-sessions)を参照してください。

## セッションの管理 {#managing-sessions}

<strong>Sessions</strong> リストには、workspace 内のすべてのセッションがステータスごとにグループ化して表示され、検索もできます。セッションからは、次の操作を行えます。

- 終了したセッションを復元する、または実行中のセッションを終了する。
- 終了したセッションを完全に削除する。
- 名前と説明を編集し、自動終了の設定を変更する。

## セッションへの接続 {#connecting-to-a-session}

セッションの詳細ページは、接続の拠点です。ここから次の操作を行えます。

- 複数タブに対応した<strong>組み込み Web ターミナル</strong>を開く。
- 自分のツールから接続するために、<strong>SSH</strong> と <strong>VNC</strong> の認証情報をコピーする。
- <strong>Open in VS Code</strong> を使用して、VS Code Remote - SSH 拡張機能で接続する。
- <strong>workspace-link buttons</strong> を使用して、IDE で特定のフォルダーを開く。
- セッションがシミュレーターまたはエミュレーターを起動している場合は、<strong>Device</strong> 行の <strong>Open device view</strong> をクリックして、それを確認・操作する。

各方法の詳細は、[セッションへの接続](/bitrise-rde/rde-options/connecting-to-a-session)を参照してください。

## テンプレート {#templates}

再利用可能なセッション構成は、UI から作成・管理できます。[テンプレート](/bitrise-rde/configuration/templates)を参照してください。

## Warm pools

<strong>Warm pools</strong> ページには、セッションを起動済みの状態に保つプール（<strong>My pools</strong>）と、workspace全体で for the プール（<strong>Workspace pools</strong>）が一覧表示されます。<strong>New warm pool</strong> でプールを Create でき、プールのページでは、サイズの変更、構成の編集、セッションの取得、プールの削除を行えます。[Warm pools](/bitrise-rde/configuration/warm-pools)を参照してください。

## Workspace の使用状況 {#workspace-usage}

<strong>Usage</strong> ページには、workspace のアクティブなセッションが現在消費しているリソースが表示されます。セッション数、OS ごとの vCPU とメモリの合計、ユーザーごとの内訳を確認できます。このページは、workspace のオーナーと、請求を管理できるメンバーのみが表示できます。同じレポートはプログラムからも取得できます。[Workspace 使用状況レポート](/bitrise-rde/configuration/rde-api#workspace-usage-report)を参照してください。
