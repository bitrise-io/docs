Bitrise Dev Environments MCP サーバーを使用すると、[Model Context Protocol](https://modelcontextprotocol.io) をサポートする任意のAIエージェント（Claude Code、Claude Desktop、Cursor、VS Code など）が、Remote Dev Environment の<GlossTerm baseform="rde session">セッション</GlossTerm>を作成して操作できます。このサーバーはオープンソースです。

## 接続オプション {#connection-options}

MCP サーバーへの接続方法は2つあります。

- <strong>Hosted</strong>: MCP クライアントを `https://mcp-rde.bitrise.io` に接続し、初回はブラウザーでサインインします。インストールは不要で、推奨のオプションです。
- <strong>Local</strong>: Personal Access Token を使用して、サーバーをバイナリとしてお使いのマシン上で実行します。セッションとお使いのコンピューターの間でのファイルのアップロードやダウンロードなど、すべてのツールを利用できます。

## MCP クライアントへのサーバーの追加 {#adding-the-server-to-your-mcp-client}

お使いのクライアントで、Hosted サーバーを設定します。

<Tabs>
<TabItem value="claude-code" label="Claude Code" default>

```bash
claude mcp add --transport http bitrise-dev-environments https://mcp-rde.bitrise.io
```

`/mcp` を実行し、ブラウザーで認証します。

</TabItem>
<TabItem value="cursor" label="Cursor">

`mcp.json` にサーバーを追加します。

```json
{
  "mcpServers": {
    "bitrise-dev-environments": {
      "url": "https://mcp-rde.bitrise.io"
    }
  }
}
```

</TabItem>
<TabItem value="vs-code" label="VS Code">

MCP の設定にサーバーを追加します。

```json
{
  "servers": {
    "bitrise-dev-environments": {
      "type": "http",
      "url": "https://mcp-rde.bitrise.io"
    }
  }
}
```

</TabItem>
</Tabs>

## エージェントの機能 {#agent-capabilities}

接続すると、次のような操作を自然な言葉でエージェントに依頼できます。

- セッションの作成、一覧表示、復元、終了、削除。
- セッションとともにiOSシミュレーターまたはAndroidエミュレーターを起動し、準備が完了するまで待機して、操作する：ビルドのインストール、UIのタップ操作、スクリーンショットの取得、テストの実行。[デバイスセッション](/bitrise-rde/devices/device-sessions)を参照してください。
- 他のユーザーのブラウザー上のデバイスでアプリのビルドを開く[デバイスプレビューリンク](/bitrise-rde/devices/device-preview-links)の発行。
- [warm pool](/bitrise-rde/configuration/warm-pools)にセッションを待機させておき、すぐにマシンが必要になったときにそこから1つ割り当てる。
- [ライフサイクルフック](/bitrise-rde/configuration/lifecycle-hooks)を持つテンプレートの作成と編集、セッションのセットアップが完了するまでの待機、フックのログの読み取りによる失敗原因の特定、再実行。
- SSHを介した、セッションでのシェルコマンドの実行。
- macOSデスクトップのスクリーンショットの取得と操作。
- SSHまたはVNCリモートアクセスを開く。
- workspaceのアクティブなセッションとリソース使用量の報告（workspaceのオーナーと課金管理者のみ）。
- ファイルのアップロードとダウンロード（ローカルサーバーのみ）。

例：*「macOSのXcodeセッションを起動して、リポジトリをクローンし、ユニットテストを実行して。」*または：*「iPhone 16シミュレーターでセッションを作成し、アプリをビルドして、オンボーディングのフローを確認して。」*

このサーバーは、エージェントが仮想デバイスを操作するために必要なガイドも、MCPリソースおよびツールとして提供します。[AIエージェント向けガイド](/bitrise-rde/devices/device-sessions#guides-for-ai-agents)を参照してください。

## 認証 {#authentication}

* Hosted サーバーはブラウザーベースのサインインを使用するため、管理が必要なトークンはありません。
* Local サーバーは、Bitrise [Personal Access Token](https://app.bitrise.io/me/account/security) を `BITRISE_TOKEN` 環境変数に設定して認証します。複数の <GlossTerm baseform="workspace">workspace</GlossTerm> に所属している場合は、`BITRISE_WORKSPACE_ID` を設定してください。
