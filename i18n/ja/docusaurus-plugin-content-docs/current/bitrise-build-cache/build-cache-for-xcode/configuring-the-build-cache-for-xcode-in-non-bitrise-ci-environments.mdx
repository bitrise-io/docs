Bitrise Build Cache は、Bitrise CI の使用を必須としません。他の CI/CD サービスを使用しながら、キャッシュを活用して Xcode ビルドの時間を短縮できます。

そのためには、ビルド中に Bitrise Build Cache CLI をダウンロードするよう CI 環境を設定し、その後 CLI を実行して Bitrise Build Cache を有効にします。

手動で手順を進める代わりに、AIコーディングエージェントを使ってセットアップすることもできます。[AIで始める](/bitrise-build-cache/getting-started-with-the-build-cache/getting-started-with-ai)を参照してください。

:::tip[GitHub Actions の使用]

GitHub Actions のワークフロー例を掲載した専用ガイドがあります。[GitHub Actions での Build Cache for Xcode の設定](/bitrise-build-cache/build-cache-for-xcode/configuring-the-build-cache-for-xcode-in-github-actions)を参照してください。

[Bitrise Build Hub](/bitrise-build-hub/build-hub-for-github-actions/build-hub-for-github-actions-overview) ランナーでは、トークンはまったく必要ありません。マシンはすでに Bitrise Workspace に接続されているため、CLI が自動的に認証を行います。以下の手順は、それ以外のすべての環境が対象です。

:::

## キャッシュの設定 {#configuring-the-cache}

1. [workspace API トークン](/bitrise-platform/workspaces/workspace-api-token)を作成し、その値をコピーします。

   トークンには、少なくとも <strong>viewer</strong> の workspace ロールを付与してください。これは Build Cache にアクセスできる最も低いロールです。
1. [Workspace ID を確認します](/bitrise-ci/api/identifying-workspaces-and-apps-with-their-slugs): <strong>Workspace settings</strong> ページを開き、左側のナビゲーションメニューで <strong>General settings</strong> を選択します。そこでスラッグを確認してコピーできます。
1. CI の設定で、次の Environment Variables を設定します。

   - `BITRISE_BUILD_CACHE_AUTH_TOKEN`: workspace API のトークン。
   - `BITRISE_BUILD_CACHE_WORKSPACE_ID`: Bitrise workspace のスラッグ。
1. 高速化したいステップの前に、次のスクリプトを CI の設定に追加します。

   :::important[Environment]

   スクリプトは、高速化したい Xcode コマンドと同じ環境で実行してください。

   他のビルドツール (たとえば Gradle) 用のワークフローがすでに設定されている場合は、Xcode をサポートする最新の CLI バージョン (v1.0.0 以降) をインストールしてください。

   Xcode Compilation Cache には Xcode 26 or later バージョンが必要です。

   :::

   ```bash
   #!/usr/bin/env bash
   set -euxo pipefail

   # download Bitrise Build Cache CLI
   curl --retry 5 -sSfL 'https://raw.githubusercontent.com/bitrise-io/bitrise-build-cache-cli/main/install/installer.sh' | sh -s -- -b /tmp/bin -d

   # run the CLI to enable Bitrise build cache for Xcode
   /tmp/bin/bitrise-build-cache activate xcode --cache --cache-push
   ```
