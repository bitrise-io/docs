Bitrise Build Cacheのキャッシュの内容全体は、いつでもクリアできます。Gradleの設定キャッシュを含め、すべてがクリアされます。キャッシュの一部だけを削除することはできません。

キャッシュをクリアすると、出力を再度保存する必要があるため、最初のビルドに通常より時間がかかります。

:::important[Owners only]

キャッシュをクリアできるのは、workspaceのオーナーのみです。

:::

キャッシュをクリアするには：

1. Bitrise Build Cacheを開きます。
1. 左側のサイドバーで <strong>Settings</strong> を選択します。
1. <strong>Cached data</strong> セクションで <strong>Clear cache</strong> をクリックします。

   ![Build Cache SettingsページのClear cacheボタン](/img/_paligo/uuid-9547e14a-19b8-4d74-9d5a-6558fdc1f8ea.png)

1. ダイアログで <strong>Clear cache</strong> をクリックします。
