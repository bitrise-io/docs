Bitrise Build Cacheのキャッシュの内容は、いつでもすべて消去できます。Gradle設定キャッシュを含め、すべてが消去されます。キャッシュの一部だけを削除することはできません。

キャッシュを消去した後の最初のビルドは、出力を再度保存する必要があるため、通常より時間がかかります。

:::important[オーナーのみ]

workspaceのオーナーのみがキャッシュを消去できます。

:::

キャッシュを消去するには、次の手順を実行します。

1. Bitrise Build Cacheを開きます。
1. <strong>Clear cache</strong> をクリックします。
1. ダイアログで <strong>Clear cache</strong> をクリックします。
