[Bitrise Build Cache](https://bitrise.io/platform/devops/build-caching)は、フルマネージドのキャッシュソリューションで、Gradle、Bazel、Xcode、React NativeでビルドされたアプリケーションのCIビルド時間を短縮します。ビルドとテストの出力を専用にキャッシュすることで、以降のビルドで行う作業量を最小限に抑えるため、更新が頻繁な環境でより効率的に動作します。CIツールであれば何でも利用でき、キャッシュインフラストラクチャを自分で管理することなく、ビルドサイクルを高速化できます。

:::tip[無料で試す]

30-day free trialを無料で提供しています。支払い情報の入力も不要です。トライアルは、Bitrise Build Cacheをセットアップすると自動的に開始されます。

[こちらをクリックしてBitrise Build Cacheを使い始めましょう](https://app.bitrise.io/build-cache)。Bitriseのアカウントをお持ちでない場合は、先にアカウントの作成を求められ、その後にBuild Cacheのセットアップに進みます。

:::

## Build Cacheへのnew connectionの追加 {#adding-a-new-connection-to-the-build-cache}

Bitrise Build Cacheを使い始めるには、new connectionを追加する必要があります。手順は次のとおりです。

- CIプロバイダーを選択します。Bitriseまたはその他のCIプロバイダーを使用できます。
- ビルドツールを選択します。現在、Bazel、Gradle、Xcode、React Nativeがサポートされています。
- CIプロバイダーとしてBitriseを使用する場合は、Bitrise projectを選択します。
- 別のCIプロバイダーを使用する場合は、Bitrise Build CacheがCIにアクセスできるように、[personal access token](/bitrise-platform/accounts/personal-access-tokens#creating-a-personal-access-token)を追加します。
- CIプロセスにキャッシュのアクティベーションスクリプトを追加します。Bitriseでは、このための専用の[Steps](/bitrise-ci/workflows-and-pipelines/steps/steps-overview)を用意しています。

new connectionを追加するには、次の手順に従います。

1. Log inからBitriseに移動し、左側のナビゲーションメニューから<strong>Build Cache</strong>を選択します。
1. 右上隅にある<strong>New connection</strong>をクリックします。

   ![cache-new-connection.png](/img/_paligo/uuid-bdbb02c7-b8e7-bf04-fb52-7cacd2231760.png)
1. 画面の指示に従います。
