専用の<GlossTerm baseform="step">Step</GlossTerm>を<GlossTerm baseform="workflow">Workflow</GlossTerm>に追加することで、Bitrise CI上でBitrise [Build Cache for Bazel](https://github.com/bitrise-steplib/bitrise-step-activate-build-cache-for-bazel)を使用できます。StepによりBitrise Build Cacheが有効になります。実行後、Bazel のビルドは自動的にbuild cacheから読み取り、有効にしている場合は新しいエントリーをプッシュします。

手動で手順を進める代わりに、AIコーディングエージェントを使ってセットアップすることもできます。[Getting started with AI](/bitrise-build-cache/getting-started-with-the-build-cache/getting-started-with-ai)を参照してください。

<Tabs>
  <TabItem value="workflow-editor" label="Workflow Editor">

  1. <Partial_OpeningTheWorkflowEditorAndSelectingAWorkflow />
  1. <strong>Bitrise [Build Cache for Bazel](https://github.com/bitrise-steplib/bitrise-step-activate-build-cache-for-bazel)</strong> StepをWorkflowに追加します。

     Stepには設定は必要ありません。

  </TabItem>
  <TabItem value="yaml" label="Configuration YAML">

  1. `bitrise.yml`ファイルを開き、`activate-build-cache-for-bazel` StepをWorkflowに追加します。

     Stepには設定は必要ありません。

     ```yaml
     your-workflow:
       steps:
         - git-clone: {}
         - activate-build-cache-for-bazel:
     ```

  </TabItem>
</Tabs>

最初のビルドでは、出力がキャッシュに保存されます。キャッシュを十分に温めるため、ビルドを何回か実行することをお勧めします。
