Bitrise Build Cache for React Native は、ビルド間でネイティブのコンパイル成果物をキャッシュすることで、CI のビルドを高速化します。React Native プロジェクトで使用される 3 つのネイティブビルドシステムすべてに対応しています。

- <strong>Gradle</strong>: Android のビルド出力（コンパイル済みクラス、リソース、dex ファイル）は、Bitrise のリモート build cache を介してキャッシュされます。
- <strong>Xcode</strong>: iOS のコンパイル結果は、Bitrise のリモート build cache（Gradle や Bazel と同じバックエンド）を介してキャッシュされます。
- <strong>C++ ネイティブモジュール</strong>: コンパイル済みのネイティブブリッジコードとサードパーティ製ネイティブモジュールは `ccache` によってキャッシュされ、キャッシュエントリーは Bitrise のリモート build cache を通じてビルド間で共有されます。

ネイティブのコンパイル出力をキャッシュすることで、以降の CI ビルドでは、変更のないネイティブコードの再コンパイルを省略できます。これは、JS レイヤーに比べてネイティブレイヤーの変更が少ない React Native プロジェクトで特に効果的です。
