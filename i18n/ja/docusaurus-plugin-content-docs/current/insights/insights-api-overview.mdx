Insights APIを使用すると、Bitrise Insightsのデータにプログラムからアクセスでき、独自のツール、ワークフロー、AIエージェントで利用できます。これは公開されている読み取り専用のREST APIで、JSONを返します。

## 用途 {#what-its-for}

チームがすでに作業している場所にInsightsのデータを取り込んだり、独自の自動化やレポートの基盤として活用したりできます。

## 仕組み {#how-it-works}

リクエストはプロジェクト単位で処理され、Insightsでデータを確認する際と同じように、結果を絞り込んだりグループ化したりできます。エンドポイント、パラメーター、制限については、[APIリファレンス](/insights-api/api-reference/bitrise-insights-api)を参照してください。

## はじめに {#get-started}

有料のInsightsプランと、`Authorization`ヘッダーで送信するBitrise APIトークンが必要です。トークンには次のいずれかを使用できます。

* [パーソナルアクセストークン](/bitrise-platform/accounts/personal-access-tokens)
* [workspace APIトークン](/bitrise-platform/workspaces/workspace-api-token)

## 接続方法 {#ways-to-connect}

| オプション | 利用する場合 | 参照先 |
| --- | --- | --- |
| Insights API | 独自の連携を構築したい場合。 | [APIリファレンス](/insights-api/api-reference/bitrise-insights-api) |
| Bitrise MCP | AIエージェントでInsightsのデータを利用したい場合。 | [MCP Insightsツール](/bitrise-platform/ai/bitrise-mcp/tools#insights) |
