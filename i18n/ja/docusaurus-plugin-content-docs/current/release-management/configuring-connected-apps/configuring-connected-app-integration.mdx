Release Management のコネクテッドアプリは、Google Play に接続するために [Google Play Console service account](/bitrise-platform/integrations/connecting-a-google-service-account-to-bitrise) を使用し、App Store に接続するために [App Store Connect account](/bitrise-platform/integrations/apple-services-connection/connecting-to-an-apple-service-with-api-key) を使用します。[アプリを初めて接続する](/release-management/getting-started-with-release-management/connecting-an-app)ときに、ストア接続を設定する必要があります。これらの設定はいつでも変更できます。

<GlossTerm baseform="workspace">workspace</GlossTerm> には、複数のサービスアカウントまたは API キーを追加できます。Release Management の各プロジェクトおよび各コネクテッドアプリは、それぞれ異なるサービスアカウントまたは API キーを使用できます。

Release Management のアプリは、次のいずれかを使用できます。

- プロジェクトのストア接続
- アプリ固有のストア接続

たとえば、Workspace に複数の App Store Connect API keys が設定されている場合、そのうちの 1 つをプロジェクトの API キーとして設定し、Release Management のコネクテッドアプリには別のキーを使用できます。

## プロジェクトレベルのストア接続を使用する {#using-a-project-level-store-connection}

:::important[接続の変更]

プロジェクトレベルのストア接続を使用している場合、プロジェクトのサービスアカウントまたは API キーを変更すると、コネクテッドアプリの接続も変更されます。これによりリリースが失敗する可能性があります。

:::

<Tabs>
<TabItem value="ios" label="iOS" default>

1. [プロジェクトの API キーを設定します](/bitrise-platform/integrations/apple-services-connection/connecting-to-an-apple-service-with-api-key)。
1. Release Management のホームページで、<strong>Your apps</strong> リストから your app を選択します。

   ![2025-08-07-rm-your-apps-list.png](/img/_paligo/uuid-c446a6a9-f922-2641-53ad-49099a7921fe.png)
1. 左側で <strong>Integrations</strong> を選択します。
1. <strong>Store</strong> タブで <strong>API key</strong> カードを見つけ、<strong>Replace</strong> をクリックします。
1. ダイアログで <strong>Use project's API key</strong> を選択します。
1. <strong>Save changes</strong> をクリックします。

</TabItem>
<TabItem value="android" label="Android">

1. [プロジェクトのサービスアカウントを設定します](/bitrise-platform/integrations/connecting-a-google-service-account-to-bitrise)。
1. Release Management のホームページで、<strong>Your apps</strong> リストから your app を選択します。

   ![2025-08-07-rm-your-apps-list.png](/img/_paligo/uuid-c446a6a9-f922-2641-53ad-49099a7921fe.png)
1. 左側で <strong>Integrations</strong> を選択します。
1. <strong>Store</strong> タブで <strong>Service account</strong> カードを見つけ、<strong>Replace</strong> をクリックします。
1. ダイアログで <strong>Use project's service account</strong> を選択します。
1. <strong>Save changes</strong> をクリックします。

</TabItem>
</Tabs>

## アプリレベルのストア接続を使用する {#using-an-app-level-store-connection}

アプリレベルのストア接続では、特定のコネクテッドアプリに対して、サービスアカウントまたは API キーを個別に設定します。アプリレベルの接続は、プロジェクトに設定された接続とは異なるものにできます。

<Tabs>
<TabItem value="ios" label="iOS" default>

1. [プロジェクトの API キーを設定します](/bitrise-platform/integrations/apple-services-connection/connecting-to-an-apple-service-with-api-key)。
1. Release Management のホームページで、<strong>Your apps</strong> リストから your app を選択します。

   ![2025-08-07-rm-your-apps-list.png](/img/_paligo/uuid-c446a6a9-f922-2641-53ad-49099a7921fe.png)
1. 左側で <strong>Integrations</strong> を選択します。
1. <strong>Store</strong> タブで <strong>API key</strong> カードを見つけ、<strong>Replace</strong> をクリックします。
1. ダイアログで <strong>Set app-level API key</strong> を選択します。
1. <strong>API key</strong> ドロップダウンメニューから Select an API key を選択します。
1. <strong>Save changes</strong> をクリックします。

</TabItem>
<TabItem value="android" label="Android">

1. [プロジェクトのサービスアカウントを設定します](/bitrise-platform/integrations/connecting-a-google-service-account-to-bitrise)。
1. Release Management のホームページで、<strong>Your apps</strong> リストから your app を選択します。

   ![2025-08-07-rm-your-apps-list.png](/img/_paligo/uuid-c446a6a9-f922-2641-53ad-49099a7921fe.png)
1. 左側で <strong>Integrations</strong> を選択します。
1. <strong>Store</strong> タブで <strong>Service account</strong> カードを見つけ、<strong>Set service account</strong> をクリックします。
1. ダイアログで <strong>Set app-level service account</strong> を選択します。
1. <strong>Service account</strong> ドロップダウンメニューから service account を選択します。
1. <strong>Save changes</strong> をクリックします。

</TabItem>
</Tabs>
