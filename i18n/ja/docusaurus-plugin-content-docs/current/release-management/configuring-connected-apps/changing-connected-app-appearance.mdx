Release Managementのすべてのアプリには、タイトルとアプリアイコンがあります。タイトルの編集や、独自のカスタムアイコンの使用が可能です。

:::important[Appアイコンの要件]

アプリアイコンでサポートされている形式はJPEGとPNGです。背景を透過にすることはできません。最大ファイルサイズは1 MBです。

:::

1. <Partial_OpeningAnAppInReleaseManagement />
1. 左側で<strong>App settings</strong>を選択します。なお、アプリケーションの<strong>App settings</strong>メニューにアクセスできるのは、<strong>Project Admin</strong>と<strong><GlossTerm baseform="workspace">Workspace</GlossTerm>オーナー</strong>のみです。
1. <strong>Appearance</strong>セクションでは、次の操作を行えます。

   - <strong>Edit title</strong>をクリックしてタイトルを変更します。ダイアログで新しいタイトルを設定し、<strong>Save</strong>をクリックします。

     ![2025-08-08-rm-add-new-app-title.png](/img/_paligo/uuid-a8e8da8b-6759-e159-5aa4-6a97f83896dc.png)
   - <strong>Change icon</strong>をクリックしてアプリアイコンを変更します。ダイアログで新しいアイコンをドラッグ&ドロップします。背景が透過していないJPEGまたはPNGで、サイズは1 MB以下である必要があります。

     ![2025-08-08-rm-change-app-icon.png](/img/_paligo/uuid-80fbbf58-d67b-34af-96aa-4b5124ef844e.png)

:::note[アプリアイコンとAPIについて]

お好みで、[API](https://api.bitrise.io/release-management/api-docs/index.html#/Connected%20Apps%20-%20Public%20Assets/GeneratePublicAssetUploadUrl)を使用してアプリアイコンを変更することもできます。

:::
