Release Management のすべてのアプリにはタイトルとアプリアイコンがあります。タイトルを編集したり、独自のカスタムアイコンを使用したりできます。

:::important[App アイコンの要件]

アプリアイコンでサポートされている形式は JPEG と PNG です。背景は透過でない必要があります。最大ファイルサイズは 1 MB です。

:::

1. <Partial_OpeningAnAppInReleaseManagement />
1. 左側で <strong>Basic settings</strong> を選択します。アプリの <strong>Basic settings</strong> メニューにアクセスできるのは、<strong>Project Admin</strong> と <strong><GlossTerm baseform="workspace">Workspace</GlossTerm> Owners</strong> のみです。
1. <strong>Appearance</strong> セクションでは、次の操作を行えます。

   - <strong>Edit title</strong> をクリックしてタイトルを変更します。ダイアログで新しいタイトルを設定し、<strong>Save</strong> をクリックします。
   - <strong>Change icon</strong> をクリックしてアプリアイコンを変更します。ダイアログで新しいアイコンをドラッグアンドドロップします。背景が透過でない JPEG または PNG で、1 MB 以下である必要があります。

:::note[アプリアイコンと API]

必要に応じて、[API](https://api.bitrise.io/release-management/api-docs/index.html#/Connected%20Apps%20-%20Public%20Assets/GeneratePublicAssetUploadUrl) を使用してアプリアイコンを変更することもできます。

:::
