:::warning[削除したリリースは元に戻せません]

リリースの削除は元に戻せません。削除すると、Release Management内にあるそのリリースのすべてのデータが失われます。

TestFlight、App Store Connect、またはGoogle Play内のデータは失われず、App StoreやGoogle Play Storeで進行中の処理にも影響はありません。App Storeの審査がキャンセルされることはありません。App Storeの段階的リリースは自動的に完了します。Google Playの段階的ロールアウトは停止しますが、Google Playで手動により処理を完了できます。

:::

リリースを削除するには、次の手順に従います。

1. <Partial_GettingToReleaseConfiguration />
1. <strong>Delete release</strong> セクションまでスクロールし、<strong>Remove リリース</strong> をクリックします。
1. ダイアログで <strong>Remove</strong> をクリックして確定します。
