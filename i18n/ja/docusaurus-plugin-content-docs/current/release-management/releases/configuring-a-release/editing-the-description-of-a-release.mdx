新しいリリースを追加する際に、リリースの説明を入力できます。これにより、後でリリースを識別しやすくなります。この説明は、リリース設定でいつでも変更できます。

:::tip[リリースの説明は内部限定です]

リリースの説明は内部限定であり、申請には含まれません。

:::

1. <Partial_GettingToReleaseConfiguration />
1. リリース情報カードで、<strong>Edit</strong>をクリックします。

   ![2025-08-08-rm-editing-release-description.png](/img/_paligo/uuid-54d3257f-0147-d101-0dde-c0296dcb798a.png)
1. <strong>Edit リリース詳細</strong>ダイアログで、説明を更新して<strong>Save</strong>をクリックします。
