アプリがこれまでのすべてのステージを通過すると、リリースの準備が整います。アプリを全ユーザーに同時にリリースすることも、Apple Store向けにフェーズドリリースを設定することもできます。

## Apple Storeのフェーズドリリースを設定する

アプリをApple Storeに段階的にリリースできます。フェーズドリリースでは、アプリを複数の異なるステージでリリースし、各ステージで新しいバージョンを受け取るユーザーは一定の割合のみになります。ユーザーは自分が段階的リリースの対象になっていることを通知されません。このプロセスを自動化することで、各ステージで異なるユーザーセグメントに手動でアプリをリリースする必要がなくなります。Release Managementが自動的にその処理を行います。

:::note[用語]

Googleはこの機能を段階的ロールアウトと呼び、Appleではフェーズドリリースと呼びます。

:::

### Apple Storeでフェーズドリリースを有効にする

このオプションを選択すると、バージョンの更新は7日間かけて、自動更新をオンにしているユーザーのうち一定の割合（Apple IDによりランダムに選択されます）に対してリリースされます。ユーザーは自分のアプリが段階的リリースの対象になっていることを通知されません。

フェーズドリリースは、App Store審査ステージの前、またはApp Store審査が完了した後のリリースステージ中に有効にできます。

<Tabs>
<TabItem value="before-app-store-review" label="Before App Store review" default>

1. <strong>App Store review</strong>ステージで<strong>App Store release settings</strong>を見つけます。
1. <strong>Phased release for automatic updates</strong>カードの右側にある<strong>Change</strong>をクリックします。
1. <strong>Release update over 7-day period using phased release</strong>オプションを選択します。

   ![phased-release-7-day.png](/img/_paligo/uuid-05ba3ed0-0f1c-c4be-e46f-cc500b21041c.png)
1. <strong>Save changes</strong>をクリックします。

</TabItem>
<TabItem value="after-app-store-review" label="After App Store review">

1. <strong>App Store review</strong>ステージまたは<strong>Release</strong>ステージで<strong>Version release</strong>カードを見つけて<strong>Change</strong>をクリックします。
1. ダイアログで、次の3つのオプションのいずれかを選択します。

   - <strong>Manually release this version</strong>
   - <strong>Automatically release this version</strong>
   - <strong>Automatically release this version after App Review, no earlier than</strong>して日付を設定します。

   ![release-version.png](/img/_paligo/uuid-4f7e400b-3a64-eb42-5b85-c51a3f41da03.png)
1. <strong>Release</strong>ステージで<strong>Phased release for automatic updates</strong>カードを見つけて<strong>Change</strong>をクリックします。
1. <strong>Release update over 7-day period using phased release</strong>オプションを選択します。

</TabItem>
</Tabs>

### フェーズドリリースを一時停止する

アプリがフェーズドリリース中の間、リリースを合計30日間一時停止できます。一時停止の回数に制限はありません。

1. <strong>Release</strong>ステージで<strong>Pause</strong>ボタンをクリックします。
1. フェーズドリリースを再開するには、<strong>Continue</strong>ボタンをクリックします。

## アプリをリリースする

すべての設定が完了すると、アプリをリリースできます。設定によっては、アプリを全ユーザーに同時にリリースすることも、段階的ロールアウトを行うこともできます。

1. リリースを開きます。
1. 左側のナビゲーションバーで<strong>Release</strong>を選択します。
1. <strong>Release version</strong>をクリックします。設定に応じて、アプリが全ユーザーにリリースされるか、フェーズドリリースが開始されます。設定は<strong>App Store release settings</strong>セクションで変更できます。

   ![app-store-release.png](/img/_paligo/uuid-fafa8157-e6f0-6495-1da6-7112515830d8.png)

:::note[自動リリースの日付を変更する]

iOSアプリの場合、App Store審査ステージで<strong>Automatically release this version after App Review, no earlier than</strong>を選択していれば、<strong>Release</strong>ページで日付を変更できます。

:::
