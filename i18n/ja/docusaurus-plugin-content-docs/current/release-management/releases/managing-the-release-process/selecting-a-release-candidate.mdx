release candidate stageでは、release process中に使用するインストール可能なアーティファクトを選択します。インストール可能なアーティファクトのソースには、次の2つがあります。

- Bitrise CIビルド:このソースを使用する場合は、ブランチとWorkflowを選択し、それらを使用したビルドで生成されたアーティファクトを選択します。デフォルトでは最新ビルドのアーティファクトが使用されますが、変更できます。
- [API経由でインストール可能なアーティファクトをアップロードする](/bitrise-ci/api/managing-build-artifacts)。Bitriseの代わりに別のCIサービスを使用している場合に特に便利です。

:::important[署名済みアーティファクトのみ]

インストール可能なアーティファクトは、署名済みアーティファクト(IPAまたはAAB)である必要があります。code signingガイドをご確認ください。

- [iOS code signing](/bitrise-ci/code-signing/ios-code-signing/creating-a-signed-ipa-for-xcode-projects)
- [Android code signing](/bitrise-ci/code-signing/android-code-signing/android-code-signing-using-the-android-sign-step)

:::

リリース候補を選択するには、次の手順を行います。

1. リリースを開きます。
1. 左側のナビゲーションバーで<strong>Release candidate</strong>を選択します。
1. ビルドアーティファクトのソースを設定します。<strong>Configure</strong>をクリックします。

   これにより、<strong>Build artifact source</strong>ダイアログが開きます。

   ![build-artifact-source.png](/img/_paligo/uuid-ca5383f8-2b6e-a07a-1876-35ad58894b5f.png)
1. 次の2つのオプションのいずれかを選択します。

   - <strong>Use Bitrise CI builds</strong>: ブランチとWorkflowを選択して、Bitrise CIビルドで生成されたアーティファクトを使用します。
   - <strong>Upload via API</strong>: このソースからアーティファクトを選択できるようにするには、[APIを使用してアップロード](/bitrise-ci/api/managing-build-artifacts)してください。
1. 生成された最新のアーティファクト、またはAPI経由でアップロードされた最新のファイルを使用するには、<strong>最新の成功したビルドを自動的に選択する</strong>チェックボックス(APIソースを使用している場合は<strong>Automatically select after successful upload</strong>というラベル)をオンにします。

   いずれの場合も、アーティファクトは署名済みアーティファクトである必要があります。
1. <strong>Save changes</strong>をクリックします。
1. 自動選択をオンにしなかった場合は、<strong>Build artifact</strong>セクションに移動し、<strong>Select artifact</strong>をクリックします。署名済みアーティファクトからのみ選択できます。

   ![select-artifact.png](/img/_paligo/uuid-9502548e-c9ec-985e-7224-7e06aa0dfbda.png)
1. ダイアログでビルドアーティファクトを選択し、<strong>Select artifact</strong>をクリックします。

リリース候補を選択すると、<strong>Build artifact</strong>の下に使用されるアーティファクトの詳細が表示されます。

![locked-artifact.png](/img/_paligo/uuid-4d8bea06-abe3-0ad5-9a37-d840ad2c0875.png)

次に進むことができます。

- iOSアプリの場合は[TestFlightアップロードステージ](/release-management/releases/managing-the-release-process/testflight-upload-stage)。
- Androidアプリの場合は[Google Playアップロードステージ](/release-management/releases/managing-the-release-process/google-play-upload-stage#uploading-the-release-candidate-to-google-play)。
