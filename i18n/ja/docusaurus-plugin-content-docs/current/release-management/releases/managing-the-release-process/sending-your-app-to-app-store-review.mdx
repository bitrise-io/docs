:::important[ロール要件]

アプリを App Store の審査に送信するには、連携済みアプリに対して Release Manager ロールを持っている必要があります。

:::

リリース候補を TestFlight にアップロードし、ビルドの処理が完了したら、App Store の審査に送信できます。審査では Apple がリリースをレビューします。

1. リリースを開きます。
1. 左側のナビゲーションバーで <strong>App Store review</strong> を選択します。
1. <strong>App Store release settings</strong> セクションを確認します。

   ![app-store-review.png](/img/_paligo/uuid-0356f699-7e6f-0169-7fb3-82576e470b62.png)
1. <strong>Phased release for automatic updates</strong> の <strong>Change</strong> をクリックして、段階的リリースを設定します。

   段階的リリースを選択すると、最初は一部のユーザーのみがリリース内容にアクセスできます。7日間かけて、徐々にすべてのユーザーがアクセスできるようになります。
1. <strong>Version release</strong> の <strong>Change</strong> をクリックして version release を設定します。次のいずれかを選択できます。

   - アプリを手動でリリースする。
   - アプリを自動でリリースする: Apple の審査が完了次第、アプリがリリースされます。
   - App Store の審査後、指定した日付以降に自動でアプリをリリースする。
1. <strong>App Store metadata</strong> セクションでメタデータを確認します。
1. 完了したら、ページ右上にある <strong>Submit version</strong> をクリックします。

   :::tip[App Store 審査のキャンセル]

   App Store の審査中にリリースを変更したい場合は、まず審査からリリースを削除する必要があります。<strong>To modify this release, remove it from review first</strong> という注記にある <strong>Remove from review</strong> をクリックし、ダイアログで確定します。

   :::

<strong>Release</strong> ページで release status を確認できます。

手動でのリリースについては、[Releasing your app on the App Store](/release-management/releases/managing-the-release-process/releasing-your-app-on-the-app-store) を参照してください。

## iOS アプリのリリースノートを編集する {#editing-the-release-note-of-an-ios-app}

[release presetsに既に設定されている](/release-management/releases/configuring-a-release/release-automation)内容とは異なるリリースノートでアプリをリリースしたい場合は、新しいアプリバージョンをロールアウトする前に手動でノートを編集できます。この変更は <strong>Release presets</strong> のデフォルト設定を上書きするものではなく、現在のリリースにのみ影響します。

:::note[Release Manager のみ]

リリースノートを編集できるのは [Release Managers](https://devcenter.bitrise.io/en/release-management/getting-started-with-release-management/release-management-concepts.html) のみである点にご注意ください。

:::

release process 中に iOS アプリのリリースノートを変更するには:

1. <strong>Release candidate</strong>、<strong>TestFlight</strong>、<strong>Approvals</strong> の各段階を進め、左側の <strong>App store review</strong> をクリックします。
1. <strong>App Store Metadata</strong> までスクロールします。
1. <strong>What's new in this version</strong> をクリックし、次に <strong>Edit metadata</strong> をクリックします。ここでリリースノートを変更できます。変更は <strong>Language</strong> に表示されている、選択したローカライズにのみ適用されます。
1. 必要に応じて、<strong>Use same content for all localizations</strong> にチェックを入れることで、新しい内容をすべてのローカライズにコピーできます。
1. <strong>Copy to</strong> をクリックし、任意のローカライズを選択することで、新しい内容を他のローカライズにもコピーできます。
