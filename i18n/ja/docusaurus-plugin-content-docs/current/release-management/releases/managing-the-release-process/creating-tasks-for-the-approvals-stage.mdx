<strong>Approvals</strong> ステージでは、App Store ConnectまたはGoogle Playへのリリースを続行するために承認が必要な、各ステークホルダーやチームメンバーのタスクを作成できます。

必要に応じて、承認タスクをチームメンバーに割り当てることができます。割り当てられたチームメンバーのみがそのタスクを承認できます。

1. リリースを開きます。
1. 左側のナビゲーションバーで<strong>Approvals</strong>を選択します。
1. <strong>Newタスク</strong>ボタンをクリックします。
1. 必要な項目を入力します。

   ![add_approval_task.png](/img/_paligo/uuid-97e3fccd-f3f6-fdc8-5f55-75f85a525e95.png)

   - <strong>Title</strong>: タスクを識別します。これは必須です。
   - <strong>Description</strong>: タスクの簡単な概要です。これは任意です。
   - <strong>Assign to</strong>: タスクを割り当てるチームメンバーを選択します。そのチームメンバーのみがタスクを承認できます。これは任意です。チームの誰でもタスクを承認できるようにする場合は、<strong>(not assigned)</strong>のままにしてください。
   - <strong>Due date</strong>: タスクの承認期限日を選択します。これは任意です。

タスクはいくつでも作成できます。

承認ステージでタスクを完了したら、タスクの横にあるチェックボックスを使ってチェックを入れることができます。すべてのタスクにチェックが入ると、左側のナビゲーションバーの<strong>Approvals</strong>にも自動的にチェックが入ります。

完了したら、次に進むことができます。

- iOSアプリでは、[App Store Reviewステージ](/release-management/releases/managing-the-release-process/sending-your-app-to-app-store-review)に進みます。
- Androidアプリでは、[Google Playでのアプリのリリース](/release-management/releases/managing-the-release-process/releasing-your-app-on-google-play)に進みます。

## REST APIを使用してチームメンバーに承認タスクを割り当てる

[Release Management API](/release-management/release-management-api)を使用して、承認タスクをチームメンバーに割り当てることができます。APIエンドポイントの詳細については、[APIドキュメント](https://api-docs.bitrise.io/)をご覧ください。

:::note[限定アクセス]

[APIコールを認証する](/bitrise-ci/api/authenticating-with-the-bitrise-api)には、パーソナルアクセストークンまたはWorkspaceトークンが必要になりますのでご注意ください。

承認タスクをチームメンバーに割り当てる権限があるのは、[Workspaceオーナー、プロジェクト管理者、リリースマネージャー](/release-management/configuring-connected-apps/release-management-roles-and-permissions)のみです。

:::

user slug、期限日、概要、説明を指定して、`POST /releases/{release_id}/approvals`エンドポイントで承認タスクを作成できます。

承認タスクは`PATCH /releases/{release_id}/approvals/{task_id}`エンドポイントで更新できます。
