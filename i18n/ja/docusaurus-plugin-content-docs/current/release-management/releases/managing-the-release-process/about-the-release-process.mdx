接続済みのアプリに新しいリリースを追加し、正常に設定できたら、release processの各リリースステージに進むことができます。次のステージに進めるのは現在のステージを完了した後のみですが、前のステージにはいつでも戻ることができます。

前のステージに変更を加えた場合は、そのステージから作業をやり直す必要があります。

<Tabs>
<TabItem value="ios" label="iOS" default>

1. [リリース候補](/release-management/releases/managing-the-release-process/selecting-a-release-candidate): <strong>Release candidate</strong> ステージでは、release branch を指定し、IPA ファイルを生成する Workflow を選択します。

   :::note[Release Managementからの環境変数]

Release Managementは、[リリース自動化](/release-management/releases/configuring-a-release/release-automation): [利用可能なenvironment variables](/bitrise-ci/references/available-environment-variables)によってトリガーされるパイプラインやワークフローに、特定のEnvironment Variablesを渡します。

   :::
1. [TestFlight](/release-management/releases/managing-the-release-process/testflight-upload-stage#uploading-the-release-candidate-to-testflight): リリース候補を TestFlight にアップロードし、テスト用に配布します。
1. [承認](/release-management/releases/managing-the-release-process/creating-tasks-for-the-approvals-stage): App Store へのリリースを続行するために承認が必要な関係者やチームメンバーに対して、タスクを作成できます。
1. [App Store 審査](/release-management/releases/managing-the-release-process/sending-your-app-to-app-store-review): アップデートを App Store の審査に提出し、承認状況の情報を確認できます。
1. [リリース](/release-management/releases/managing-the-release-process/releasing-your-app-on-the-app-store): アプリをすべてのユーザーに同時にリリースすることも、段階的リリースを設定することもできます。

</TabItem>
<TabItem value="android" label="Android">

1. [リリース候補](/release-management/releases/managing-the-release-process/selecting-a-release-candidate): <strong>Release candidate</strong> ステージでは、release branch を指定し、AAB ファイルを生成する Workflow を選択します。
1. [Google Playのアップロードとテスト](/release-management/releases/managing-the-release-process/google-play-upload-stage#uploading-the-release-candidate-to-google-play): リリース候補を Google Play にアップロードし、テスト用に配布します。
1. [承認](/release-management/releases/managing-the-release-process/creating-tasks-for-the-approvals-stage): Google Play へのリリースを続行するために承認が必要な関係者やチームメンバーに対して、タスクを作成できます。
1. [リリース](/release-management/releases/managing-the-release-process/releasing-your-app-on-the-app-store): アプリをすべてのユーザーに同時にリリースすることも、段階的ロールアウトを設定することもできます。

</TabItem>
</Tabs>
