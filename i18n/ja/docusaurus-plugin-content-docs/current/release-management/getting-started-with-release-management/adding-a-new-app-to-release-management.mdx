Release Managementの利用を開始するには、少なくとも1つのアプリを追加する必要があります。ストア接続やコードリポジトリは必要ありません。アプリを[Bitrise project](/bitrise-platform/projects/projects-overview)にリンクする必要があります。既存のBitrise projectがない場合は、自動的に1つ作成されます。

アプリを追加するには:

1. Log inしてBitriseにアクセスし、左側のナビゲーションメニューから<strong>Releases</strong>を選択します。
1. 初めてのアプリの場合は、<strong>Get started with Release Management</strong>ページが表示されます。アプリの追加から始めます。

   初めてのアプリでない場合は、アプリ一覧の上にある<strong>New app</strong>ボタンを探します。
1. アプリのプロジェクトを設定します。

   - アプリを既存のBitrise projectにリンクするには、<strong>Existing project</strong>オプションを選択し、ドロップダウンメニューからプロジェクトを選びます。
   - 新しいプロジェクトを自動的に作成するには、<strong>New project</strong>オプションを選択します。このプロジェクトはRelease Managementプロジェクトになりますが、いつでもCIの設定を追加できます。

   ![add-new-app-newproj.png](/img/_paligo/uuid-8821de29-e79d-0932-c3dd-f5deea8eba32.png)
1. 次のページで、以下を指定します:

   - アプリのタイトル。
   - mobile OS。
   - mobile OSに応じた、package nameまたはバンドルID。

   これらはこの時点では検証されません。オンラインストアにすでに存在するpackage nameまたはバンドルIDを使用することをおすすめしますが、後でいつでも変更できます。

   ![adding-app.png](/img/_paligo/uuid-9073242e-afd9-262e-25cf-395ab1881ea6.png)
1. <strong>Add app</strong>をクリックします。

アプリを追加すると、インストール可能なアーティファクトのアップロードを開始し、ビルド配布機能を使用できるようになります: [テスターへのビルドの配布](/release-management/build-distribution/distributing-builds-to-testers)。

リリースを管理するには、アプリをアプリストアに接続する必要があります: [アプリの接続](/release-management/getting-started-with-release-management/connecting-an-app)。
