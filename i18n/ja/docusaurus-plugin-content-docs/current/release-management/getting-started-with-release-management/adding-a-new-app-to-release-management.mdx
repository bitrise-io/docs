Release Management を使い始めるには、少なくとも 1 つのアプリを追加する必要があります。ストア接続やコードリポジトリは不要です。アプリを [Bitrise project](/bitrise-platform/projects/projects-overview)にリンクする必要があります。既存の Bitrise project がない場合は、自動的に作成されます。

アプリを追加するには、次の手順を実行します。

1. Log in から Bitrise に移動し、左側のナビゲーションメニューで <strong>Releases</strong> を選択します。
1. 最初のアプリの場合は、<strong>Get started with Release Management</strong> ページが表示され、<strong>Distribute builds for testing</strong>、<strong>Release mobile app to stores</strong>、<strong>Deploy CodePush updates</strong> の 3 つのオプションがあります。以下の手順は <strong>Distribute builds for testing</strong> の流れを説明しています。

   最初のアプリでない場合は、アプリ一覧の上にある <strong>New app</strong> ボタンを探してください。
1. アプリのプロジェクトを設定します。

   - 既存の Bitrise project にアプリをリンクするには、<strong>Existing project</strong> オプションを選択し、ドロップダウンメニューからプロジェクトを選びます。
   - 新しいプロジェクトを自動的に作成するには、<strong>New project</strong> オプションを選択します。このプロジェクトは Release Management プロジェクトになりますが、いつでも CI の設定を追加できます。
1. 次のページで、以下を指定します。

   - アプリのタイトル。
   - mobile OS。
   - package name またはバンドル ID (mobile OS によって異なります)。

   この時点では、package name またはバンドル ID の形式が有効かどうかだけがチェックされ、実際のストア掲載情報とは照合されません。package name またはバンドル ID には、オンラインストアに既に存在するものを使用することをお勧めしますが、後から変更することもできます。
1. <strong>Add app</strong> をクリックします。

アプリを追加したら、インストール可能なアーティファクトのアップロードを開始し、ビルド配布機能を利用できます。[Distributing builds to testers](/release-management/build-distribution/distributing-builds-to-testers)を参照してください。

リリースを管理するには、アプリをアプリストアに接続する必要があります。[Connecting an app](/release-management/getting-started-with-release-management/connecting-an-app)を参照してください。
