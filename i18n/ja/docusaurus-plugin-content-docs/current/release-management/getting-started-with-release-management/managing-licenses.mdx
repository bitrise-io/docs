Release Managementは、無料プランの基本機能に加えて、追加の機能を提供します。特定の接続済みアプリで Standard プランの機能を有効にするには、Standard ライセンスを購入し、そのアプリに割り当てる必要があります。

## ライセンスとcurrent apps {#licenses-and-current-apps}

ライセンスは、Release Managementの概要ページで、アプリ一覧の横にある <strong>Workspace</strong> ウィジェットから管理できます。ウィジェットには次の数値が表示されます。

- <strong>Standard apps</strong>: Standard ライセンスが割り当てられているアプリの数と、プランで利用可能な合計数。
- <strong>Basic apps</strong>: Basic (無料) プランのアプリの数。

## connected appsへのライセンスの割り当て {#assigning-licenses-to-connected-apps}

アプリを接続した後は Basic ライセンスで開始でき、いつでもアップグレードして Standard ライセンスの追加特典を利用できます。ライセンスは接続済みアプリに割り当てた後は譲渡できず、ライセンス期間(請求サイクル)中はそのアプリに紐づいたままになります。

connected appsにライセンスを割り当てるには、次の手順を実行します。

1. Release Managementを開きます。
1. <strong>Connected apps</strong> リストの横にある <strong>Workspace</strong> ウィジェットを見つけ、<strong>Manage licenses</strong> をクリックします。
1. 接続済みアプリごとにライセンスを選択します。<strong>Change</strong> 列には、アプリに割り当てられたライセンスが変更される場合に、その内容と変更が反映される時期が表示されます。
1. サマリーで、現在の期間と次の期間に割り当てられているライセンスの合計数を確認します。
1. <strong>Confirm changes</strong> をクリックします。

## プランの上限の超過 {#exceeding-your-plan-limit}

割り当てたライセンス数がプランの上限を超えると、通知が表示されます。[割り当てたライセンスを変更する](#assigning-licenses-to-connected-apps)ために戻るか、プランを変更して、選択した構成で続行できます。

問題を解決するには、次の手順を実行します。

1. 通知内のリンクをクリックして、プランを変更します。新しいブラウザータブで <strong>Change plan for Release Management</strong> ページが開きます。
1. <strong>Apps in plan</strong> の数(connected appsに割り当てることができるライセンス)を増減します。

   <strong>Current apps</strong> の数が新しい <strong>Apps in plan</strong> の上限を超える場合は通知が表示されますが、continue to checkout。新しいリリースでもすべての機能を引き続き使用できるように、変更が反映される前にライセンスを管理してください。

   :::caution

   <strong>Current apps</strong> が Standard ライセンスの <strong>Apps in plan</strong> の数を超えると、Workspace内のどのconnected appsでも Standard ライセンスの追加特典を利用できなくなります。

   :::
