Release Management に新しいアプリを追加したら、リリースを作成できるように、App Store または Google Play のアプリに接続します。

- iOS の場合は、App Store Connect に有効な bundle ID を持つアプリが必要です。
- Android の場合は、Google Play に有効な package name を持つアプリが必要です。

<Tabs>
<TabItem value="ios" label="iOS" default>

1. iOS アプリが App Store に登録されていることを確認します。

   接続の途中で、アプリの bundle ID を入力する必要があります。
1. Bitrise CI プロジェクトがあることを確認します。

   アプリを Release Management に追加するときにプロジェクトを作成した場合は、CI の設定を追加してプロジェクトを拡張できます。[新しいプロジェクトの追加](/bitrise-ci/getting-started/adding-a-new-project)を参照してください。
1. workspace に、少なくとも 1 つの App Store Connect API キーが追加されていることを確認します。[API キーを使用した Apple サービスへの接続](/bitrise-platform/integrations/apple-services-connection/connecting-to-an-apple-service-with-api-key)を参照してください。
1. Release Management でアプリを開き、左側のナビゲーションで <strong>Releases</strong> を選択します。
1. <strong>Connect app</strong> をクリックします。
1. App Store Connect API キーを設定します。ダイアログには 2 つのオプションがあります。

   <strong>Use project's API key</strong>: プロジェクトレベルで設定された API キーを使用して App Store に接続します。プロジェクトの API キーを変更すると、Release Management アプリの API キーも変更されます。

   <strong>Set app-level API key</strong>: workspace に追加されている任意の API キーを、<strong>API key</strong> ドロップダウンメニューから選択できます。このオプションでは、プロジェクトレベルでどの API キーが設定されていても影響しません。
1. bundle ID を入力し、<strong>Validate</strong> をクリックします。

   bundle ID は、App Store に存在するアプリの bundle ID と完全に一致している必要があります。検証に成功すると、<strong>Connect</strong> ボタンが有効になります。
1. <strong>Connect</strong> をクリックします。

</TabItem>
<TabItem value="android" label="Android">

1. Android アプリが Google Play に登録されていることを確認します。
1. workspace に、少なくとも 1 つの Google サービスアカウントが追加されていることを確認します。[Google サービスアカウントの Bitrise への接続](/bitrise-platform/integrations/connecting-a-google-service-account-to-bitrise)を参照してください。
1. Bitrise CI プロジェクトがあることを確認します。
1. Release Management でアプリを開き、左側のナビゲーションで <strong>Releases</strong> を選択します。
1. <strong>Connect app</strong> をクリックします。
1. サービスアカウントを設定します。ダイアログには 2 つのオプションがあります。

   <strong>Use project's service account</strong>: プロジェクトレベルで設定されたサービスアカウントを使用して Google Play に接続します。プロジェクトのサービスアカウントを変更すると、Release Management アプリのサービスアカウントも変更されます。

   <strong>Set app-level service account</strong>: workspace に追加されている任意のサービスアカウントを、<strong>Service account</strong> ドロップダウンメニューから選択できます。このオプションでは、プロジェクトレベルでどの API キーが設定されていても影響しません。
1. <strong>Application ID</strong> フィールドに Google Play アプリの package name を入力し、<strong>Validate</strong> をクリックします。

   - Google Play で package name が見つかった場合、<strong>Connect</strong> ボタンが有効になります。

   - 一致するものが見つからない場合は、package name を正しく入力したか確認し、Google Play サービスアカウントが動作していることを確認してください。
1. <strong>Connect</strong> をクリックします。

</TabItem>
</Tabs>
