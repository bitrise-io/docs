Bitriseは、ホスト型のCodePushプロダクトを提供しており、Bitrise platformの他の部分と統合されています。Release ManagementのReact NativeアプリとExpoアプリで、独自のインフラストラクチャをホスティングおよび運用することなく使用できます。

CodePushを使用すると、React Native開発者はモバイルアプリのアップデートをユーザーのデバイスに直接デプロイできます。このプロダクトは2つの部分で構成されています。

- BitriseのRelease Management内のCodePushでは、開発者がアップデートを公開し、ロールアウトして管理します。これはBitriseが運用するホスト型サービスです。まずは[CodePushデプロイの作成](/release-management/codepush/creating-a-codepush-deployment)から始めてください。
- アプリ内で利用可能なアップデートを処理する[アプリSDK](https://github.com/bitrise-io/react-native-code-push)。SDKはReact Native New ArchitectureとExpoをサポートしています。[CodePush用にアプリを設定する](/release-management/codepush/configuring-your-app-for-codepush)をご覧ください。

アプリユーザーにアップデートをプッシュするには、Release Managementの[アプリ](/release-management/getting-started-with-release-management/adding-a-new-app-to-release-management)が必要です。


## CodePushのプランとティア {#codepush-plans-and-tiers}

CodePushの利用状況は、次の要素によって測定されます。

- <strong>Monthly active users</strong>: 1回の月次請求サイクル内で、CodePushのアップデートを1回以上ダウンロードした一意のエンドユーザーです。同じ月内で同一人物が複数回ダウンロードした場合も、MAUとしては1件としてカウントされます。
- <strong>Data transfer</strong>: CodePushのアップデートによってユーザーに配信されたファイルの合計サイズです。
- <strong>Storage</strong>: CodePushのアップデートアーティファクトを保存するために<GlossTerm baseform="workspace">workspace</GlossTerm>に割り当てられた容量（GiB）の合計です。
