デバイスにオーバー・ジ・エア（OTA）アップデートを配信する場合、アップデートのダウンロードとインストールにかかる時間は、スムーズなユーザー体験にとって重要です。

CodePush経由でデプロイされるアップデートは、通常アプリのコードのごく一部のみを変更するため、バンドル全体をダウンロードしてインストールするのは非効率です。CodePushはパッケージバージョン間の差分アップデートを自動的に計算するため、変更部分のみがダウンロードおよびインストールされます。

## デルタアップデートの仕組み

デルタアップデートパッケージには、新しいバージョン全体ではなく、デバイスにすでにインストールされているバージョンとインストールするバージョンとの間の変更のみが含まれます。

![ファイルベースの差分方式とバイナリ差分方式のアップデートパッケージを比較する図](/img/codepush/file-vs-binary-diffing.png)

<strong>ファイルレベルの差分方式:</strong> CodePushは2つのリリースをファイルごとに比較します。アップデートパッケージには、新規追加および変更されたファイルの全内容と、削除するファイルのリストのみが含まれます。変更のないファイルはパッケージから除外されます。

<strong>バイナリ差分方式:</strong> より効率的な差分方式です。ファイルレベルの差分方式と同様に、変更のないファイルはパッケージから除外され、パッケージには削除するファイルのリストが含まれます。2つのバージョン間で変更があったファイルについては、CodePushが新旧バージョンの間でバイト単位のパッチを計算し、ファイル全体の代わりにそのパッチを配信します。ほとんどのReact Nativeアップデートでは、JSバンドルはバージョン間で必ず変更されるため、この手法によりJSバンドルファイル全体を取得する必要がなくなります。

## CodePushによるデルタアップデート

CodePushはパッケージバージョン間の差分アップデートを自動的に計算します。この機能はデフォルトで有効になっており、クライアントSDKがより高速にダウンロードおよびインストールできる、より小さなアップデートが実現します。また、データ転送コストの削減にもつながります。

CodePushのデルタアップデートはサーバー側で計算されるため、有効にするために特別な作業を行う必要はありません。

現時点でのデルタアップデートの仕組みはファイルレベルの差分方式であり、バイナリ差分方式のサポートはQ42026年に[Bitrise CodePush SDK](https://github.com/bitrise-io/react-native-code-push)へ追加される予定です。
