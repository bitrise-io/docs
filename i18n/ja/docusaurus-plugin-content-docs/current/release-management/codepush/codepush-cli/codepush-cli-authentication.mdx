CodePush コマンドに必要なBitrise APIを操作するには、APIトークンが必要です。トークンには次の2つの方法でアクセスできます。

- 環境変数(Env Var)を作成し、設定内でそれを参照する方法。CIビルドの場合はこの方法をお勧めします。
- アクセストークンをローカルに保存する方法。ローカル開発の場合はこの方法をお勧めします。

両方が設定されている場合、環境変数が先に解決され、優先されます。

## 環境変数を使用した認証 {#authenticating-with-an-env-var}

1. [個人用アクセストークンを生成](/bitrise-platform/accounts/personal-access-tokens)し、コピーします。
1. トークンの値をBITRISE_API_TOKEN環境変数に追加します。
1. コマンドを実行すると、CodePush のCLIが自動的に環境変数を解決します。

## トークンをローカルに保存する {#storing-the-token-locally}

1. [個人用アクセストークンを生成](/bitrise-platform/accounts/personal-access-tokens)し、コピーします。
1. 次のいずれかのコマンドを実行します。

   ```bash
   # Interactive — prompts for your token
   bitrise :codepush auth login

   # Non-interactive
   bitrise :codepush auth login --token <TOKEN>    # or: -t <TOKEN>
   ```

   トークンは、制限された権限(0600)でユーザー設定ディレクトリに保存されます。

   - macOS: `~/Library/Application Support/codepush/config.json`
   - Linux: `~/.config/codepush/config.json`

## ローカルに保存したトークンを失効させる {#revoking-a-locally-stored-token}

CodePush 用にローカルに保存したAPIトークンを失効させたい場合は、いつでも失効させることができます。トークンを失効させると、BITRISE_API_TOKEN環境変数を設定しない限り、Bitrise APIを操作できなくなります。

トークンを失効させるには、次のコマンドを実行します。

```bash
bitrise :codepush auth revoke
```
