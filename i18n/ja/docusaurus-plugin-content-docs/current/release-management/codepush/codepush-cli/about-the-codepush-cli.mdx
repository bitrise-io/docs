Bitrise CodePush CLIは、CodePush用のクライアントです。ローカルマシン上で使用し、CodePushの統合とアップデートを設定・管理します。

CodePush CLIは2つのモードで実行できます。1つは[Bitrise CLI](/bitrise-ci/bitrise-cli/installing-and-updating-the-bitrise-cli)プラグイン(コマンドのプレフィックスは`bitrise :codepush`)として、もう1つはスタンドアロンバイナリ(コマンドのプレフィックスは`codepush`)としてです。どちらのモードも同じコマンドをサポートしており、Bitrise CodePushサーバーへの認証にはBitrise APIトークンが必要です。

CodePush CLIは、HTTPS経由でBitrise APIと通信するGoバイナリです。ほとんどのコマンドは、認証のためにBitrise APIトークンを必要とします。例外は完全にローカルで完結する操作です。`bundle`はマシン上で直接React NativeまたはExpoバンドラーを呼び出し(`npx react-native bundle`または`npx expo export:embed`)、`debug`はAPI呼び出しを一切行わずに、`adb`または`xcrun`経由で接続されたデバイスからログをストリーミングします。

CodePush CLIを使用すると、次のことができます。

- デプロイの作成、一覧表示、名前変更、削除を行います。
- アップデートのプッシュ、以前のリリースへのロールバック、デプロイ間でのリリースのプロモート、既存リリースのメタデータのパッチ適用を行います。
- 特定のバージョンのアップデート詳細とアップデート処理ステータスを表示します。
- プロジェクト構成を初期化し、認証情報をローカルに保存します。
- React NativeおよびExpoプロジェクト向けにJavaScriptバンドルを生成します。プロジェクトの種類、エントリファイル、Hermes、Metro設定を自動検出します。

また、CodePush CLIを使用して、さまざまなサーバー環境を作成し、切り替えることもできます。たとえば、CodePushのアップデートをBitrise CodePushサーバーにプッシュする前に、ステージング環境を設定できます。

CodePush CLIのソースコードはGitHubで公開されています：[bitrise-io/bitrise-plugins-codepush-cli](https://github.com/bitrise-io/bitrise-plugins-codepush-cli)。
