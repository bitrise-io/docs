Release Managementは、TestFlightやGoogle Playを利用することなく、モバイルアプリのビルドをテスターに配布できる、便利で安全なソリューションです。インストール可能なアーティファクトがあれば、Bitriseによってプライベートとパブリックの両方のインストールリンクを生成でき、テスターやその他の関係者はそのリンクを使って、OTA(Over-the-Air)インストールで実機にアプリをインストールできます。

配布可能なすべてのビルドには、<strong>Build distribution</strong>ページからアクセスできます。これらは、内部テスターに配布できるビルドです。配布可能なビルドは次のとおりです。

- iOSアプリの場合、Development、Ad-hoc、またはEnterpriseのプロビジョニングが設定されたIPAです。
- Androidアプリの場合、テスターに配布できるのはAPKのみです。AABは配布できません。

配布可能な各ビルドには、インストール手順とメタデータを含む専用のページがあります。メタデータには、アーティファクトのソース、作成日時、サイズ、supported device typesなどが含まれます。

テスターグループを設定すると、テスターがbuild detailsページにアクセスして、そこからアプリをインストールできるようになります。<GlossTerm baseform="workspace">Workspace</GlossTerm>のオーナー、Workspaceマネージャー、プロジェクト管理者は、ビルドページからテスターグループに通知メールを送信することもできます。詳細については、[テスターグループ](/release-management/build-distribution/tester-groups)を参照してください。

Bitrise CIのビルドから、または専用のAPIを使用して、インストール可能なアーティファクトをこのページにアップロードできます。詳細については、[インストール可能なアーティファクト](/release-management/installable-artifacts)を参照してください。

## build detailsページへのアクセス {#accessing-the-build-details-page}

Bitriseでbuild detailsページにアクセスするには、次の手順に従います。

:::note[ログインが必要です]

build detailsページにアクセスするには、Bitriseユーザーアカウントが必要です。このアカウントは、プロジェクトのチームのメンバーである必要があります。

:::

1. Release Managementで接続済みのアプリを開きます。
1. 左側で<strong>Build distribution</strong>を選択します。
1. <strong>Builds</strong>タブを選択します。
1. 目的のビルドを見つけて、右側の矢印をクリックします。

   ![build-details-access.png](/img/_paligo/uuid-55dc2023-f61b-5331-f1af-94924727ff25.png)

## アーティファクトのインストール {#installing-artifacts}

ビルドのアーティファクトは、そのbuild detailsページからインストールできます。手順は次のとおりです。

1. ビルドの[build detailsページにアクセスします](#accessing-the-build-details-page)。

   通知メールからbuild detailsページにアクセスすることもできます。
1. <strong>Install this version securely</strong>カードで、ビルドをインストールまたはダウンロードします。

   - モバイルデバイスでページを開くには、そのデバイスでQRコードをスキャンします。
   - アプリがAndroidアプリの場合は、<strong>Download artifact</strong>をクリックしてAPKファイルまたはAABファイルをダウンロードします。
   - アプリがiOSアプリの場合は、お使いのユーザーとこのビルドに登録されているデバイスのSafari(プライベートウィンドウ以外)でページを開き、<strong>Install</strong>をクリックします。直接インストールできない場合は、ページ上部の<strong>Download artifact</strong>アイコンボタンを使用してIPAファイルをダウンロードしてください。
   - 別のBitriseユーザーとページを共有するには、<strong>Copy page URL</strong>をクリックします。このページにアクセスするには認証が必要です。

## 公開インストールページの有効化 {#enabling-the-public-install-page}

公開インストールページを使用すると、Bitriseアカウントを持たないテスターにも、インストール可能なアーティファクトを配布できます。

1. ビルドのbuild detailsページにアクセスします。
1. <strong>Public install link</strong>カードを見つけて、<strong>Manage access</strong>をクリックします。

   :::important[必要なアクセス権]

   ビルドの公開インストールページを有効または無効にできるのは、Workspaceのオーナー、プロジェクト管理者、Releaseマネージャーのみです。

   :::
1. <strong>Manage public install link</strong>ダイアログで<strong>Enabled</strong>を選択し、<strong>Save changes</strong>をクリックします。

   公開インストールページを再度オフにするには、<strong>Disabled</strong>を選択して<strong>Save changes</strong>をクリックします。
1. <strong>Get link</strong>をクリックすると、URLとQRコードの両方を含むダイアログが開きます。

## カスタムアクセスリンク {#custom-access-link}

APKまたはストア向けではないIPAアーティファクトについて、共有可能なインストールリンクをすばやく生成できます。有効期限とアクセスコードは任意で設定できます。リンクを受け取ったユーザーは、Bitriseアカウントがなくてもビルドをインストールできます。

:::note

このリンクは、[公開インストールページ](/bitrise-ci/deploying/ios-deployment/installing-an-ipa-file-from-the-public-install-page)のリンクとは異なります。公開インストールページは恒久的で、アクセス制御はありません。

:::

次の[アクセスロール](/release-management/configuring-connected-apps/release-management-roles-and-permissions)を持つユーザーは、カスタムアクセスリンクを作成できます。

- Workspace owners
- Project admin

同じアーティファクトに対して、有効期限の異なる複数のアクセスリンクを作成することも、有効期限なしで作成することもできます。すべての共有リンクは、URLを知っていれば誰でもアクセスできます。

### カスタムアクセスリンクの作成 {#creating-a-custom-access-link}

1. [ビルドのbuild detailsページにアクセスします](/release-management/build-distribution/distributing-builds-to-testers)。
1. <strong>Public access</strong>タブに移動します。
1. <strong>New access link</strong>をクリックします。
1. link nameを追加します。
1. 必要に応じて<strong>Expiry</strong>をオンにして、for theリンクの有効期限を設定します。指定した日付を過ぎると、リンクにはアクセスできなくなります。
1. 必要に応じて<strong>Access code</strong>をオンにして、入力フィールドにコードを設定します。テスターがリンクにアクセスするには、このコードが必要になります。
1. 準備ができたら、<strong>Create & copy URL</strong>をクリックします。


## テスター向け手順の追加 {#adding-instructions-for-testers}

インストール可能なアーティファクトごとに、テスター向けのテスト手順を設定できます。ビルドに追加された内容や、テストしてほしい項目をテスターに伝えられます。

この手順は、インストール可能なアーティファクトのbuild detailsページと、[公開インストールページ](/bitrise-ci/deploying/ios-deployment/installing-an-ipa-file-from-the-public-install-page)で確認できます。

:::important[編集権限]

次のロールを持つユーザーは、テスト手順を編集できます。

- Workspaceのオーナー
- Project admin
- Release Manager

App testerロールを持つユーザーは、読み取り専用のアクセス権を持ちます。ロールの詳細については、[Release Managementのロールと権限](/release-management/configuring-connected-apps/release-management-roles-and-permissions)を参照してください。

:::

インストール可能なアーティファクトにテスト手順を追加するには、次の手順に従います。

1. [build detailsページにアクセスします](/release-management/build-distribution/distributing-builds-to-testers)。

   通知メールからbuild detailsページにアクセスすることもできます。
1. <strong>What to test</strong>セクションを見つけて、<strong>Edit</strong>をクリックします。

   ![2025-09-04-rm-what-to-test.png](/img/_paligo/uuid-aac41e7c-0756-9d0b-d3a3-9fdf2db628dc.png)
1. テスター宛てのメッセージを書き、what to testを伝えます。

   メッセージの上限は4000文字です。
1. <strong>Save changes</strong>をクリックします。
